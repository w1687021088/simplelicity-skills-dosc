# CREATE EVENT 创建事件

`CREATE EVENT` 语句创建一个定时任务，在指定时间或按照指定间隔自动执行 SQL 语句块。事件由 MySQL 事件调度器负责触发，无需外部 cron 或任务调度程序介入，所有定时逻辑在数据库内完成。

---

## 语法

```sql
CREATE
    [DEFINER = user]
    EVENT [IF NOT EXISTS] event_name
    ON SCHEDULE schedule
    [ON COMPLETION [NOT] PRESERVE]
    [ENABLE | DISABLE | DISABLE ON SLAVE]
    [COMMENT 'string']
    DO event_body;

schedule:
    AT timestamp [+ INTERVAL interval] ...   -- 一次性：在指定时刻执行
  | EVERY interval                           -- 周期性：每隔一段时间执行
    [STARTS timestamp [+ INTERVAL interval]]
    [ENDS timestamp [+ INTERVAL interval]]

interval:
    quantity {YEAR | QUARTER | MONTH | DAY | HOUR | MINUTE | WEEK | SECOND |
              YEAR_MONTH | DAY_HOUR | DAY_MINUTE | DAY_SECOND | 
              HOUR_MINUTE | HOUR_SECOND | MINUTE_SECOND}
```

---

## 一次性事件（AT）

```sql
-- 10 分钟后执行一次（执行后自动删除，ON COMPLETION NOT PRESERVE 是默认）
CREATE EVENT IF NOT EXISTS evt_one_time_cleanup
ON SCHEDULE AT NOW() + INTERVAL 10 MINUTE
DO
    DELETE FROM temp_cache WHERE expired_at < NOW();

-- 在指定时刻执行一次
CREATE EVENT IF NOT EXISTS evt_midnight_archive
ON SCHEDULE AT '2026-12-31 23:59:00'
ON COMPLETION NOT PRESERVE   -- 执行后自动删除（默认）
COMMENT '年末数据归档'
DO
    INSERT INTO archive_2026 SELECT * FROM orders WHERE YEAR(created_at) = 2026;
```

## 周期性事件（EVERY）

```sql
-- 每天凌晨 1 点执行清理
CREATE EVENT IF NOT EXISTS evt_daily_cleanup
ON SCHEDULE EVERY 1 DAY
    STARTS '2026-01-01 01:00:00'   -- 从这个时间开始
ON COMPLETION PRESERVE              -- 执行后保留事件（不自动删除）
ENABLE
COMMENT '每日凌晨1点清理过期数据'
DO
BEGIN
    DELETE FROM session_logs WHERE expired_at < NOW() - INTERVAL 30 DAY;
    DELETE FROM temp_files WHERE created_at < NOW() - INTERVAL 7 DAY;
END;

-- 每小时统计一次
CREATE EVENT IF NOT EXISTS evt_hourly_stats
ON SCHEDULE EVERY 1 HOUR
    STARTS CURDATE() + INTERVAL 1 HOUR   -- 从下一个整点开始
ON COMPLETION PRESERVE
DO
    INSERT INTO hourly_stats (hour_time, order_count, total_revenue)
    SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:00:00'),
           COUNT(*), SUM(amount)
    FROM orders
    WHERE created_at >= NOW() - INTERVAL 1 HOUR
      AND status = 2;

-- 每 5 分钟执行一次（带结束时间）
CREATE EVENT IF NOT EXISTS evt_five_min_check
ON SCHEDULE EVERY 5 MINUTE
    STARTS NOW()
    ENDS NOW() + INTERVAL 24 HOUR   -- 只执行 24 小时
ON COMPLETION NOT PRESERVE
DO
    UPDATE queue_items SET status = 4
    WHERE status = 1 AND created_at < NOW() - INTERVAL 30 MINUTE;
```

## ON COMPLETION 选项

```sql
-- ON COMPLETION NOT PRESERVE（默认）：事件执行完毕（AT 时间过了或 ENDS 到期）后自动删除
CREATE EVENT evt_auto_drop
ON SCHEDULE AT NOW() + INTERVAL 1 HOUR
ON COMPLETION NOT PRESERVE
DO SELECT 1;  -- 1小时后执行，然后自动删除该事件

-- ON COMPLETION PRESERVE：事件过期后保留（状态变为 DISABLE，可以查看和重启）
CREATE EVENT evt_keep_after_done
ON SCHEDULE AT NOW() + INTERVAL 1 HOUR
ON COMPLETION PRESERVE   -- 执行后不删除，可以通过 ALTER EVENT 重新设置
DO SELECT 1;
```

## ENABLE / DISABLE 状态

```sql
-- 创建时禁用（先创建，后续手动启用）
CREATE EVENT evt_initially_disabled
ON SCHEDULE EVERY 1 DAY
STARTS '2026-03-01 02:00:00'
DISABLE   -- 暂时禁用，不会执行
COMMENT '计划中的批量任务，未来启用'
DO CALL sp_batch_process();

-- 启用事件
ALTER EVENT evt_initially_disabled ENABLE;

-- 禁用事件（暂停执行）
ALTER EVENT evt_daily_cleanup DISABLE;
```

## 查看已创建的事件

```sql
-- 查看当前数据库的事件
SHOW EVENTS;
SHOW EVENTS FROM mydb;

-- 查看完整定义
SHOW CREATE EVENT evt_daily_cleanup\G

-- 从 information_schema 查询
SELECT EVENT_NAME, EVENT_TYPE, EXECUTE_AT, INTERVAL_VALUE, INTERVAL_FIELD,
       STATUS, LAST_EXECUTED, NEXT_EXECUTION_AT
FROM information_schema.EVENTS
WHERE EVENT_SCHEMA = DATABASE();
```

## 适用场景

- **定时清理**：过期数据、日志、临时文件的定期删除
- **定时统计**：每小时/每天汇总业务指标到报表表
- **定时任务**：自动取消超时未支付订单、定时发送推送通知队列
- **数据归档**：定期将历史数据迁移到归档表

## 常见问题

**事件调度器未开启时，创建的事件会执行吗？**

不会。调度器未开启（`event_scheduler = OFF`）时，事件定义存在数据库中，但不会被触发执行。当调度器开启后，处于 ENABLE 状态且时间符合的事件会立即开始执行（如果有积压的错过执行时间，不会补执行）。

---

## 注意事项

- 事件体中的 SQL 语句如果有错误（如表不存在），事件仍然会被触发并尝试执行，只是执行失败。MySQL 不会自动禁用执行失败的事件，也不会发送报警，需要通过 `information_schema.EVENTS` 的 `LAST_EXECUTED` 和通过错误日志监控。
- 事件体如果包含多条语句，必须用 `BEGIN ... END` 包裹，并相应地设置 DELIMITER。在 MySQL Workbench 或其他 GUI 工具中创建时，工具通常自动处理这个问题。

---

## 总结

`CREATE EVENT event_name ON SCHEDULE {AT timestamp | EVERY interval} DO event_body` 创建定时任务。一次性事件用 `AT`，周期性事件用 `EVERY`。`ON COMPLETION PRESERVE` 保留事件定义（否则执行后自动删除）。创建时可以 `DISABLE` 先暂停，之后用 `ALTER EVENT ... ENABLE` 激活。事件调度器必须开启（`event_scheduler = ON`）事件才会执行。
