# SET 变量赋值

在存储过程中，`SET` 语句用于给局部变量、用户变量和系统变量赋值。它是最直接的赋值方式，可以赋予字面量、表达式计算结果、函数返回值等。

---

## 语法

```sql
SET var_name = expr [, var_name = expr ...]
SET @user_var = expr
SET @@system_var = expr
```

---

## 基本示例

```sql
DELIMITER //

CREATE PROCEDURE sp_set_demo()
BEGIN
    DECLARE v_count  INT          DEFAULT 0;
    DECLARE v_name   VARCHAR(100) DEFAULT '';
    DECLARE v_date   DATE;
    
    -- 赋予字面量
    SET v_count = 10;
    SET v_name  = 'MySQL 8.4';
    
    -- 赋予表达式结果
    SET v_count = v_count * 2 + 5;   -- 25
    
    -- 赋予函数返回值
    SET v_date = CURDATE();
    
    -- 一次赋多个变量
    SET v_count = 100, v_name = 'Admin', v_date = '2026-01-01';
    
    -- 赋值给用户变量（@prefix）
    SET @result = v_count;
    
    SELECT v_count, v_name, v_date, @result;
END //

DELIMITER ;
```

## SET 与系统变量

```sql
DELIMITER //

CREATE PROCEDURE sp_set_system_vars()
BEGIN
    -- 读取系统变量
    DECLARE v_max_connections INT;
    SET v_max_connections = @@global.max_connections;
    SELECT v_max_connections;
    
    -- 设置会话级系统变量（在过程内有效）
    SET @@session.group_concat_max_len = 65536;
    
    -- 修改完成后，建议恢复（避免影响其他查询）
    SET @@session.group_concat_max_len = 1024;
END //

DELIMITER ;
```

## SET 赋值与 SELECT INTO 的对比

```sql
DELIMITER //

CREATE PROCEDURE sp_compare_assignment(IN p_user_id INT)
BEGIN
    DECLARE v_email   VARCHAR(255);
    DECLARE v_count   INT;
    
    -- 方式1：SET 直接赋字面量或表达式
    SET v_count = 0;
    SET v_email = CONCAT('user_', p_user_id, '@example.com');  -- 拼接字符串
    
    -- 方式2：SELECT INTO 从查询结果赋值
    SELECT email INTO v_email FROM users WHERE id = p_user_id;
    SELECT COUNT(*) INTO v_count FROM orders WHERE user_id = p_user_id;
    
    SELECT v_email, v_count;
END //

DELIMITER ;
```

| 赋值方式 | 适用场景 | 示例 |
|---------|---------|------|
| `SET var = value` | 字面量、表达式、函数结果 | `SET v_x = v_x + 1` |
| `SELECT col INTO var` | 从表中查询结果赋值 | `SELECT name INTO v_name FROM t WHERE id=1` |

## 条件赋值

```sql
DELIMITER //

CREATE PROCEDURE sp_conditional_set(IN p_score INT)
BEGIN
    DECLARE v_grade VARCHAR(10);
    
    -- SET 结合 IF 表达式
    SET v_grade = IF(p_score >= 90, 'A',
                 IF(p_score >= 80, 'B',
                 IF(p_score >= 70, 'C',
                 IF(p_score >= 60, 'D', 'F'))));
    
    -- 或者用 CASE 表达式
    SET v_grade = CASE
        WHEN p_score >= 90 THEN 'A'
        WHEN p_score >= 80 THEN 'B'
        WHEN p_score >= 70 THEN 'C'
        WHEN p_score >= 60 THEN 'D'
        ELSE 'F'
    END;
    
    SELECT p_score, v_grade;
END //

DELIMITER ;
```

## 适用场景

- **初始化局部变量**：设置计数器初始值、累加器初始值、标志位
- **计算中间结果**：在循环或条件分支中更新变量值
- **临时修改系统变量**：在过程内临时调整 `group_concat_max_len` 等会话变量
- **构建动态值**：通过 CONCAT、日期函数等构建字符串或日期值赋给变量

---

## 常见问题

**SET 和 `:=` 赋值操作符有区别吗？**

在存储过程中 `SET var = value` 和 `SET var := value` 效果相同（`:=` 是赋值操作符）。在 SELECT 语句中，`=` 是比较操作符，只有 `:=` 才是赋值（如 `SELECT @var := 1`）。在存储过程的 SET 语句中，两者等价，推荐用 `=`（更简洁）。

---

## 注意事项

- `SET` 赋值是即时生效的，赋值语句执行后，后续代码立即使用新值。
- 在同一 `SET` 语句中一次赋多个变量时（`SET v_a = 1, v_b = v_a + 1`），注意赋值顺序：`v_b = v_a + 1` 使用的是赋值前的 `v_a` 值（即赋值并不是同时发生的，是从左到右顺序赋值）。

---

## 总结

`SET var = expr` 是存储过程中最直接的变量赋值语句，支持字面量、表达式、函数返回值、IF/CASE 条件表达式等。可以一次 SET 多个变量（逗号分隔）。与 `SELECT ... INTO` 的区别是：SET 用于直接赋值，SELECT INTO 用于从查询结果赋值。也可以通过 SET 修改系统变量（`@@session.var`），但过程结束后记得恢复以避免影响其他查询。
