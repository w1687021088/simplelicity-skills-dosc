# INOUT 双向参数

`INOUT` 参数既可以接收调用者传入的值（读），也可以在过程内修改该值并将新值传回给调用者（写）。它结合了 `IN` 和 `OUT` 的特性，适合"传入一个值，过程处理后修改并返回"的场景，相当于双向的按引用传递。

---

## 语法

```sql
CREATE PROCEDURE sp_name(INOUT param_name data_type)
BEGIN
    -- 可以读取 param_name（来自调用者）
    -- 也可以修改 param_name（修改后传回调用者）
    SET param_name = new_value;
END;
```

---

## 基本示例

```sql
DELIMITER //

-- 将值翻倍并返回
CREATE PROCEDURE sp_double_value(INOUT p_num INT)
BEGIN
    SET p_num = p_num * 2;  -- 读取调用者传入的值，修改后写回
END //

-- 字符串追加
CREATE PROCEDURE sp_append_suffix(INOUT p_str VARCHAR(255), IN p_suffix VARCHAR(50))
BEGIN
    SET p_str = CONCAT(p_str, p_suffix);  -- 在原字符串后追加
END //

DELIMITER ;

-- 调用
SET @val = 10;
CALL sp_double_value(@val);
SELECT @val;  -- 20（传入 10，过程将其翻倍后返回 20）

SET @greeting = 'Hello';
CALL sp_append_suffix(@greeting, ', MySQL 8.4!');
SELECT @greeting;  -- 'Hello, MySQL 8.4!'
```

## INOUT 与计数器

```sql
DELIMITER //

-- 累计增加调用次数（每调用一次，计数器 +1）
CREATE PROCEDURE sp_increment_counter(INOUT p_counter INT, IN p_step INT)
BEGIN
    SET p_counter = COALESCE(p_counter, 0) + p_step;
END //

DELIMITER ;

SET @counter = 0;
CALL sp_increment_counter(@counter, 1);   -- @counter = 1
CALL sp_increment_counter(@counter, 5);   -- @counter = 6
CALL sp_increment_counter(@counter, 3);   -- @counter = 9
SELECT @counter;  -- 9
```

## 实际业务应用：余额操作

```sql
DELIMITER //

-- 账户充值：传入当前余额，充值后返回新余额
CREATE PROCEDURE sp_recharge(
    INOUT p_balance  DECIMAL(12,2),
    IN    p_amount   DECIMAL(12,2),
    OUT   p_success  TINYINT
)
BEGIN
    IF p_amount <= 0 THEN
        SET p_success = 0;  -- 充值金额无效
    ELSE
        SET p_balance = p_balance + p_amount;
        SET p_success = 1;
    END IF;
END //

DELIMITER ;

SET @balance = 100.00;
CALL sp_recharge(@balance, 50.00, @ok);
SELECT @balance AS new_balance, @ok AS success;
-- new_balance = 150.00, success = 1
```

## IN / OUT / INOUT 三种参数对比

| 参数方向 | 调用者传值 | 过程内可读取初始值 | 过程内修改能否传回 | 典型用途 |
|---------|----------|-----------------|-----------------|---------|
| IN | 是 | 是 | 否 | 传入查询条件、操作目标 |
| OUT | 是（变量名）| 否（初始为 NULL）| 是 | 返回计算结果、操作状态 |
| INOUT | 是 | 是 | 是 | 读取后修改再传回（如计数器、余额）|

---

## 适用场景

- **累加/累减操作**：计数器、余额增减（每次调用都在上次结果基础上操作）
- **字符串拼接累积**：多次调用逐步拼接构建一个长字符串
- **状态机推进**：传入当前状态，过程内计算新状态后写回

---

## 常见问题

**INOUT 参数必须传用户变量吗？**

与 OUT 参数相同，INOUT 参数也必须传变量（用户变量 `@var` 或局部变量），不能传字面量。因为 INOUT 需要既读取初始值又写回修改值，字面量无法被写入。

---

## 注意事项

- `INOUT` 参数在过程内修改的是该变量的值，而不是副本。如果调用者传入的变量还有其他用途，调用后注意其值已被修改。
- 调用前确保 INOUT 参数对应的用户变量已初始化（`SET @var = initial_value`），否则初始值为 NULL，可能导致计算结果异常。

---

## 总结

`INOUT` 参数结合了 IN 和 OUT 的特性，进入过程时可以读取调用者传入的值，过程内的修改也会传回调用者。适合"读取-修改-返回"模式的操作（计数器、余额、状态机）。与 OUT 的区别是 INOUT 进入过程时有初始值（调用者传入的），而 OUT 进入时始终为 NULL。
