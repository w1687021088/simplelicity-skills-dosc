# CASE 流程控制语句

存储过程中的 `CASE` 是流程控制语句（不是 SQL 表达式），用于多分支逻辑判断，功能上等同于多个 `ELSEIF` 的 IF 语句，但在多等值判断时语法更简洁清晰。它有两种形式：简单 CASE（等值比较）和搜索 CASE（条件表达式）。

---

## 语法

```sql
-- 形式1：简单 CASE（等值比较）
CASE case_value
    WHEN when_value1 THEN statements;
    [WHEN when_value2 THEN statements;]
    ...
    [ELSE statements;]
END CASE;

-- 形式2：搜索 CASE（任意条件）
CASE
    WHEN condition1 THEN statements;
    [WHEN condition2 THEN statements;]
    ...
    [ELSE statements;]
END CASE;
```

---

## 基本示例

```sql
DELIMITER //

-- 简单 CASE：按状态码分发处理
CREATE PROCEDURE sp_handle_order_status(IN p_order_id INT)
BEGIN
    DECLARE v_status INT;
    SELECT status INTO v_status FROM orders WHERE id = p_order_id;
    
    CASE v_status
        WHEN 0 THEN
            -- 待支付：检查支付超时
            UPDATE orders SET status = 4
            WHERE id = p_order_id AND created_at < NOW() - INTERVAL 30 MINUTE;
        WHEN 1 THEN
            -- 已支付：触发发货流程
            INSERT INTO shipping_queue(order_id, created_at) VALUES (p_order_id, NOW());
        WHEN 2 THEN
            -- 已发货：无操作，等待用户确认
            SELECT '订单已发货，等待收货确认' AS message;
        WHEN 3 THEN
            -- 已完成：写入完结日志
            INSERT INTO order_history(order_id, action, created_at)
            VALUES (p_order_id, 'completed', NOW());
        ELSE
            SELECT CONCAT('未知状态：', v_status) AS message;
    END CASE;
END //

-- 搜索 CASE：按分数区间分级
CREATE PROCEDURE sp_score_grade(IN p_score INT, OUT p_grade VARCHAR(10))
BEGIN
    CASE
        WHEN p_score IS NULL THEN
            SET p_grade = '未参加考试';
        WHEN p_score >= 90 THEN
            SET p_grade = 'A';
        WHEN p_score >= 80 THEN
            SET p_grade = 'B';
        WHEN p_score >= 70 THEN
            SET p_grade = 'C';
        WHEN p_score >= 60 THEN
            SET p_grade = 'D';
        ELSE
            SET p_grade = 'F';
    END CASE;
END //

DELIMITER ;
```

## 无匹配时的行为

```sql
DELIMITER //

CREATE PROCEDURE sp_case_no_match(IN p_val INT)
BEGIN
    -- 简单 CASE：没有 ELSE 且 p_val 不匹配任何 WHEN 时
    CASE p_val
        WHEN 1 THEN SELECT '一';
        WHEN 2 THEN SELECT '二';
        -- 没有 ELSE
    END CASE;
    -- 如果 p_val = 5，报错：ERROR 1339 (20000): Case not found for CASE statement
END //

DELIMITER ;

-- 安全写法：始终加上 ELSE（即使只是记录日志或空操作）
CASE p_val
    WHEN 1 THEN ...;
    WHEN 2 THEN ...;
    ELSE BEGIN END;  -- 空 ELSE，不做任何操作但不报错
END CASE;
```

## CASE 流程控制语句 vs CASE WHEN 表达式

```sql
-- CASE 流程控制语句（只能在存储程序中，执行语句块）
CASE v_status
    WHEN 1 THEN
        UPDATE orders SET ...;    -- 可以执行多条 SQL
        INSERT INTO logs ...;
    WHEN 2 THEN
        DELETE FROM ...;
END CASE;

-- CASE WHEN 表达式（可以在任何 SQL 中，返回单个值）
SELECT CASE status
    WHEN 1 THEN '待支付'
    WHEN 2 THEN '已完成'
    ELSE '其他'
END AS status_label
FROM orders;

-- 在 SET 中用 CASE 表达式
SET v_label = CASE v_status
    WHEN 1 THEN '待支付'
    ELSE '其他'
END;
```

## 适用场景

- **多状态码分发处理**：根据状态码执行不同的 UPDATE/INSERT 操作（比多个 IF-ELSEIF 更清晰）
- **枚举值的多路分支**：处理有限枚举值（订单类型、角色类型、操作码）
- **命令分发模式**：存储过程接收一个命令参数，用 CASE 分发到不同的执行路径

---

## 常见问题

**CASE 流程控制语句和 IF 流程控制语句什么时候用哪个？**

多个等值比较（如状态码 1/2/3/4）用 CASE 更简洁，可读性更好；复杂条件（范围判断、NULL 检查、混合条件）用 IF-ELSEIF 更灵活。实际上两者可以互换，但按约定选择合适的会让代码更易读。

---

## 注意事项

- 没有 `ELSE` 子句的 CASE 语句，如果所有 WHEN 都不匹配，会报错 `ERROR 1339: Case not found`。建议总是加 `ELSE BEGIN END;`（空操作）或在 ELSE 中处理异常情况。
- 存储过程中的 `CASE` 流程控制语句以 `END CASE` 结束（有 CASE 两个词），而 SQL 表达式中的 CASE 以 `END` 结束（只有一个词），不要混淆。

---

## 总结

`CASE ... WHEN ... THEN ... [ELSE ...] END CASE` 是存储过程中的多路分支控制语句，有等值比较（简单 CASE）和条件表达式（搜索 CASE）两种形式。没有 ELSE 且无匹配时报错，应始终添加 ELSE 子句。与 SQL 中的 CASE WHEN 表达式不同，流程控制 CASE 可以在每个 WHEN 分支中执行多条 SQL 语句，且以 `END CASE` 结束。
