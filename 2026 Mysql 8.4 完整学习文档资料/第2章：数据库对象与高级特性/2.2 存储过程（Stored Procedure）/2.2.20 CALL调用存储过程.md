# CALL 调用存储过程

`CALL` 语句执行一个已创建的存储过程。存储过程可以有 IN、OUT、INOUT 三种参数，调用时分别传入字面量/变量、用户变量。`CALL` 也可以在另一个存储过程内部调用（嵌套调用）。

---

## 语法

```sql
CALL sp_name([parameter[,...]])
CALL sp_name[()]   -- 无参数时括号可省略
```

---

## 基本调用示例

```sql
-- 无参数存储过程
CALL sp_get_all_users();
CALL sp_get_all_users;   -- 无参数时括号可省略

-- 只有 IN 参数
CALL sp_get_user(5);
CALL sp_get_user(p_user_id => 5);  -- MySQL 8.0+ 不支持命名参数，只支持位置参数

-- IN + OUT 参数
CALL sp_get_user_email(5, @email);
SELECT @email;   -- 查看 OUT 参数的值

-- IN + OUT + INOUT 参数
SET @balance = 100.00;
CALL sp_recharge(@balance, 50.00, @success);
SELECT @balance, @success;
```

---

## 调用前设置用户变量

```sql
-- 为 OUT/INOUT 参数准备变量（可以不初始化，但建议初始化）
SET @user_count = 0;
CALL sp_count_users(@user_count);
SELECT @user_count AS total_active_users;

-- 多个 OUT 参数
CALL sp_order_stats(5, @cnt, @total, @last_date);
SELECT 
    @cnt        AS order_count,
    @total      AS total_amount,
    @last_date  AS last_order_date;
```

## 在存储过程中调用存储过程（嵌套调用）

```sql
DELIMITER //

-- 外层过程调用内层过程
CREATE PROCEDURE sp_outer(IN p_user_id INT)
BEGIN
    DECLARE v_email    VARCHAR(255);
    DECLARE v_order_cnt INT;
    
    -- 调用另一个存储过程获取邮件
    CALL sp_get_user_email(p_user_id, @email_out);
    SET v_email = @email_out;
    
    -- 调用另一个统计过程
    CALL sp_count_user_orders(p_user_id, @order_cnt_out);
    SET v_order_cnt = @order_cnt_out;
    
    SELECT v_email, v_order_cnt;
END //

DELIMITER ;
```

## CALL 返回结果集

```sql
-- 存储过程中的 SELECT 语句会直接返回结果集给客户端
CALL sp_get_active_users();
-- 客户端会收到一个结果集（和普通 SELECT 一样）

-- 存储过程中有多个 SELECT，客户端会收到多个结果集
DELIMITER //
CREATE PROCEDURE sp_multi_resultset()
BEGIN
    SELECT COUNT(*) AS user_count FROM users;           -- 结果集 1
    SELECT COUNT(*) AS order_count FROM orders;         -- 结果集 2
    SELECT SUM(amount) AS total_revenue FROM orders;    -- 结果集 3
END //
DELIMITER ;

CALL sp_multi_resultset();
-- 客户端依次收到三个结果集
```

## 获取 CALL 执行后的状态

```sql
-- ROW_COUNT()：获取存储过程内最后一条 DML 语句影响的行数
-- （注意：获取的是过程内最后一条 DML，不完全可靠）
CALL sp_update_user_status(5, 0);
SELECT ROW_COUNT() AS affected;

-- LAST_INSERT_ID()：获取存储过程内最后一次 INSERT 的自增 ID
CALL sp_create_user('alice', 'alice@example.com', @new_id);
-- 过程内 SET @new_id = LAST_INSERT_ID()
SELECT @new_id AS new_user_id;
```

## 适用场景

- **封装业务操作**：下单、支付、退款等多步骤操作封装为过程，通过 CALL 触发
- **定时任务**：事件调度器（Event Scheduler）通过 CALL 执行存储过程实现定时任务
- **批量数据处理**：手动触发批量操作（数据迁移、定期统计）

---

## 常见问题

**CALL 能在普通 SELECT 中使用吗？**

不能。`CALL` 是独立的语句，不能嵌入到 `SELECT`、`WHERE`、`FROM` 等 SQL 子句中。如果需要在 SQL 中调用可复用的逻辑，应使用存储函数（`CREATE FUNCTION`），函数可以在 SQL 表达式中调用。

---

## 注意事项

- 调用 OUT 或 INOUT 参数的存储过程时，必须传用户变量（`@var`），不能传字面量。`CALL sp_count(5)` 其中第二个参数是 OUT 参数的话会报错，需改为 `CALL sp_count(@result)`。
- MySQL 不支持存储过程的命名参数传递（如 `sp_name(param_name => value)`），参数只能按位置顺序传递。

---

## 总结

`CALL sp_name([params])` 执行存储过程，支持传入字面量（IN 参数）和用户变量（OUT/INOUT 参数）。存储过程可以返回结果集（通过内部 SELECT）和标量值（通过 OUT 参数）。可以在存储过程内嵌套调用其他存储过程。OUT 参数值通过调用后读取用户变量获得。
