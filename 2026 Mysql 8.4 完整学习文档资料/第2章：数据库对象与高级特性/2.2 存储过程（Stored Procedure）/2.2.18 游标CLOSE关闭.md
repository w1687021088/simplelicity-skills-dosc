# 游标 CLOSE 关闭

`CLOSE cursor_name` 关闭一个已打开的游标，释放其占用的内存和相关资源。游标使用完毕后应显式关闭，养成良好的资源管理习惯。即使不显式关闭，存储过程结束时 MySQL 也会自动关闭所有未关闭的游标。

---

## 语法

```sql
CLOSE cursor_name;
```

---

## 基本示例

```sql
DELIMITER //

CREATE PROCEDURE sp_close_demo()
BEGIN
    DECLARE v_id    INT;
    DECLARE v_done  TINYINT DEFAULT FALSE;
    DECLARE v_count INT DEFAULT 0;
    
    DECLARE user_cur CURSOR FOR
        SELECT id FROM users WHERE is_active = 1;
    
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_done = TRUE;
    
    -- 打开游标
    OPEN user_cur;
    
    count_loop: LOOP
        FETCH user_cur INTO v_id;
        IF v_done THEN LEAVE count_loop; END IF;
        SET v_count = v_count + 1;
    END LOOP count_loop;
    
    -- 关闭游标（释放资源）
    CLOSE user_cur;
    
    SELECT v_count AS active_user_count;
END //

DELIMITER ;
```

## CLOSE 后重新打开（游标重用）

```sql
DELIMITER //

CREATE PROCEDURE sp_cursor_reuse()
BEGIN
    DECLARE v_id   INT;
    DECLARE v_done TINYINT DEFAULT FALSE;
    
    DECLARE cur CURSOR FOR
        SELECT id FROM users WHERE is_active = 1 ORDER BY id LIMIT 3;
    
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_done = TRUE;
    
    -- 第一次遍历
    OPEN cur;
    loop1: LOOP
        FETCH cur INTO v_id;
        IF v_done THEN LEAVE loop1; END IF;
        SELECT CONCAT('第一次：id = ', v_id) AS info;
    END LOOP loop1;
    CLOSE cur;
    
    -- 重置标志位（这一步很关键！）
    SET v_done = FALSE;
    
    -- 第二次遍历（从头开始）
    OPEN cur;
    loop2: LOOP
        FETCH cur INTO v_id;
        IF v_done THEN LEAVE loop2; END IF;
        SELECT CONCAT('第二次：id = ', v_id) AS info;
    END LOOP loop2;
    CLOSE cur;
END //

DELIMITER ;
```

## 关闭未打开的游标

```sql
DELIMITER //

CREATE PROCEDURE sp_close_not_open()
BEGIN
    DECLARE cur CURSOR FOR SELECT id FROM users;
    
    -- 不 OPEN，直接 CLOSE
    CLOSE cur;
    -- ERROR 1326 (24000): Cursor is not open
    -- 关闭一个未打开的游标会报错
END //

DELIMITER ;
```

## 游标完整生命周期对照

```sql
DELIMITER //

CREATE PROCEDURE sp_cursor_full_lifecycle()
BEGIN
    DECLARE v_id   INT;
    DECLARE v_name VARCHAR(100);
    DECLARE v_done TINYINT DEFAULT FALSE;
    
    -- 1. 声明：定义游标（不执行查询）
    DECLARE my_cur CURSOR FOR
        SELECT id, username FROM users ORDER BY id LIMIT 5;
    
    -- 2. 声明处理程序
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_done = TRUE;
    
    -- 3. OPEN：执行 SELECT，游标就绪
    OPEN my_cur;
    
    -- 4. FETCH 循环：逐行读取
    fetch_loop: LOOP
        FETCH my_cur INTO v_id, v_name;
        IF v_done THEN LEAVE fetch_loop; END IF;
        SELECT v_id, v_name;
    END LOOP fetch_loop;
    
    -- 5. CLOSE：释放游标资源
    CLOSE my_cur;
    
    -- 可选：重用游标
    -- SET v_done = FALSE;
    -- OPEN my_cur;  再次使用...
    -- CLOSE my_cur;
END //

DELIMITER ;
```

## 适用场景

- **所有使用游标的存储过程结束前**：游标使用完毕后应立即 CLOSE，而不是等过程结束时自动关闭
- **游标重用**：CLOSE 后重置标志位，再次 OPEN 可以从头重新遍历同一数据集
- **提前退出时**：使用 LEAVE 提前退出循环后，仍需 CLOSE 游标，避免资源泄漏

---

## 常见问题

**如果不 CLOSE，会有什么影响？**

存储过程执行结束时，MySQL 会自动关闭该过程内所有未关闭的游标，通常不会造成资源永久泄漏。但在长时间运行的存储过程中，不及时关闭不再需要的游标会持续占用内存（游标数据集保持在内存中），可能影响服务器性能。

---

## 注意事项

- CLOSE 后若要重新使用游标，必须重置 NOT FOUND 处理程序中设置的标志变量（`SET v_done = FALSE`），否则游标虽已重新打开，但第一次 FETCH 就会因标志为 TRUE 而立即退出循环。
- 对同一个游标连续两次 CLOSE（不中间 OPEN）会报错 `ERROR 1326: Cursor is not open`，CLOSE 前应确认游标处于打开状态。

---

## 总结

`CLOSE cursor_name` 关闭已打开的游标并释放其资源。游标使用完毕后应显式 CLOSE，即使 MySQL 在过程结束时会自动关闭。CLOSE 后若要重用游标，先重置标志变量再 OPEN，游标会重新从数据集第一行开始。关闭未打开的游标会报错，需确保游标处于打开状态再 CLOSE。
