# LOOP 与 LEAVE 退出循环

`LOOP` 是 MySQL 存储过程中最基础的循环结构，没有内置的退出条件，依靠 `LEAVE` 语句手动退出。`LEAVE` 可以跳出任何有标签的语句块（LOOP、WHILE、REPEAT，甚至 BEGIN...END 块）。这种组合提供了最灵活的循环控制。

---

## 语法

```sql
-- LOOP（无退出条件，需要 LEAVE 手动退出）
[label:] LOOP
    statements;
    IF exit_condition THEN
        LEAVE label;
    END IF;
END LOOP [label];

-- LEAVE（跳出指定标签的块）
LEAVE label;
```

---

## 基本示例

```sql
DELIMITER //

-- LOOP + LEAVE 实现简单循环
CREATE PROCEDURE sp_loop_demo(IN p_max INT)
BEGIN
    DECLARE v_i   INT DEFAULT 1;
    DECLARE v_sum INT DEFAULT 0;
    
    my_loop: LOOP
        -- 退出条件：放在循环体开始处（等价于 WHILE 的前置检查）
        IF v_i > p_max THEN
            LEAVE my_loop;
        END IF;
        
        SET v_sum = v_sum + v_i;
        SET v_i   = v_i + 1;
    END LOOP my_loop;
    
    SELECT p_max AS max_val, v_sum AS total;
END //

DELIMITER ;

CALL sp_loop_demo(10);  -- total = 55
```

## LEAVE 退出外层循环（嵌套循环）

```sql
DELIMITER //

-- 嵌套循环中，LEAVE 只退出指定标签的循环
CREATE PROCEDURE sp_nested_loop()
BEGIN
    DECLARE v_i INT DEFAULT 1;
    DECLARE v_j INT DEFAULT 1;
    
    outer_loop: LOOP
        SET v_j = 1;
        
        inner_loop: LOOP
            IF v_j > 3 THEN
                LEAVE inner_loop;   -- 只退出内层循环
            END IF;
            
            SELECT CONCAT('i=', v_i, ', j=', v_j) AS pair;
            
            -- 当 i=2, j=2 时，提前退出整个嵌套循环
            IF v_i = 2 AND v_j = 2 THEN
                LEAVE outer_loop;   -- 退出外层循环（整个循环结束）
            END IF;
            
            SET v_j = v_j + 1;
        END LOOP inner_loop;
        
        SET v_i = v_i + 1;
        IF v_i > 3 THEN
            LEAVE outer_loop;
        END IF;
    END LOOP outer_loop;
END //

DELIMITER ;
```

## LEAVE 退出 BEGIN...END 块（过程提前返回）

```sql
DELIMITER //

-- LEAVE 可以用于提前退出 BEGIN...END 块（类似其他语言的 return）
CREATE PROCEDURE sp_early_exit(IN p_user_id INT)
proc_body: BEGIN  -- 给 BEGIN...END 块加标签
    DECLARE v_is_active TINYINT;
    
    SELECT is_active INTO v_is_active FROM users WHERE id = p_user_id;
    
    -- 前置检查：用户不活跃则提前退出
    IF v_is_active = 0 THEN
        SELECT '用户已被禁用' AS message;
        LEAVE proc_body;   -- 相当于 return，后续代码不执行
    END IF;
    
    -- 继续处理活跃用户的逻辑
    UPDATE users SET last_login_at = NOW() WHERE id = p_user_id;
    SELECT '登录成功' AS message;
END proc_body //

DELIMITER ;
```

## LOOP vs WHILE vs REPEAT 选择

```sql
-- LOOP + LEAVE：最灵活，退出条件可以放在循环体任意位置
my_loop: LOOP
    -- 可以在多个地方 LEAVE（多出口）
    IF condition1 THEN LEAVE my_loop; END IF;
    -- 执行语句...
    IF condition2 THEN LEAVE my_loop; END IF;
END LOOP;

-- WHILE：退出条件只在循环开始处（单出口）
WHILE condition DO ... END WHILE;

-- REPEAT：退出条件只在循环结束处（单出口）
REPEAT ... UNTIL condition END REPEAT;
```

---

## 适用场景

- **多出口循环**：循环体中多个位置可能触发退出条件（用 LOOP + 多个 LEAVE）
- **嵌套循环的跨层退出**：内层循环满足条件时直接退出外层循环
- **存储过程的提前返回**：通过给 BEGIN 块加标签并 LEAVE 实现提前退出（MySQL 没有 RETURN 语句用于过程）
- **游标循环**：游标遍历数据时，LOOP + LEAVE 是最常见的模式

---

## 常见问题

**MySQL 存储过程可以用 RETURN 提前返回吗？**

`RETURN` 只用于存储函数（FUNCTION），在存储过程（PROCEDURE）中不能使用 RETURN 直接返回（会语法错误）。存储过程提前退出的方式是给最外层的 `BEGIN...END` 块加标签，然后 `LEAVE label_name`。

---

## 注意事项

- `LEAVE` 后必须跟标签名，标签名是在 `LOOP`、`WHILE`、`REPEAT` 或 `BEGIN` 关键字前定义的（如 `my_loop: LOOP`）。没有标签的循环无法被 LEAVE 点名退出。
- 没有 `LEAVE` 的 `LOOP` 是无限循环，会导致连接永久挂起，必须确保循环体内有明确的退出路径。

---

## 总结

`LOOP ... END LOOP` 是无条件循环，必须通过 `LEAVE label` 手动退出。LEAVE 指定标签可以精确退出嵌套循环中的任意层，也可以退出 BEGIN...END 块（实现存储过程的提前返回）。LOOP 比 WHILE/REPEAT 更灵活（支持多出口），适用于游标遍历、嵌套循环跨层退出等场景。所有 LOOP 都必须有标签并至少有一条 LEAVE 退出路径，否则形成无限循环。
