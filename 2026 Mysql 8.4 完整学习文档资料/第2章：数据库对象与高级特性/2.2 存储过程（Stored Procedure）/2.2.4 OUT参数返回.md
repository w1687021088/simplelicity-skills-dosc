# OUT 参数返回

`OUT` 参数是存储过程的输出参数，调用者传入一个变量，存储过程在执行过程中将值写入该参数，执行完成后调用者可以读取到写入的值。`OUT` 参数相当于按引用传递（pass by reference）的输出方向，调用者传入的初始值在过程内部不可见（初始值为 NULL）。

---

## 语法

```sql
CREATE PROCEDURE sp_name(OUT param_name data_type)
BEGIN
    -- 通过 SELECT INTO 或 SET 将值赋给 OUT 参数
    SET param_name = some_value;
    -- 或
    SELECT some_col INTO param_name FROM some_table WHERE ...;
END;
```

---

## 基本示例

```sql
DELIMITER //

-- 返回用户总数
CREATE PROCEDURE sp_count_users(OUT p_count INT)
BEGIN
    SELECT COUNT(*) INTO p_count FROM users WHERE is_active = 1;
END //

-- 返回指定用户的邮箱
CREATE PROCEDURE sp_get_user_email(
    IN  p_user_id INT,
    OUT p_email   VARCHAR(255)
)
BEGIN
    SELECT email INTO p_email FROM users WHERE id = p_user_id;
    -- 如果没有匹配行，p_email 保持 NULL
END //

DELIMITER ;

-- 调用：传入用户变量接收 OUT 参数的值
CALL sp_count_users(@total);
SELECT @total;           -- 查看返回的值，例如：125

CALL sp_get_user_email(5, @email);
SELECT @email;           -- 例如：alice@example.com
```

## OUT 参数的初始值问题

```sql
DELIMITER //

CREATE PROCEDURE sp_demo_out(OUT p_val INT)
BEGIN
    -- OUT 参数在过程内的初始值是 NULL（不是调用者传入的值）
    SELECT p_val AS initial_value;  -- 显示 NULL
    SET p_val = 42;
    SELECT p_val AS final_value;    -- 显示 42
END //

DELIMITER ;

SET @my_var = 100;
CALL sp_demo_out(@my_var);
SELECT @my_var;  -- 42（被过程的 SET 覆盖）
-- OUT 参数：进入时看不到调用者的值（100 不可见），出来时带走过程设置的值（42）
```

## 多个 OUT 参数

```sql
DELIMITER //

CREATE PROCEDURE sp_order_stats(
    IN  p_user_id    INT,
    OUT p_order_cnt  INT,
    OUT p_total_amt  DECIMAL(12,2),
    OUT p_last_order DATE
)
BEGIN
    SELECT 
        COUNT(*),
        COALESCE(SUM(amount), 0),
        DATE(MAX(created_at))
    INTO p_order_cnt, p_total_amt, p_last_order
    FROM orders
    WHERE user_id = p_user_id AND status = 2;
END //

DELIMITER ;

-- 调用
CALL sp_order_stats(5, @cnt, @total, @last);
SELECT @cnt AS order_count, @total AS total_amount, @last AS last_order_date;
-- 一次调用获取三个统计值
```

## OUT 参数与结果集的对比

```sql
-- 方式1：OUT 参数（适合返回少量标量值）
CALL sp_count_users(@count);
SELECT @count;

-- 方式2：结果集（适合返回行列数据）
CREATE PROCEDURE sp_get_all_users()
BEGIN
    SELECT id, username, email FROM users;
END;
CALL sp_get_all_users();

-- 选择依据：
-- 标量结果（一个数字、一个字符串）→ OUT 参数，或 SELECT 列
-- 多行多列数据 → SELECT 结果集（不用 OUT）
-- 混合：可以同时使用 OUT 参数 + SELECT 结果集
```

---

## 适用场景

- **返回操作结果**：存储过程执行 INSERT/UPDATE/DELETE 后，通过 OUT 参数返回受影响行数或新增 ID
- **返回统计值**：计算某用户的订单总数、总金额等，通过 OUT 参数而非结果集返回
- **错误码传递**：在不使用异常处理的场景，通过 OUT 参数传回操作是否成功（0=成功，非0=失败）
- **批量获取标量**：一次调用通过多个 OUT 参数同时获取多个统计指标

---

## 常见问题

**调用存储过程时必须传用户变量（@var）吗？**

OUT 和 INOUT 参数必须传**变量**（以 `@` 开头的用户变量或存储过程/函数的局部变量），不能传字面量。`CALL sp_count_users(100)` 会报错，因为 `100` 是字面量，无法被写入。必须先声明变量：`CALL sp_count_users(@count)`。

---

## 注意事项

- `OUT` 参数进入存储过程时其值被 MySQL 重置为 NULL，即使调用者传入的变量有值。如果需要在过程内既读调用者的值，又写回，应使用 `INOUT` 参数。
- 如果存储过程因异常提前退出，OUT 参数可能没有被赋值，调用者读到的是 NULL，调用前应初始化变量并在调用后检查 NULL。

---

## 总结

`OUT` 参数是存储过程的输出参数，用于将过程内计算的值传回调用者。调用时传入用户变量（`@var`），过程执行完成后从该变量读取返回值。OUT 参数进入过程时初始值为 NULL（不继承调用者变量的值）。适合返回标量计算结果、操作状态码等少量标量数据。多个 OUT 参数可以在一次调用中返回多个值。
