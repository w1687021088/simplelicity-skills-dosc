# IF ... THEN ... ELSE 条件控制

`IF ... THEN ... ELSEIF ... ELSE ... END IF` 是存储过程中的基本条件控制结构，根据布尔表达式的真假执行不同的语句块。这里的 IF 是流程控制语句，与 `IF()` 函数不同。

---

## 语法

```sql
IF condition THEN
    statements;
[ELSEIF condition THEN
    statements;]
...
[ELSE
    statements;]
END IF;
```

---

## 基本示例

```sql
DELIMITER //

-- 简单的 IF...THEN...ELSE
CREATE PROCEDURE sp_check_age(IN p_age INT)
BEGIN
    IF p_age < 0 THEN
        SELECT '年龄不合法' AS result;
    ELSEIF p_age < 18 THEN
        SELECT '未成年' AS result;
    ELSEIF p_age < 60 THEN
        SELECT '成年人' AS result;
    ELSE
        SELECT '老年人' AS result;
    END IF;
END //

DELIMITER ;

CALL sp_check_age(25);   -- 成年人
CALL sp_check_age(15);   -- 未成年
CALL sp_check_age(-1);   -- 年龄不合法
```

## 在业务逻辑中使用

```sql
DELIMITER //

CREATE PROCEDURE sp_process_order(
    IN  p_order_id INT,
    OUT p_result   VARCHAR(100)
)
BEGIN
    DECLARE v_status    INT;
    DECLARE v_amount    DECIMAL(10,2);
    DECLARE v_user_id   INT;
    
    SELECT status, amount, user_id
    INTO v_status, v_amount, v_user_id
    FROM orders WHERE id = p_order_id;
    
    IF v_status IS NULL THEN
        SET p_result = '订单不存在';
    ELSEIF v_status != 1 THEN
        SET p_result = CONCAT('订单状态异常，当前状态：', v_status);
    ELSEIF v_amount <= 0 THEN
        SET p_result = '订单金额无效';
    ELSE
        -- 正常处理
        UPDATE orders SET status = 2, processed_at = NOW() WHERE id = p_order_id;
        UPDATE users SET order_count = order_count + 1 WHERE id = v_user_id;
        INSERT INTO order_logs(order_id, action, created_at)
        VALUES (p_order_id, 'confirmed', NOW());
        SET p_result = '处理成功';
    END IF;
END //

DELIMITER ;

CALL sp_process_order(100, @msg);
SELECT @msg;
```

## 嵌套 IF

```sql
DELIMITER //

CREATE PROCEDURE sp_discount_calc(
    IN  p_user_id    INT,
    IN  p_amount     DECIMAL(10,2),
    OUT p_discount   DECIMAL(5,2)
)
BEGIN
    DECLARE v_is_vip      TINYINT;
    DECLARE v_order_count INT;
    
    SELECT is_vip, order_count INTO v_is_vip, v_order_count
    FROM users WHERE id = p_user_id;
    
    -- 外层：判断是否是VIP
    IF v_is_vip = 1 THEN
        -- 内层：VIP用户按订单数量进一步区分折扣
        IF v_order_count > 100 THEN
            SET p_discount = 0.75;   -- 75折
        ELSEIF v_order_count > 50 THEN
            SET p_discount = 0.80;   -- 80折
        ELSE
            SET p_discount = 0.85;   -- 85折
        END IF;
    ELSE
        IF p_amount > 500 THEN
            SET p_discount = 0.95;   -- 满500享95折
        ELSE
            SET p_discount = 1.00;   -- 无折扣
        END IF;
    END IF;
END //

DELIMITER ;
```

## IF 流程控制语句 vs IF() 函数

```sql
-- IF 流程控制语句（只能在存储程序中使用，执行多条语句）
IF condition THEN
    statement1;
    statement2;
END IF;

-- IF() 函数（可以在任何 SQL 表达式中使用，只能返回单个值）
SELECT IF(score >= 60, '及格', '不及格') AS grade FROM students;

-- 在 SET 语句中用 IF() 函数（不是 IF 流程控制）
SET v_grade = IF(p_score >= 60, '及格', '不及格');
```

## 适用场景

- **参数有效性验证**：在执行核心逻辑前检查参数是否合法（NULL 检查、范围检查）
- **多步骤业务分支**：根据当前状态或条件执行不同的业务逻辑
- **错误处理与降级**：查询到特殊情况时走不同的处理路径

---

## 常见问题

**ELSEIF 和 ELSE IF（加空格）有区别吗？**

在 MySQL 存储过程中，`ELSEIF`（一个词）是正确的关键字。`ELSE IF`（两个词）是 `ELSE` 后面嵌套一个独立的 `IF` 块，需要额外的 `END IF` 来关闭内层 IF，写法不同且更复杂。应使用 `ELSEIF`（无空格）。

---

## 注意事项

- `IF` 流程控制语句必须以 `END IF` 结束（不能省略），`ELSE` 和 `ELSEIF` 子句都是可选的，但 `END IF` 是必须的。
- NULL 值的比较需要特别注意：`IF v_val = NULL` 永远不成立（NULL 不等于任何值），判断 NULL 应使用 `IF v_val IS NULL`。

---

## 总结

`IF condition THEN ... [ELSEIF condition THEN ...] [ELSE ...] END IF` 是存储过程中的多路分支控制语句。支持任意数量的 `ELSEIF` 子句，顺序匹配，找到第一个 TRUE 就执行对应块并跳过其他分支。与 `IF()` 函数不同，IF 流程控制语句可以在 THEN 块中执行多条语句。判断 NULL 必须用 `IS NULL` 而不是 `= NULL`。
