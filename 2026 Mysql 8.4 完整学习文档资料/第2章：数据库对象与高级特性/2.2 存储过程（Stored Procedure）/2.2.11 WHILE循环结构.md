# WHILE 循环结构

`WHILE` 是存储过程中最常用的循环结构，在每次迭代前检查条件，条件为 TRUE 则执行循环体，条件为 FALSE 则退出循环。属于"先检查后执行"的前置条件循环。

---

## 语法

```sql
[label:] WHILE condition DO
    statements;
END WHILE [label];
```

- `label`：可选的循环标签，`LEAVE label` 可提前退出，`ITERATE label` 可跳过当次剩余执行进入下一次迭代
- `condition`：布尔表达式，为 TRUE 时继续循环

---

## 基本示例

```sql
DELIMITER //

-- 简单计数循环
CREATE PROCEDURE sp_count_up(IN p_max INT)
BEGIN
    DECLARE v_i INT DEFAULT 1;
    DECLARE v_sum INT DEFAULT 0;
    
    WHILE v_i <= p_max DO
        SET v_sum = v_sum + v_i;
        SET v_i = v_i + 1;
    END WHILE;
    
    SELECT p_max AS count_to, v_sum AS total;
END //

DELIMITER ;

CALL sp_count_up(10);  -- sum = 55
```

## 批量处理数据

```sql
DELIMITER //

-- 批量生成测试用户
CREATE PROCEDURE sp_generate_test_users(IN p_count INT)
BEGIN
    DECLARE v_i INT DEFAULT 1;
    
    WHILE v_i <= p_count DO
        INSERT INTO users (username, email, is_active, created_at)
        VALUES (
            CONCAT('test_user_', v_i),
            CONCAT('test', v_i, '@example.com'),
            1,
            NOW() - INTERVAL FLOOR(RAND() * 365) DAY
        );
        SET v_i = v_i + 1;
    END WHILE;
    
    SELECT CONCAT('生成了 ', p_count, ' 个测试用户') AS result;
END //

DELIMITER ;

CALL sp_generate_test_users(100);
```

## 带 LEAVE 的提前退出

```sql
DELIMITER //

-- 找到第一个满足条件的值并提前退出
CREATE PROCEDURE sp_find_first(IN p_target INT, OUT p_found TINYINT)
BEGIN
    DECLARE v_i     INT DEFAULT 1;
    DECLARE v_val   INT;
    SET p_found = 0;
    
    outer_loop: WHILE v_i <= 100 DO
        -- 模拟某种计算
        SET v_val = v_i * v_i;
        
        IF v_val = p_target THEN
            SET p_found = 1;
            LEAVE outer_loop;  -- 找到后立即退出循环
        END IF;
        
        SET v_i = v_i + 1;
    END WHILE outer_loop;
    
    IF p_found = 1 THEN
        SELECT CONCAT('找到：v_i = ', v_i, '，v_val = ', v_val) AS result;
    ELSE
        SELECT '未找到' AS result;
    END IF;
END //

DELIMITER ;

CALL sp_find_first(49, @found);  -- 找到 v_i=7, 7*7=49
```

## 分批处理大数据（防止长事务）

```sql
DELIMITER //

-- 分批删除过期数据（每批 1000 条，避免大事务锁表）
CREATE PROCEDURE sp_batch_delete_expired()
BEGIN
    DECLARE v_affected INT DEFAULT 1;
    DECLARE v_total    INT DEFAULT 0;
    
    WHILE v_affected > 0 DO
        DELETE FROM session_logs
        WHERE expired_at < NOW() - INTERVAL 30 DAY
        LIMIT 1000;
        
        SET v_affected = ROW_COUNT();
        SET v_total = v_total + v_affected;
        
        -- 短暂休眠，减少对主库的压力
        DO SLEEP(0.1);
    END WHILE;
    
    SELECT v_total AS total_deleted;
END //

DELIMITER ;
```

## 适用场景

- **批量数据处理**：生成测试数据、批量更新、分批删除
- **数值计算**：累加、累乘、斐波那契等数学计算
- **数据迁移**：分批读取旧数据写入新结构
- **重试逻辑**：某个操作失败时循环重试（有最大重试次数限制）

---

## 常见问题

**WHILE 循环和 REPEAT 循环有什么区别？**

WHILE 是前置条件循环（先检查后执行），条件一开始就不满足的话一次都不执行。REPEAT 是后置条件循环（先执行后检查），循环体至少执行一次。

---

## 注意事项

- 循环变量的递增（如 `SET v_i = v_i + 1`）必须明确写在循环体中，MySQL 的 WHILE 没有自增语法。忘记递增会导致无限循环，锁死连接。
- 对大数据量的循环操作，应当考虑分批提交事务（每 N 次提交一次），避免长事务持有锁太久影响并发。

---

## 总结

`WHILE condition DO ... END WHILE` 是先检查条件再执行的前置循环。条件为 FALSE 时一次不执行。配合 `LEAVE label` 可以提前退出，配合 `ITERATE label` 可以跳过当次剩余语句进入下一轮。使用时务必确保循环变量有正确的递增/递减，避免死循环。
