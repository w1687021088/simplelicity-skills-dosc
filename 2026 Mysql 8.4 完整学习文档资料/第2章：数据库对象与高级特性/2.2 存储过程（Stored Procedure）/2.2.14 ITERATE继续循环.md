# ITERATE 继续循环

`ITERATE` 用于跳过当次循环体中 `ITERATE` 之后的剩余语句，直接进入下一次迭代（类似其他编程语言中的 `continue`）。`ITERATE` 只能用于循环语句（LOOP、WHILE、REPEAT）中，且必须指定循环标签。

---

## 语法

```sql
ITERATE label;
```

- `label`：要继续（跳过本次剩余语句，进入下次迭代）的循环标签
- 与 `LEAVE label`（退出循环）的区别：ITERATE 是继续下次，LEAVE 是完全退出

---

## 基本示例

```sql
DELIMITER //

-- 只累加奇数（偶数跳过）
CREATE PROCEDURE sp_sum_odd(IN p_max INT)
BEGIN
    DECLARE v_i   INT DEFAULT 0;
    DECLARE v_sum INT DEFAULT 0;
    
    my_loop: WHILE v_i < p_max DO
        SET v_i = v_i + 1;
        
        -- 偶数：跳过累加，继续下一次迭代
        IF MOD(v_i, 2) = 0 THEN
            ITERATE my_loop;   -- 跳过 SET v_sum = v_sum + v_i
        END IF;
        
        -- 只有奇数才执行到这里
        SET v_sum = v_sum + v_i;
    END WHILE my_loop;
    
    SELECT p_max AS range, v_sum AS odd_sum;
END //

DELIMITER ;

CALL sp_sum_odd(10);  -- odd_sum = 25 (1+3+5+7+9)
```

## 在 LOOP 中使用 ITERATE

```sql
DELIMITER //

-- 处理数据时跳过已处理的记录
CREATE PROCEDURE sp_process_pending_tasks()
BEGIN
    DECLARE v_task_id  INT;
    DECLARE v_status   TINYINT;
    DECLARE v_done     TINYINT DEFAULT FALSE;
    DECLARE v_processed INT DEFAULT 0;
    
    DECLARE task_cursor CURSOR FOR
        SELECT id, status FROM tasks WHERE status IN (0, 1) LIMIT 100;
    DECLARE CONTINUE HANDLER FOR NOT FOUND SET v_done = TRUE;
    
    OPEN task_cursor;
    
    task_loop: LOOP
        FETCH task_cursor INTO v_task_id, v_status;
        IF v_done THEN
            LEAVE task_loop;
        END IF;
        
        -- 跳过状态为 1（处理中）的任务
        IF v_status = 1 THEN
            ITERATE task_loop;   -- 跳过，继续读下一条
        END IF;
        
        -- 只处理 status = 0（待处理）的任务
        UPDATE tasks SET status = 1, started_at = NOW() WHERE id = v_task_id;
        SET v_processed = v_processed + 1;
        
    END LOOP task_loop;
    
    CLOSE task_cursor;
    SELECT v_processed AS processed_count;
END //

DELIMITER ;
```

## ITERATE vs LEAVE vs 不使用

```sql
DELIMITER //

CREATE PROCEDURE sp_loop_control_demo()
BEGIN
    DECLARE v_i INT DEFAULT 0;
    
    my_loop: WHILE v_i < 5 DO
        SET v_i = v_i + 1;
        
        IF v_i = 2 THEN
            ITERATE my_loop;  -- 跳过 v_i=2 的后续语句，继续循环
        END IF;
        
        IF v_i = 4 THEN
            LEAVE my_loop;    -- 到 v_i=4 时退出整个循环（v_i=5 不会执行）
        END IF;
        
        SELECT v_i AS processed_value;
    END WHILE my_loop;
    -- 输出：1, 3（2 被跳过，4 触发退出，5 不执行）
END //

DELIMITER ;
```

---

## ITERATE 在三种循环中的行为

| 循环类型 | ITERATE 效果 |
|---------|-------------|
| WHILE | 跳转到条件检查处，重新检查 WHILE 条件 |
| REPEAT | 跳转到 UNTIL 条件检查处，重新检查退出条件 |
| LOOP | 跳转到循环体开始处，重新执行下一次迭代 |

---

## 适用场景

- **过滤不需要处理的记录**：游标遍历时，满足跳过条件的记录用 ITERATE 忽略
- **条件累积**：只对满足特定条件的值做累加/统计（奇数、正数等）
- **多条件分支中的提前继续**：某个条件只需要简单记录日志然后跳过，不做其他处理

---

## 常见问题

**ITERATE 能用于没有标签的循环吗？**

不能。`ITERATE` 必须后跟一个标签名，用于标识要继续的循环。没有标签的循环无法使用 ITERATE，因此在可能需要 ITERATE 的循环上必须定义标签（`my_loop: WHILE condition DO`）。

---

## 注意事项

- `ITERATE` 只对循环变量的推进有影响（会跳过 ITERATE 后的语句），但循环变量的递增如果在 ITERATE 之后，它也会被跳过，导致死循环。将循环变量递增放在 ITERATE 之前（如本页示例在 IF 判断前先 `SET v_i = v_i + 1`）是正确的做法。
- `ITERATE` 只能在循环语句（LOOP/WHILE/REPEAT）内使用，在 BEGIN...END 块或 IF 块中直接使用（不在循环内）会报语法错误。

---

## 总结

`ITERATE label` 跳过本次循环中 ITERATE 之后的剩余语句，直接进入下一次迭代（等同于其他语言的 `continue`）。必须指定循环标签。使用时注意循环变量的递增位置，确保在 ITERATE 之前完成递增，避免死循环。适用于游标遍历中跳过特定记录、条件累积计算等场景。
