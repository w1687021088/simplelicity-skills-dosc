# 局部变量声明 DECLARE

`DECLARE` 用于在存储过程或函数的 `BEGIN...END` 块中声明局部变量。局部变量只在声明它的 `BEGIN...END` 块内有效，与以 `@` 开头的用户变量不同，局部变量作用域严格限定在存储过程内部。

---

## 语法

```sql
DECLARE var_name [, var_name ...] type [DEFAULT value];
```

- `var_name`：变量名（不带 `@` 前缀）
- `type`：任何合法的 MySQL 数据类型
- `DEFAULT value`：可选的初始值，不指定时默认为 `NULL`
- `DECLARE` 语句必须位于 `BEGIN...END` 块的最顶部，在任何其他语句之前

---

## 基本示例

```sql
DELIMITER //

CREATE PROCEDURE sp_demo_declare()
BEGIN
    -- 必须在 BEGIN 后、其他语句前声明
    DECLARE v_count    INT          DEFAULT 0;
    DECLARE v_name     VARCHAR(100) DEFAULT '';
    DECLARE v_salary   DECIMAL(10,2);       -- 默认 NULL
    DECLARE v_date     DATE         DEFAULT CURDATE();
    DECLARE v_flag     TINYINT(1)   DEFAULT FALSE;
    
    -- 声明完后才能有其他语句
    SET v_count = 10;
    SET v_name  = 'MySQL 8.4';
    
    SELECT v_count, v_name, v_salary, v_date, v_flag;
END //

DELIMITER ;

CALL sp_demo_declare();
```

## 局部变量与用户变量的区别

```sql
-- 用户变量（@prefix）：会话级别，过程外也可见，用 SET @var = value 直接赋值
SET @user_var = 100;
SELECT @user_var;  -- 可以在过程外使用

-- 局部变量（DECLARE）：只在 BEGIN...END 块内有效，过程结束后消失
DELIMITER //
CREATE PROCEDURE sp_scope_demo()
BEGIN
    DECLARE v_local INT DEFAULT 0;
    SET v_local = 42;
    SELECT v_local;        -- 42（过程内可见）
    SET @user_var = v_local;  -- 可以把局部变量的值赋给用户变量传出
END //
DELIMITER ;

CALL sp_scope_demo();
SELECT @user_var;  -- 42（通过用户变量传出的值）
-- v_local 已经不存在了，直接 SELECT v_local 会报错
```

| 对比维度 | 局部变量（DECLARE）| 用户变量（@var）|
|---------|-----------------|--------------|
| 声明方式 | `DECLARE var type` | 无需声明，直接 SET |
| 作用域 | BEGIN...END 块内 | 当前会话（连接）|
| 类型 | 有明确类型 | 弱类型（动态）|
| 初始值 | DEFAULT 或 NULL | NULL（未赋值时）|
| 访问速度 | 稍快（强类型）| 稍慢 |
| 使用场景 | 存储过程/函数内部临时变量 | 过程间传递数据 |

## 声明位置的要求

```sql
DELIMITER //

CREATE PROCEDURE sp_declare_order()
BEGIN
    -- 正确：DECLARE 在 BEGIN 后所有语句的最前面
    DECLARE v_a INT DEFAULT 0;
    DECLARE v_b VARCHAR(50);
    
    -- 错误：不能在 SET 后面再 DECLARE（语法错误）
    -- SET v_a = 10;
    -- DECLARE v_c INT;  -- ERROR: DECLARE should be the first statement in a block
    
    SET v_a = 10;
    SET v_b = 'hello';
    SELECT v_a, v_b;
END //

DELIMITER ;
```

## 嵌套 BEGIN...END 块中的变量作用域

```sql
DELIMITER //

CREATE PROCEDURE sp_nested_scope()
BEGIN
    DECLARE v_outer INT DEFAULT 1;
    
    BEGIN
        DECLARE v_inner INT DEFAULT 100;  -- 只在这个内层块可见
        SET v_outer = v_inner + v_outer;  -- 内层可以访问外层变量
        SELECT v_inner, v_outer;          -- 101
    END;
    
    -- SELECT v_inner;  -- 错误：v_inner 在此已超出作用域
    SELECT v_outer;  -- 101（外层变量在整个外层块内有效）
END //

DELIMITER ;
```

## 适用场景

- **临时中间结果存储**：存储 `SELECT INTO` 查询的结果、计算的中间值
- **循环计数器**：`DECLARE v_counter INT DEFAULT 0;` 用于循环控制
- **游标相关变量**：声明用于接收游标 FETCH 结果的变量
- **条件判断标志**：`DECLARE v_done TINYINT DEFAULT FALSE;` 用于循环结束标志

---

## 常见问题

**局部变量和列名同名会怎样？**

在 SQL 语句中，当局部变量名与表的列名相同时，MySQL 优先将其识别为列名，而不是局部变量。为避免歧义，建议局部变量统一使用 `v_` 前缀（如 `v_user_id`），参数使用 `p_` 前缀，确保不与列名冲突。

---

## 注意事项

- `DECLARE` 必须是 `BEGIN...END` 块中的第一批语句，不能在 `IF`、`SET`、`SELECT` 等语句之后再声明。将 DECLARE 统一放到 BEGIN 后的顶部是强制规范。
- 同一 `BEGIN...END` 块中不能重复声明同名变量（重复声明会报语法错误）。如果需要在不同条件分支使用不同类型的临时变量，可以使用嵌套的 BEGIN...END 块。

---

## 总结

`DECLARE var_name type [DEFAULT value]` 在存储过程/函数的 BEGIN...END 块顶部声明局部变量。局部变量有明确类型，作用域严格限于声明它的 BEGIN...END 块内，与用户变量（@var）不同。`DECLARE` 必须在块内所有其他语句之前。命名建议统一使用 `v_` 前缀避免与列名和参数冲突。
