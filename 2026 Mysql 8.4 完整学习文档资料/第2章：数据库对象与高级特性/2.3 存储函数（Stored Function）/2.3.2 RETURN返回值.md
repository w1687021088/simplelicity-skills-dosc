# RETURN 返回值

`RETURN` 语句是存储函数中必须存在的语句，用于结束函数的执行并将一个值返回给调用者。函数中的所有执行路径都必须有 `RETURN`，否则没有 RETURN 的路径执行时会返回 NULL。`RETURN` 只能用于存储函数，不能用于存储过程（过程用 LEAVE 提前退出）。

---

## 语法

```sql
RETURN expr;
```

- `expr`：任何返回单个值的表达式，其类型必须与函数声明中的 `RETURNS type` 兼容

---

## 基本示例

```sql
DELIMITER //

-- 简单计算型函数
CREATE FUNCTION fn_circle_area(radius DOUBLE) RETURNS DOUBLE
DETERMINISTIC
BEGIN
    RETURN PI() * radius * radius;
END //

-- 字符串处理型函数
CREATE FUNCTION fn_first_word(p_str VARCHAR(255)) RETURNS VARCHAR(255)
DETERMINISTIC
BEGIN
    DECLARE v_pos INT;
    SET v_pos = LOCATE(' ', p_str);
    IF v_pos = 0 THEN
        RETURN p_str;          -- 没有空格，整个字符串就是第一个词
    ELSE
        RETURN LEFT(p_str, v_pos - 1);  -- 返回第一个空格前的部分
    END IF;
END //

DELIMITER ;

SELECT fn_circle_area(5.0);                    -- 78.53981...
SELECT fn_first_word('Hello World MySQL');     -- Hello
SELECT fn_first_word('OneWord');               -- OneWord
```

## 多路径都需要 RETURN

```sql
DELIMITER //

-- 所有 IF 分支都要有 RETURN
CREATE FUNCTION fn_grade(p_score INT) RETURNS VARCHAR(10)
DETERMINISTIC
BEGIN
    IF p_score IS NULL THEN
        RETURN 'N/A';          -- 分支1：NULL
    ELSEIF p_score >= 90 THEN
        RETURN 'A';            -- 分支2：优秀
    ELSEIF p_score >= 60 THEN
        RETURN 'B';            -- 分支3：及格
    ELSE
        RETURN 'C';            -- 分支4：不及格（所有路径都有 RETURN）
    END IF;
    -- 不需要最后再加 RETURN（IF 覆盖了所有情况）
END //

-- 危险写法：某条路径没有 RETURN（只有警告，不报错）
CREATE FUNCTION fn_bad_example(n INT) RETURNS INT
DETERMINISTIC
BEGIN
    IF n > 0 THEN
        RETURN n * 2;
    END IF;
    -- n <= 0 时没有 RETURN，MySQL 返回 NULL（发出 Warning）
END //

DELIMITER ;

SELECT fn_grade(85);     -- B
SELECT fn_grade(NULL);   -- N/A
SELECT fn_bad_example(-1);  -- NULL（带警告）
```

## RETURN 在查询函数中

```sql
DELIMITER //

CREATE FUNCTION fn_get_order_count(p_user_id INT) RETURNS INT
READS SQL DATA
BEGIN
    DECLARE v_count INT DEFAULT 0;
    
    SELECT COUNT(*) INTO v_count
    FROM orders
    WHERE user_id = p_user_id AND status = 2;
    
    RETURN v_count;   -- 返回查询结果
END //

-- 带早期返回（类似 guard clause）
CREATE FUNCTION fn_calc_discount(
    p_user_id INT,
    p_amount  DECIMAL(10,2)
) RETURNS DECIMAL(10,2)
READS SQL DATA
BEGIN
    DECLARE v_is_vip TINYINT;
    
    -- 金额无效：提前返回
    IF p_amount <= 0 THEN
        RETURN 0;
    END IF;
    
    SELECT is_vip INTO v_is_vip FROM users WHERE id = p_user_id;
    
    -- 用户不存在：提前返回
    IF v_is_vip IS NULL THEN
        RETURN p_amount;  -- 无折扣原价返回
    END IF;
    
    IF v_is_vip = 1 THEN
        RETURN p_amount * 0.85;  -- VIP 85折
    ELSE
        RETURN p_amount;         -- 普通用户原价
    END IF;
END //

DELIMITER ;
```

## RETURN 的类型自动转换

```sql
DELIMITER //

-- 函数声明 RETURNS INT，但 RETURN 了字符串
CREATE FUNCTION fn_type_coerce(n INT) RETURNS INT
DETERMINISTIC
BEGIN
    RETURN '42abc';   -- MySQL 自动截取数字部分，返回 42（带警告）
END //

-- 建议：RETURN 的类型与 RETURNS 声明一致，避免隐式转换
CREATE FUNCTION fn_type_safe(n INT) RETURNS INT
DETERMINISTIC
BEGIN
    RETURN CAST(n * 1.5 AS SIGNED);  -- 明确转换为整型
END //

DELIMITER ;
```

## 适用场景

- **计算函数**：纯数学计算（面积、折扣、评分）通过 RETURN 返回结果
- **条件映射**：状态码转文字、评级映射，多分支各自 RETURN 对应值
- **早期退出（guard clause）**：先检查无效输入，用 RETURN 提前返回默认值，减少嵌套深度

---

## 常见问题

**函数末尾没有 RETURN 会报错吗？**

不报错，但 MySQL 会发出警告，且该执行路径到达函数末尾时返回 NULL。这通常是逻辑 Bug——调用者拿到 NULL 而不是预期值。必须检查所有 IF 分支都有对应的 RETURN。

---

## 注意事项

- `RETURN` 后面的表达式会按照 `RETURNS type` 声明的类型进行隐式转换，类型不兼容时 MySQL 不报错而是静默转换（可能丢失数据），建议确保类型匹配。
- `RETURN` 只能在函数中使用。在存储过程中使用 `RETURN` 会报语法错误；存储过程的提前退出应使用 `LEAVE proc_label`。

---

## 总结

`RETURN expr` 结束函数执行并返回值，是存储函数区别于存储过程的核心语句。函数中所有可能的执行路径都必须有 RETURN，遗漏的路径会静默返回 NULL。可以在函数体任意位置使用 RETURN（实现早期退出模式）。返回值的类型应与 RETURNS 声明一致，避免隐式转换引起精度损失。
