# GROUP BY 分组聚合

`GROUP BY` 将查询结果按指定列（或表达式）进行分组，使聚合函数（`COUNT`、`SUM`、`AVG`、`MAX`、`MIN`）对每组数据分别计算，而不是对全部数据计算一个总值。它是数据统计和报表查询的核心语法。

---

## 语法

```sql
SELECT col1, AGG_FUNC(col2) [, ...]
FROM tbl_name
[WHERE condition]
GROUP BY col1 [, col2, ...]
[HAVING group_condition]
[ORDER BY ...]
[LIMIT n];
```

---

## 基本示例

```sql
-- 按部门统计员工数和平均薪资
SELECT dept_id,
       COUNT(*) AS 员工数,
       AVG(salary) AS 平均薪资,
       MAX(salary) AS 最高薪资,
       MIN(salary) AS 最低薪资,
       SUM(salary) AS 薪资总和
FROM employees
GROUP BY dept_id
ORDER BY 平均薪资 DESC;

-- 按日期分组统计订单金额
SELECT DATE(created_at) AS 日期,
       COUNT(*) AS 订单数,
       SUM(amount) AS 当日销售额
FROM orders
WHERE status = 2   -- 已完成
GROUP BY DATE(created_at)
ORDER BY 日期;

-- 多列分组
SELECT dept_id, status,
       COUNT(*) AS 数量
FROM employees
GROUP BY dept_id, status
ORDER BY dept_id, status;
```

## 聚合函数详解

```sql
-- COUNT 的三种形式
SELECT 
    COUNT(*) AS 总行数,        -- 计所有行（包括 NULL）
    COUNT(phone) AS 有手机号数, -- 只计非 NULL 的 phone 行
    COUNT(DISTINCT city) AS 城市数  -- 不重复的 city 值的数量
FROM users;

-- SUM、AVG 忽略 NULL
SELECT AVG(score) FROM users;  -- 只对非 NULL 的 score 求均值
-- 如果要把 NULL 算作 0：AVG(COALESCE(score, 0))

-- GROUP_CONCAT：将组内多行值拼接为字符串
SELECT dept_id,
       GROUP_CONCAT(name ORDER BY name SEPARATOR ', ') AS 员工名单
FROM employees
GROUP BY dept_id;
-- 技术部: 李四, 张三
-- 市场部: 王五
```

## GROUP BY 与 ONLY_FULL_GROUP_BY（SQL 模式）

```sql
-- MySQL 默认启用 ONLY_FULL_GROUP_BY 模式
-- 在此模式下，SELECT 中的非聚合列必须出现在 GROUP BY 中
SHOW VARIABLES LIKE 'sql_mode';
-- 包含 ONLY_FULL_GROUP_BY

-- 错误示例：name 不在 GROUP BY 中，也不是聚合函数
SELECT dept_id, name, AVG(salary) FROM employees GROUP BY dept_id;
-- ERROR 1055: 'employees.name' isn't in GROUP BY

-- 正确写法1：将 name 加入 GROUP BY
SELECT dept_id, name, salary FROM employees GROUP BY dept_id, name;

-- 正确写法2：用聚合函数包裹 name
SELECT dept_id, MIN(name) AS 代表员工, AVG(salary) AS 平均薪资
FROM employees GROUP BY dept_id;

-- 正确写法3：关闭 ONLY_FULL_GROUP_BY（不推荐生产使用）
SET sql_mode = REPLACE(@@sql_mode, 'ONLY_FULL_GROUP_BY', '');
```

## GROUP BY 与 ROLLUP（小计/总计）

```sql
-- WITH ROLLUP：自动生成各分组层次的小计和总计行
SELECT dept_id, status, COUNT(*) AS 数量
FROM employees
GROUP BY dept_id, status WITH ROLLUP;
-- 结果包含：
-- 各 (dept_id, status) 组合的行
-- 每个 dept_id 的小计行（status=NULL）
-- 全部数据的总计行（dept_id=NULL, status=NULL）

-- GROUPING() 函数区分 ROLLUP 生成的 NULL 和数据本身的 NULL
SELECT 
    GROUPING(dept_id) AS is_dept_rollup,
    dept_id,
    COUNT(*) AS cnt
FROM employees
GROUP BY dept_id WITH ROLLUP;
-- is_dept_rollup=1 表示该行是 ROLLUP 生成的汇总行
```

## 适用场景

- **数据统计报表**：按维度统计数量、金额、均值（日销售额、部门人数等）
- **数据质量检查**：`GROUP BY + HAVING COUNT(*) > 1` 找重复数据
- **标签聚合**：`GROUP_CONCAT` 将一对多关联数据合并为一列展示

---

## 常见问题

**GROUP BY 时 NULL 如何处理？**

NULL 值被单独归为一组，即所有 `NULL` 的行被分为同一组，可以对其做聚合计算。

---

## 注意事项

- `GROUP BY` 中的列应该有索引（特别是在大表上），可以避免创建临时表进行排序/哈希分组，大幅提升性能。
- `GROUP_CONCAT` 的默认最大长度是 1024 字节，如果分组内数据量大，可能被截断。调整：`SET SESSION group_concat_max_len = 65536`。

---

## 总结

`GROUP BY` 按指定列分组，配合聚合函数（COUNT、SUM、AVG、MAX、MIN、GROUP_CONCAT）对每组数据独立计算。MySQL 默认的 `ONLY_FULL_GROUP_BY` 模式要求 SELECT 中的非聚合列必须在 GROUP BY 中声明。`WITH ROLLUP` 可自动生成小计和总计行。GROUP BY 列有索引时性能最优。
