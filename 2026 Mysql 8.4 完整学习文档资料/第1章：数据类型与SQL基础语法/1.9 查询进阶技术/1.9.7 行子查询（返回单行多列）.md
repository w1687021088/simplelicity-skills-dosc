# 行子查询（返回单行多列）

行子查询是返回**单行多列**的子查询，其结果是一个行值，可以与表中的多列组合进行比较。MySQL 支持用行构造器（row constructor）`(col1, col2, ...)` 与行子查询的结果进行等值或比较操作。

---

## 语法

```sql
-- 行子查询与行构造器比较
SELECT col1, col2
FROM tbl_name
WHERE (col1, col2) = (SELECT col1, col2 FROM other_tbl WHERE condition);

-- 行子查询返回多行时会报错（同标量子查询）
-- 需确保子查询只返回一行
```

---

## 基本示例

```sql
-- 场景1：查找与指定员工薪资和部门都相同的其他员工
SELECT name, dept_id, salary
FROM employees
WHERE (dept_id, salary) = (
    SELECT dept_id, salary FROM employees WHERE name = '张三'
)
AND name != '张三';

-- 场景2：查找最新一笔订单的完整信息
-- （最新指 created_at 最大）
SELECT * FROM orders
WHERE (user_id, created_at) = (
    SELECT user_id, MAX(created_at) FROM orders WHERE user_id = 100
    GROUP BY user_id
);
-- 注意：这只适合某用户只有一笔最新订单的情况
-- 若需要返回多用户的最新订单，改用 JOIN + 派生表

-- 场景3：多列主键的查找
CREATE TABLE order_items (
    order_id   INT UNSIGNED NOT NULL,
    product_id INT UNSIGNED NOT NULL,
    qty        INT UNSIGNED NOT NULL,
    PRIMARY KEY (order_id, product_id)
);

-- 查找特定多列主键的行
SELECT qty FROM order_items
WHERE (order_id, product_id) = (1001, 5);
-- 等同于 WHERE order_id = 1001 AND product_id = 5
-- 但行构造器写法更简洁
```

## 行子查询与 IN 的结合（行值 IN 列表）

```sql
-- 行值 IN 列表（批量多列匹配）
SELECT name, dept_id, salary
FROM employees
WHERE (dept_id, salary) IN (
    (1, 15000),
    (2, 10000),
    (3, 8000)
);

-- 行值 IN 子查询（找出某些组合的行）
-- 查询与任意 VIP 用户拥有相同国家和城市的普通用户
SELECT u.id, u.username, u.country, u.city
FROM users u
WHERE (u.country, u.city) IN (
    SELECT country, city FROM vip_users
)
AND u.is_vip = 0;
```

---

## 与 IN 操作符对比

```sql
-- 单列 IN（最常见）
SELECT * FROM employees WHERE dept_id IN (1, 2, 3);

-- 多列 IN（行值 IN）
SELECT * FROM employees WHERE (dept_id, salary) IN ((1, 15000), (2, 10000));
-- 等价于：
SELECT * FROM employees
WHERE (dept_id = 1 AND salary = 15000)
   OR (dept_id = 2 AND salary = 10000);
```

## 行子查询与 JOIN 的对比

```sql
-- 行子查询方式（可读性强，适合简单逻辑）
SELECT * FROM orders
WHERE (user_id, amount) = (
    SELECT user_id, MAX(amount) FROM orders GROUP BY user_id ORDER BY MAX(amount) DESC LIMIT 1
);

-- JOIN 方式（通常更高效）
SELECT o.*
FROM orders o
INNER JOIN (
    SELECT user_id, MAX(amount) AS max_amount
    FROM orders
    GROUP BY user_id
    ORDER BY max_amount DESC
    LIMIT 1
) t ON o.user_id = t.user_id AND o.amount = t.max_amount;
```

---

## 适用场景

- **多列主键的精确查找**：`WHERE (pk1, pk2) = (val1, val2)`
- **多列组合条件匹配**：在 WHERE 中同时匹配多列的特定组合
- **IN 多列组合**：`WHERE (col1, col2) IN ((v1, v2), (v3, v4), ...)`

---

## 常见问题

**行子查询中 NULL 值如何处理？**

与单列一样，NULL 与任何值的等值比较结果为 NULL（非 TRUE），因此行子查询中如果有列返回 NULL，匹配可能失败。确保参与行比较的列都是非 NULL 的，或使用 `IS NOT DISTINCT FROM` 语义。

---

## 注意事项

- 行子查询要求子查询只返回**一行**，返回多行会报错 `Subquery returns more than 1 row`。需要通过 `LIMIT 1` 或聚合函数保证只返回一行。
- MySQL 对行值构造器的索引使用能力有限，`(col1, col2) = (val1, val2)` 在某些情况下无法有效使用联合索引（取决于版本和具体情况），可以改写为 `WHERE col1 = val1 AND col2 = val2` 显式写法。

---

## 总结

行子查询返回单行多列，配合行构造器 `(col1, col2)` 可以对多列进行组合等值比较。`IN` 操作符支持行值列表，实现多组多列条件的批量匹配。适合多列主键查找和多列组合匹配场景。子查询必须只返回一行，否则报错。
