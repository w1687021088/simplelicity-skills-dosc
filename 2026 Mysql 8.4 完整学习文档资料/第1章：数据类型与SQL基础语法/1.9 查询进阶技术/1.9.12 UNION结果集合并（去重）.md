# UNION 结果集合并（去重）

`UNION` 将两个或多个 SELECT 语句的结果集合并为一个结果集，并自动去除完全重复的行（所有列值都相同的行）。去重操作类似于对最终结果执行 `DISTINCT`，需要额外的排序或哈希计算，有一定性能开销。

---

## 语法

```sql
SELECT col1, col2 FROM tbl1
UNION
SELECT col1, col2 FROM tbl2
[ORDER BY ...]
[LIMIT n];
```

- 每个 SELECT 的**列数必须相同**
- 对应列的**数据类型应该兼容**
- 最终结果集的列名由**第一个 SELECT** 的列名决定
- `ORDER BY` 和 `LIMIT` 放在最后一个 SELECT 之后，作用于整个合并结果

---

## 基本示例

```sql
-- 合并两张表的查询结果（自动去重）
-- 假设 archived_orders 和 active_orders 有相同结构
SELECT id, user_id, amount FROM active_orders
UNION
SELECT id, user_id, amount FROM archived_orders
ORDER BY id;
-- 如果同一条订单在两张表都存在，只出现一次

-- 合并不同业务的用户 ID（去重后）
SELECT user_id FROM orders WHERE status = 2
UNION
SELECT user_id FROM reviews WHERE rating >= 4;
-- 下过订单或写过好评的用户 ID（每个 user_id 只出现一次）
```

---

## 三个及以上 SELECT 的合并

```sql
-- 任意多个 SELECT 可以用 UNION 连接
SELECT id, 'active' AS source FROM active_users
UNION
SELECT id, 'vip' AS source FROM vip_users
UNION
SELECT id, 'enterprise' AS source FROM enterprise_users
ORDER BY id;
-- 注意：UNION 自动去重，如果同一个 id 在多个查询中出现，只保留一条
-- 如果需要保留所有行（包括重复），使用 UNION ALL
```

---

## 对每个 SELECT 独立排序（子句顺序）

```sql
-- 整体 ORDER BY 和 LIMIT
SELECT id, amount FROM orders WHERE status = 1
UNION
SELECT id, amount FROM orders WHERE status = 2
ORDER BY amount DESC   -- 对合并后的全部结果排序
LIMIT 10;              -- 取前 10 条

-- 如果需要对每个部分单独 ORDER BY（然后合并），需要用括号包裹
(SELECT id, amount FROM orders WHERE status = 1 ORDER BY amount DESC LIMIT 5)
UNION
(SELECT id, amount FROM orders WHERE status = 2 ORDER BY amount DESC LIMIT 5);
-- 注意：括号内的 ORDER BY 仅在配合 LIMIT 时有意义
-- MySQL 可能忽略没有 LIMIT 的括号内 ORDER BY
```

---

## UNION 的去重机制

```sql
-- UNION 的去重基于所有列的组合
-- 如果两行所有列值都相同，只保留一行
SELECT 1, 'a'
UNION
SELECT 1, 'a'  -- 与第一行完全相同，被去重
UNION
SELECT 1, 'b'; -- 第三列不同，保留

-- 结果：
-- 1  a
-- 1  b

-- NULL 的处理：两个 NULL 视为相同（不同于普通比较中 NULL != NULL）
SELECT NULL UNION SELECT NULL;
-- 结果：只有一行 NULL（被去重）
```

## UNION 与 UNION ALL 的性能对比

```sql
-- UNION 去重需要内部排序或哈希，有额外开销
-- UNION ALL 不去重，直接合并，速度更快

-- 如果确定两个 SELECT 没有重复行（或不需要去重），始终用 UNION ALL
-- 例如：不同表的同结构数据合并（设计上保证没有重复）
SELECT * FROM orders_2025 UNION ALL SELECT * FROM orders_2026;

-- 需要去重时才用 UNION
SELECT user_id FROM orders UNION SELECT user_id FROM reviews;
```

---

## 适用场景

- **多表合并查询**：将历史表和当前表的数据合并为统一的结果集
- **多条件结果合并**：将不同 WHERE 条件的结果合并（并集），并去除重复项
- **报表的分类汇总行合并**：将不同分类的汇总行合并到一个结果集中展示

---

## 常见问题

**UNION 去重是基于值还是引用？**

基于值，即所有列值都相同的两行会被视为重复，只保留一行。对于字符串比较，大小写敏感性取决于列的排序规则（collation）。

---

## 注意事项

- UNION 的各个 SELECT 子查询不能包含 `FOR UPDATE` 锁定子句。
- 列数必须一致，类型不一致时 MySQL 会隐式转换（取更宽泛的类型）。如果某个 SELECT 缺少某列，可以用字面量或 NULL 填充：`SELECT id, name, NULL AS phone FROM admins UNION SELECT id, name, phone FROM users`。

---

## 总结

`UNION` 合并多个 SELECT 结果并自动去除完全重复的行，最终列名由第一个 SELECT 决定。去重操作有额外的排序或哈希开销。不需要去重时改用 `UNION ALL` 性能更好。ORDER BY 和 LIMIT 放在最后作用于合并后的整体结果。
