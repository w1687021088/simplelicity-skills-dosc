# DENSE_RANK() 窗口函数

`DENSE_RANK()` 也是排名函数，与 `RANK()` 类似——相同排序值的行获得相同名次，但与 RANK() 的不同之处在于：DENSE_RANK() 在并列之后**不跳号**，名次是连续的（dense 意为"密集的"）。例如有两行并列第 1 名，下一行是第 2 名，而不是第 3 名。

---

## 语法

```sql
DENSE_RANK() OVER (
    [PARTITION BY col1, col2, ...]
    ORDER BY col3 [ASC|DESC]
)
```

---

## 基本示例

```sql
-- 全公司薪资排名（DENSE_RANK：并列后不跳号）
SELECT name, dept_id, salary,
    DENSE_RANK() OVER (ORDER BY salary DESC) AS d_rank
FROM employees;

-- 数据和结果：
-- Alice  技术部  15000  → d_rank = 1
-- Bob    技术部  15000  → d_rank = 1（并列第1）
-- Carol  市场部  12000  → d_rank = 2（不跳到3，紧接1之后是2）
-- Dave   财务部  10000  → d_rank = 3

-- 对比 RANK()：Carol 在 RANK 中是第3名，在 DENSE_RANK 中是第2名
```

---

## DENSE_RANK 适合"前 N 个等级"的场景

```sql
-- 场景：找出排名前 3 的薪资等级的所有员工（包含并列）
WITH ranked AS (
    SELECT id, name, salary,
        DENSE_RANK() OVER (ORDER BY salary DESC) AS d_rnk
    FROM employees
)
SELECT id, name, salary, d_rnk
FROM ranked
WHERE d_rnk <= 3;
-- 结果：最高3个不同薪资水平的所有员工
-- 如果有10人并列第1名，10人都出现

-- 用 RANK() 的话，d_rnk <= 3 只取名次数字 <= 3 的行
-- 用 DENSE_RANK() 确保名次是连续的（1, 2, 3），
-- 表示"前3个不同薪资层级"更清晰

-- 按部门各取排名前2的薪资层级
WITH ranked AS (
    SELECT id, name, dept_id, salary,
        DENSE_RANK() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS d_rnk
    FROM employees
)
SELECT id, name, dept_id, salary
FROM ranked WHERE d_rnk <= 2;
```

## 三种排名函数对比

```sql
-- 完整对比（详见 1.9.21 RANK 中的表格）
-- 数据：100, 100, 90, 90, 80

-- ROW_NUMBER: 1, 2, 3, 4, 5   (唯一，无并列)
-- RANK:       1, 1, 3, 3, 5   (并列，跳号)
-- DENSE_RANK: 1, 1, 2, 2, 3   (并列，不跳号，名次连续)
```

| 特征 | RANK() | DENSE_RANK() |
|------|--------|--------------|
| 并列处理 | 相同排序值给相同名次 | 相同排序值给相同名次 |
| 并列后下一名次 | 跳号（跳过并列数量）| 不跳号（紧接下一个）|
| 最大名次值 | 可等于总行数 | 等于不同排序值的数量 |
| 适用场景 | 竞赛名次（金银铜不跳）| 等级分层（连续等级编号）|

---

## 实际应用：百分位分组（NTILE 对比）

```sql
-- 用 DENSE_RANK 实现薪资等级分层（层数不固定）
SELECT name, salary,
    DENSE_RANK() OVER (ORDER BY salary) AS salary_tier
FROM employees;
-- 薪资相同的员工在同一层，层号是连续的 1, 2, 3...

-- NTILE(4) 按行数平均分为4组（与 DENSE_RANK 不同）
SELECT name, salary,
    NTILE(4) OVER (ORDER BY salary) AS quartile
FROM employees;
-- 按行数平均分成4等份，同一份内的行有相同的 quartile 值
```

---

## 适用场景

- **等级分层**：消费等级（钻石/黄金/白银/普通），名次连续不跳号更直观
- **前 N 个不同值**：取前 N 个不同分数/薪资水平的所有行
- **积分/排行榜**：游戏排行榜中，分数相同的玩家同名次，名次连续

---

## 常见问题

**DENSE_RANK 和 RANK 在 MySQL 的 `WHERE d_rnk <= N` 行为有何不同？**

`RANK() <= N`：包含名次数字 <= N 的行，但可能跳过某些数字（如 1, 1, 3 时，没有名次 2）。
`DENSE_RANK() <= N`：包含前 N 个不同排序值的所有行，名次是 1, 2, ..., N（无空洞）。
业务上"前 N 个薪资等级"用 DENSE_RANK 更准确；业务上"名次数字上不超过 N"用 RANK。

---

## 注意事项

- 与 RANK() 一样，DENSE_RANK() 的结果不能直接在 WHERE 中过滤，需要通过 CTE 或派生表包一层。
- `DENSE_RANK()` 产生的名次编号等于分区内不同排序值的数量，这个值通常比 RANK 产生的最大名次小（因为不跳号）。

---

## 总结

`DENSE_RANK()` 给相同排序值的行赋予相同名次，并列之后的名次**不跳号**（与 RANK 的跳号不同），名次编号是连续的整数。适合需要"连续等级编号"的场景，如分层统计、积分排行。选择 DENSE_RANK 还是 RANK 的依据：是否需要名次编号无空洞（连续）。
