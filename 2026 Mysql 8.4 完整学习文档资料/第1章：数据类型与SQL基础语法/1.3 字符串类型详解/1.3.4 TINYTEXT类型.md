## TINYTEXT 类型

TINYTEXT 是 MySQL TEXT 类型家族中最小的一种，最大存储 255 个字节的文本内容。它在 TEXT 类型家族中的定位类似于 TINYINT 在整数家族中的位置：容量最小，适合存储短文本。

---

### 基本特性

| 属性 | 值 |
|------|---|
| 最大存储 | 255 字节 |
| 最大字符数 | utf8mb4 下约 63 个字符（255÷4）；latin1 下 255 个字符 |
| 存储方式 | 变长，1 字节长度前缀 |
| NULL 支持 | 支持 |
| 默认值 | 不能设置 DEFAULT（TEXT 类型限制） |
| 索引 | 必须使用前缀索引 |

---

### 语法

```sql
column_name TINYTEXT
column_name TINYTEXT CHARACTER SET utf8mb4
column_name TINYTEXT NOT NULL    -- 可以设置 NOT NULL，但不能设置 DEFAULT
```

---

### TINYTEXT 与 VARCHAR(255) 的对比

在实践中，`TINYTEXT` 和 `VARCHAR(255)` 看起来功能相近，但有重要差异：

| 对比维度 | TINYTEXT | VARCHAR(255) |
|---------|---------|-------------|
| 最大容量 | 255 字节 | 255 字符 |
| 能否设 DEFAULT | 不能 | 能 |
| 能否直接建完整索引 | 不能，需要前缀索引 | 能 |
| 存储位置 | 可能行外存储（大值时）| 行内存储 |
| 排序/临时表 | 按最大长度分配，效率稍低 | 按声明最大长度，效率稍高 |

由于这些差异，在实际项目中，**`VARCHAR(255)` 几乎总是比 `TINYTEXT` 更合适的选择**，它有更完整的功能支持（DEFAULT 值、直接建索引）。

---

### 创建示例

```sql
-- TINYTEXT 的使用（实际更推荐 VARCHAR）
CREATE TABLE product_tags (
    product_id INT UNSIGNED NOT NULL,
    tag_summary TINYTEXT COMMENT '标签摘要，最多255字节'
);

-- 推荐的替代写法（用 VARCHAR）
CREATE TABLE product_tags_better (
    product_id  INT UNSIGNED NOT NULL,
    tag_summary VARCHAR(255) NOT NULL DEFAULT '' COMMENT '标签摘要'
);
```

### 适用场景

TINYTEXT 的适用场景非常有限，主要在以下情况下才会选择它：
- 从其他数据库迁移的数据库方案中明确使用了 TINYTEXT
- 需要区分"不应该用于索引"和"短文本"语义的设计场景
- 存量系统中已有 TINYTEXT 列，维护时需要理解其特性

新项目中，几乎不应该主动选择 TINYTEXT，直接使用 `VARCHAR(N)` 更合适。

---

### 常见问题

**为什么不能给 TINYTEXT 设置 DEFAULT 值？**

MySQL 规定 TEXT 类族（TINYTEXT、TEXT、MEDIUMTEXT、LONGTEXT）和 BLOB 类族不支持 DEFAULT 值，这是设计上的限制。如果字段需要 DEFAULT 值，应使用 VARCHAR 代替。

**TINYTEXT 能创建索引吗？**

不能直接创建完整列索引，只能创建前缀索引：

```sql
CREATE TABLE t (col TINYTEXT);
CREATE INDEX idx_col ON t (col(50));  -- 前缀索引，只索引前50个字节
```

---

### 注意事项

- TINYTEXT 的容量是 255 **字节**，不是 255 个字符。在 utf8mb4 字符集下，一个汉字占 3 字节，255 字节只能存约 63 个汉字。如果需要存 255 个汉字，应用 TEXT 类型。
- TEXT 类型家族的列不能有 DEFAULT 值，也不能直接建完整索引，这是选择 VARCHAR 的主要理由。

---

### 总结

TINYTEXT 最大存储 255 字节文本，是 TEXT 家族中容量最小的类型。由于不支持 DEFAULT 值和直接索引，在新项目设计中几乎没有理由选择 TINYTEXT——`VARCHAR(255)` 在功能上是更完整的替代方案。维护旧系统时理解 TINYTEXT 的字节容量限制（非字符数）是需要注意的要点。
