# CREATE TABLE 基础语法

`CREATE TABLE` 是 MySQL 中最常用的 DDL 语句，用于定义表结构。它包含列定义、约束定义、索引定义，以及表级别的存储引擎、字符集、注释等属性设置。

---

## 完整语法结构

```sql
CREATE [TEMPORARY] TABLE [IF NOT EXISTS] tbl_name (
    col_name col_definition [, col_name col_definition ...]
    [, table_constraints ...]
    [, table_indexes ...]
) [table_options];
```

`col_definition` 的基本格式：
```sql
col_name data_type
    [NOT NULL | NULL]
    [DEFAULT default_value | DEFAULT expr]
    [AUTO_INCREMENT]
    [UNIQUE [KEY]]
    [PRIMARY KEY]
    [COMMENT 'comment_text']
    [COLLATE collation_name]
    [COLUMN_FORMAT {FIXED | DYNAMIC | DEFAULT}]
    [STORAGE {DISK | MEMORY}]
    [INVISIBLE]
```

## 标准建表示例

```sql
-- 用户表（包含常见约束和属性）
CREATE TABLE users (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT       COMMENT '用户ID',
    username    VARCHAR(50) NOT NULL                       COMMENT '用户名',
    email       VARCHAR(200) NOT NULL                      COMMENT '邮箱',
    password    VARCHAR(255) NOT NULL                      COMMENT '加密密码',
    status      ENUM('active', 'inactive', 'banned') NOT NULL DEFAULT 'active' COMMENT '账户状态',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_username (username),
    UNIQUE KEY uk_email (email),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='用户表';

-- 订单表（展示外键和复合索引）
CREATE TABLE orders (
    id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT    COMMENT '订单ID',
    user_id     INT UNSIGNED NOT NULL                      COMMENT '用户ID',
    order_no    VARCHAR(32) NOT NULL                       COMMENT '订单编号',
    amount      DECIMAL(10, 2) NOT NULL DEFAULT 0.00       COMMENT '订单金额',
    status      TINYINT UNSIGNED NOT NULL DEFAULT 0        COMMENT '状态：0待支付1已支付2已完成',
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '下单时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_order_no (order_no),
    INDEX idx_user_created (user_id, created_at),
    CONSTRAINT fk_orders_user FOREIGN KEY (user_id) REFERENCES users(id)
        ON DELETE RESTRICT ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单表';
```

## 临时表

```sql
-- 临时表：只在当前会话中可见，会话结束自动删除
CREATE TEMPORARY TABLE temp_analysis (
    user_id     INT UNSIGNED,
    order_count INT UNSIGNED,
    total_amount DECIMAL(12, 2)
);

-- 临时表的使用场景：复杂查询中间结果缓存
INSERT INTO temp_analysis
SELECT user_id, COUNT(*), SUM(amount) FROM orders
WHERE created_at >= '2026-01-01'
GROUP BY user_id;

-- 同名临时表会遮蔽同名普通表（在当前会话中）
-- 临时表不显示在 SHOW TABLES 中
```

## 表选项

```sql
-- ENGINE：存储引擎，默认 InnoDB（也是唯一推荐的）
-- CHARSET/CHARACTER SET：表的默认字符集
-- COLLATE：表的默认排序规则
-- COMMENT：表注释
-- AUTO_INCREMENT：指定 AUTO_INCREMENT 初始值
-- ROW_FORMAT：行格式（DYNAMIC, COMPACT, COMPRESSED, REDUNDANT）

CREATE TABLE example (
    id   INT NOT NULL AUTO_INCREMENT PRIMARY KEY
) ENGINE=InnoDB
  AUTO_INCREMENT=1000     -- 从 1000 开始自增
  DEFAULT CHARSET=utf8mb4
  COMMENT='示例表'
  ROW_FORMAT=DYNAMIC;
```

## 查看表结构

```sql
-- 查看表的列结构（简洁）
DESCRIBE users;
-- 或
DESC users;

-- 查看建表语句（完整，含索引、约束）
SHOW CREATE TABLE users;

-- 查看表详细信息（行数、存储引擎、自增值等）
SHOW TABLE STATUS LIKE 'users';

-- 通过信息模式查看
SELECT column_name, column_type, is_nullable, column_default, extra, column_comment
FROM information_schema.COLUMNS
WHERE table_schema = DATABASE() AND table_name = 'users'
ORDER BY ordinal_position;
```

## 适用场景

`CREATE TABLE` 是所有数据持久化的起点，在以下场景中会用到：
- 新功能开发时设计数据表结构
- 数据库初始化脚本（通常配合 `IF NOT EXISTS`）
- 导入数据前创建目标表
- 创建临时表辅助复杂查询

---

## 常见问题

**CREATE TABLE IF NOT EXISTS 和不加 IF NOT EXISTS 有什么区别？**

不加时，如果表已存在会报错 `ERROR 1050: Table already exists`，并且语句不会执行。加上后，如果表已存在则静默跳过（不报错，不修改已有表），适合幂等的初始化脚本。

**建表时必须指定 ENGINE=InnoDB 吗？**

MySQL 8.0 的默认存储引擎就是 InnoDB，不指定时自动使用 InnoDB。建议显式写明 `ENGINE=InnoDB` 以增加代码可读性和明确性。

---

## 注意事项

- 每张表必须有主键（虽然 MySQL 不强制，但没有主键的 InnoDB 表在复制和性能上都有隐患）。InnoDB 会自动使用一个隐藏的 6 字节行 ID 作为主键，但这对应用层不可见，无法利用。
- 建表时应为每个列加上 `COMMENT`，这对后期维护和阅读 DDL 非常有帮助。
- 字段类型要精确匹配业务需求，不要因为"保险"而用过大的类型（如用 BIGINT 存状态码），这会浪费存储空间并影响索引效率。

---

## 总结

`CREATE TABLE` 定义表结构，包含列定义（类型、约束、默认值）、表级约束（PRIMARY KEY、UNIQUE、FOREIGN KEY）、索引和表属性（引擎、字符集、注释）。`IF NOT EXISTS` 让语句幂等。临时表（TEMPORARY）只在当前会话存在。建表时应遵循：有主键、有注释、类型精确、字符集统一（utf8mb4）的原则。
