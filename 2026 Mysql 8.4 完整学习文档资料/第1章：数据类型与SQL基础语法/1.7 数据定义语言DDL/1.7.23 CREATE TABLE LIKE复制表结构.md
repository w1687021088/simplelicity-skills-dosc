# CREATE TABLE ... LIKE 复制表结构

`CREATE TABLE ... LIKE` 基于已有表的结构（列定义、索引、约束）创建一张新的空表，不复制数据。这是快速创建与已有表结构相同的新表的标准方式，常用于数据归档、分表切换、测试环境准备等场景。

---

## 语法

```sql
CREATE [TEMPORARY] TABLE [IF NOT EXISTS] new_tbl_name LIKE orig_tbl_name;
```

---

## 复制内容说明

| 内容 | 是否复制 |
|------|---------|
| 列定义（类型、NOT NULL、DEFAULT、COMMENT）| 是 |
| 主键（PRIMARY KEY）| 是 |
| 唯一索引（UNIQUE KEY）| 是 |
| 普通索引（INDEX）| 是 |
| 全文索引（FULLTEXT）| 是 |
| 表存储引擎（ENGINE）| 是 |
| 字符集（CHARSET）| 是 |
| AUTO_INCREMENT 起始值 | 否（重置为 1）|
| 表数据 | 否（空表）|
| 外键约束（FOREIGN KEY）| 否（不复制）|
| CHECK 约束 | 是（MySQL 8.0.16+）|
| 触发器 | 否（不复制）|

---

## 基本示例

```sql
-- 基于 orders 表创建相同结构的新表
CREATE TABLE orders_2025 LIKE orders;

-- 创建分表（按月分表）
CREATE TABLE orders_2026_01 LIKE orders;
CREATE TABLE orders_2026_02 LIKE orders;
CREATE TABLE orders_2026_03 LIKE orders;

-- 创建临时表（结构与原表相同，但只在当前会话存在）
CREATE TEMPORARY TABLE temp_orders LIKE orders;

-- IF NOT EXISTS 防止重复创建报错
CREATE TABLE IF NOT EXISTS orders_backup LIKE orders;

-- 跨库复制结构
CREATE TABLE newdb.orders LIKE mydb.orders;
```

---

## 典型使用场景示例

```sql
-- 场景：数据归档（将旧数据移到归档表）
-- 1. 创建与原表结构相同的归档表
CREATE TABLE orders_archive_2025 LIKE orders;

-- 2. 将 2025 年的数据移入归档表
INSERT INTO orders_archive_2025
SELECT * FROM orders WHERE YEAR(created_at) = 2025;

-- 3. 从原表删除已归档的数据
DELETE FROM orders WHERE YEAR(created_at) = 2025;

-- 场景：蓝绿切换（创建新表替换旧表）
-- 1. 创建新表（与旧表结构相同）
CREATE TABLE users_new LIKE users;

-- 2. 在新表上做所需的结构修改
ALTER TABLE users_new ADD COLUMN score INT UNSIGNED NOT NULL DEFAULT 0;

-- 3. 迁移数据
INSERT INTO users_new (id, username, email, ...)
SELECT id, username, email, ... FROM users;

-- 4. 原子切换
RENAME TABLE users TO users_old, users_new TO users;

-- 5. 确认后删除旧表
DROP TABLE users_old;
```

---

## 适用场景

- **数据归档**：定期将历史数据移入归档表（与原表结构相同）
- **分表**：创建按时间/范围分片的表（按月分表、按年分表）
- **蓝绿切换**：创建新表用于不停服的表结构迁移
- **测试**：在不影响原表的情况下，创建相同结构的测试表

---

## 常见问题

**LIKE 复制的表中，外键约束是否需要手动添加？**

是的，`LIKE` 不复制外键约束。如果新表也需要外键约束，必须在创建后手动用 `ALTER TABLE ... ADD FOREIGN KEY` 添加。

**LIKE 复制的表，AUTO_INCREMENT 从多少开始？**

从 1 开始（或者建表语句中指定的 `AUTO_INCREMENT` 起始值），不会继承原表当前的 AUTO_INCREMENT 值。

---

## 注意事项

- `LIKE` 只复制表结构，不复制 TRIGGER（触发器）和 FOREIGN KEY（外键约束），如果新表需要这些，必须手动补充。
- 跨数据库复制结构时，需要有源表所在数据库的 SELECT 权限和目标数据库的 CREATE 权限。

---

## 总结

`CREATE TABLE ... LIKE` 基于已有表创建结构相同的空表，复制列定义、索引、CHECK 约束等，但不复制外键约束和触发器，AUTO_INCREMENT 重置为 1。适用于数据归档、分表创建、蓝绿切换等场景，是数据库日常维护中简洁实用的工具语句。
