# CREATE DATABASE 语法与字符集指定

`CREATE DATABASE` 是 MySQL 中创建数据库（Schema）的语句，可以在创建时指定字符集和排序规则，这些设置会作为数据库级别的默认值，影响后续在该库中创建的所有表和列（除非表或列层面有单独指定）。

---

## 语法

```sql
CREATE DATABASE [IF NOT EXISTS] db_name
    [CHARACTER SET charset_name]
    [COLLATE collation_name]
    [ENCRYPTION {'Y' | 'N'}];

-- CREATE SCHEMA 与 CREATE DATABASE 完全等价
CREATE SCHEMA [IF NOT EXISTS] db_name ...;
```

---

## 创建示例

```sql
-- 最简创建（使用服务器默认字符集，通常是 utf8mb4）
CREATE DATABASE my_app;

-- 指定字符集和排序规则（推荐写法）
CREATE DATABASE my_app
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

-- 如果数据库已存在则不报错（幂等创建）
CREATE DATABASE IF NOT EXISTS my_app
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_0900_ai_ci;

-- 创建区分大小写的数据库
CREATE DATABASE my_app_cs
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_bin;   -- _bin 排序规则区分大小写

-- 创建金融类数据库（中文内容，支持全范围排序）
CREATE DATABASE finance_db
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_zh_0900_as_cs;  -- 中文字符按拼音排序，区分大小写
```

---

## 常用字符集与排序规则

| 字符集 | 排序规则 | 特点 |
|--------|---------|------|
| utf8mb4 | utf8mb4_0900_ai_ci | MySQL 8.0+ 默认，不区分大小写和重音 |
| utf8mb4 | utf8mb4_unicode_ci | 兼容性好，Unicode 排序规则 |
| utf8mb4 | utf8mb4_bin | 按二进制值排序，区分大小写 |
| utf8mb4 | utf8mb4_zh_0900_as_cs | 中文按拼音排序，区分大小写 |

## 查看与管理数据库

```sql
-- 查看所有数据库
SHOW DATABASES;

-- 查看数据库的创建语句（含字符集信息）
SHOW CREATE DATABASE my_app;
-- 输出：CREATE DATABASE `my_app` /*!40100 DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci */ /*!80016 DEFAULT ENCRYPTION='N' */

-- 查看当前使用的数据库
SELECT DATABASE();

-- 切换数据库
USE my_app;
```

## 数据库级别字符集的继承关系

```
服务器字符集（character_set_server）
    → 数据库字符集（CREATE DATABASE ... CHARACTER SET）
        → 表字符集（CREATE TABLE ... CHARACTER SET）
            → 列字符集（column_def CHARACTER SET）
```

低层级没有明确指定时，继承高层级的字符集设置。修改数据库字符集不会自动修改已有表的字符集，只对新建表生效。

```sql
-- 查看数据库字符集
SELECT schema_name, default_character_set_name, default_collation_name
FROM information_schema.SCHEMATA
WHERE schema_name = 'my_app';
```

## 适用场景

- 项目初始化时统一指定 `utf8mb4` 和合适的排序规则，避免后续出现字符集不一致的问题
- 多租户系统中为每个租户创建独立的数据库（Schema）
- 区分开发库、测试库、生产库的命名规范

---

## 常见问题

**创建数据库时不指定字符集，默认是什么？**

MySQL 8.0 起，服务器默认字符集是 `utf8mb4`，排序规则是 `utf8mb4_0900_ai_ci`（通过 `character_set_server` 和 `collation_server` 参数控制）。早期版本默认是 `latin1`，所以老项目中经常需要显式指定 `utf8mb4`。

**IF NOT EXISTS 是幂等的吗？**

是的，加上 `IF NOT EXISTS` 后，如果数据库已经存在，语句不会报错，也不会修改已有数据库的任何设置（字符集等）。这使得数据库初始化脚本可以安全地重复执行。

---

## 注意事项

- 数据库名区分大小写（在文件系统大小写敏感的系统上，如 Linux），建议统一使用小写字母和下划线命名。
- 修改已有数据库的字符集用 `ALTER DATABASE`，但只影响新建表，已有表需要单独 ALTER TABLE 来改变字符集。

---

## 总结

`CREATE DATABASE` 创建数据库，可通过 `CHARACTER SET` 和 `COLLATE` 指定字符集和排序规则，推荐统一使用 `utf8mb4` + `utf8mb4_0900_ai_ci`。`IF NOT EXISTS` 使语句幂等，适合初始化脚本。数据库级字符集是后续建表的默认值，低层级（表、列）可以单独覆盖。
