# RENAME TABLE 表重命名

`RENAME TABLE` 是 MySQL 中重命名表的语句，可以同时重命名多张表，也可以通过重命名实现表在不同数据库（Schema）之间的移动。RENAME TABLE 是原子操作，要么全部成功要么全部回滚。

---

## 语法

```sql
RENAME TABLE old_tbl_name TO new_tbl_name
    [, old_tbl2 TO new_tbl2, ...];

-- ALTER TABLE 也可以重命名
ALTER TABLE old_tbl_name RENAME [TO | AS] new_tbl_name;
```

---

## 基本示例

```sql
-- 重命名单张表
RENAME TABLE old_users TO users;

-- 同时重命名多张表（原子操作，全部成功或全部失败）
RENAME TABLE 
    order_list TO orders,
    product_list TO products,
    user_account TO users;

-- 将表移动到另一个数据库（同实例）
RENAME TABLE mydb.old_table TO newdb.new_table;

-- 使用 ALTER TABLE 方式重命名
ALTER TABLE old_users RENAME TO users;
```

---

## 原子性保证

```sql
-- 以下操作是原子的：如果其中任何一步失败，所有重命名都不会执行
RENAME TABLE 
    current_orders TO orders_backup,    -- 将当前表改名为备份
    new_orders TO current_orders;        -- 将新表改名为当前表名
-- 这种"表切换"操作在数据迁移中非常有用
-- 可以实现对应用无感知的数据迁移：新旧表同时存在，切换瞬间完成
```

---

## 通过 RENAME 实现表切换（蓝绿切换）

```sql
-- 场景：需要重建一张大表（如重新导入数据、更改存储引擎等）
-- 不能直接 TRUNCATE + 重新导入（期间表不可用）

-- 步骤1：创建新表（与原表同结构）
CREATE TABLE users_new LIKE users;

-- 步骤2：在新表上做各种准备（导入数据、重建索引等）
-- 这期间原表 users 仍然正常服务
INSERT INTO users_new SELECT * FROM users;

-- 步骤3：原子切换（1毫秒级别）
RENAME TABLE users TO users_old, users_new TO users;
-- 应用程序访问 users，瞬间切换到新表，极短锁定时间

-- 步骤4：确认无误后删除旧表
DROP TABLE users_old;
```

```sql
-- 查看当前数据库的所有表
SHOW TABLES;

-- 查看特定库的所有表
SELECT table_name FROM information_schema.TABLES 
WHERE table_schema = 'mydb' ORDER BY table_name;
```

## 适用场景

- **规范化表名**：将历史遗留的不规范表名改为符合命名规范的名称
- **表切换**：用新表替换旧表（蓝绿部署），实现无停机数据迁移
- **跨库移动**：在同一实例内，将表从一个数据库移到另一个数据库

---

## 常见问题

**RENAME TABLE 会锁表吗？**

RENAME TABLE 需要对被重命名的表获取独占锁（MDL - Metadata Lock），锁定时间极短（通常是毫秒级）。对于"蓝绿切换"（两表同时 RENAME），锁定时间也极短，对业务几乎无感。

**RENAME TABLE 到另一个数据库时，外键约束会怎样？**

跨库移动有外键约束的表会失败（外键不能跨数据库引用）。需要先删除外键，移动后重新创建。

---

## 注意事项

- RENAME TABLE 后，所有引用旧表名的视图、存储过程、触发器不会自动更新，仍然使用旧表名（会报找不到表的错误）。重命名后需要手动更新这些对象。
- 跨库的 RENAME TABLE（移动表）等效于将表从源库删除并在目标库创建，外键约束和触发器在跨库后的行为需要特别验证。

---

## 总结

`RENAME TABLE` 是原子性的表重命名操作，可以一次重命名多张表。通过同时重命名两张表可以实现"蓝绿切换"——用新表无缝替换旧表，对业务几乎无感知。也可以将表跨数据库移动（同实例内）。重命名后需要手动更新引用旧表名的视图和存储过程。
