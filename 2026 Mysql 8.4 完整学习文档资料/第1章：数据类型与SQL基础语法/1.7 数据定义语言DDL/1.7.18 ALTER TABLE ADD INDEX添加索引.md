# ALTER TABLE ADD INDEX 添加索引

`ALTER TABLE ... ADD INDEX` 用于在已有表上添加索引，是数据库性能调优中最常执行的 DDL 操作之一。MySQL 8.0 对在线添加索引（ONLINE DDL）的支持非常成熟，大部分情况下添加索引时不需要锁表。

---

## 语法

```sql
-- 添加普通索引
ALTER TABLE tbl_name ADD INDEX [index_name] (col_name [(length)] [ASC|DESC], ...);
ALTER TABLE tbl_name ADD KEY [index_name] (...);  -- KEY 等价于 INDEX

-- 添加唯一索引
ALTER TABLE tbl_name ADD UNIQUE INDEX [index_name] (col_name, ...);

-- 添加全文索引
ALTER TABLE tbl_name ADD FULLTEXT INDEX [index_name] (col_name, ...);

-- 添加空间索引
ALTER TABLE tbl_name ADD SPATIAL INDEX [index_name] (col_name);

-- 等价的 CREATE INDEX 语法
CREATE [UNIQUE | FULLTEXT | SPATIAL] INDEX index_name ON tbl_name (col_name, ...);
```

---

## 添加索引示例

```sql
-- 添加单列索引
ALTER TABLE orders ADD INDEX idx_user_id (user_id);

-- 添加复合索引
ALTER TABLE orders ADD INDEX idx_user_status_created (user_id, status, created_at);

-- 添加唯一索引
ALTER TABLE users ADD UNIQUE INDEX uk_email (email);

-- 添加前缀索引
ALTER TABLE articles ADD INDEX idx_title_prefix (title(100));

-- 添加函数索引（MySQL 8.0.13+，降低大小写进行搜索）
ALTER TABLE users ADD INDEX idx_email_lower ((LOWER(email)));

-- 同时添加多个索引
ALTER TABLE orders
    ADD INDEX idx_status (status),
    ADD INDEX idx_created (created_at),
    ADD INDEX idx_user_created (user_id, created_at);
```

---

## 在线添加索引（Online DDL）

MySQL 8.0 中，`ADD INDEX` 默认使用 INPLACE 算法，允许并发 DML（LOCK=NONE）：

```sql
-- 默认行为（INPLACE + LOCK=NONE）
ALTER TABLE orders ADD INDEX idx_amount (amount);
-- 添加索引期间，INSERT/UPDATE/DELETE 正常进行，不锁表

-- 显式指定算法
ALTER TABLE orders
    ADD INDEX idx_user_id (user_id),
    ALGORITHM=INPLACE,
    LOCK=NONE;

-- 全文索引需要 LOCK=SHARED（不支持 LOCK=NONE）
ALTER TABLE articles ADD FULLTEXT INDEX idx_content (content), LOCK=SHARED;
```

## 函数索引（MySQL 8.0.13+）

```sql
-- 对表达式建索引（表达式必须用括号括起来）
CREATE TABLE users (
    id      INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
    email   VARCHAR(200) NOT NULL
);

-- 对 email 小写版本建索引（实现大小写不敏感的邮箱唯一约束）
ALTER TABLE users ADD UNIQUE INDEX uk_email_lower ((LOWER(email)));

-- 查询时使用相同表达式可利用索引
SELECT * FROM users WHERE LOWER(email) = 'alice@example.com';  -- 走 uk_email_lower
EXPLAIN SELECT * FROM users WHERE LOWER(email) = 'alice@example.com';
-- type: ref, key: uk_email_lower

-- 对 JSON 字段建函数索引
CREATE TABLE products (
    id   INT PRIMARY KEY AUTO_INCREMENT,
    meta JSON
);
ALTER TABLE products ADD INDEX idx_price ((CAST(meta->>'$.price' AS DECIMAL(10,2))));
SELECT * FROM products WHERE CAST(meta->>'$.price' AS DECIMAL(10,2)) < 100;  -- 走索引
```

## 查看索引创建进度

```sql
-- 通过 performance_schema 查看 DDL 进度（MySQL 8.0+）
SELECT event_name, work_completed, work_estimated,
       ROUND(work_completed/work_estimated*100, 2) AS pct_done
FROM performance_schema.events_stages_current
WHERE event_name LIKE '%alter%';
```

## 适用场景

- **慢查询优化**：通过 EXPLAIN 发现全表扫描（type=ALL），为 WHERE 条件列添加索引
- **JOIN 优化**：为 JOIN ON 条件列添加索引
- **ORDER BY / GROUP BY 优化**：为排序/分组列添加索引
- **覆盖索引**：为常用查询的 SELECT 列+WHERE 列组合建复合索引

---

## 常见问题

**添加索引时表会锁吗？**

MySQL 8.0 中，普通 B-Tree 索引使用 INPLACE 算法，LOCK=NONE（不锁表），添加索引期间可以正常进行 DML 操作。全文索引（FULLTEXT）需要 LOCK=SHARED（允许读，不允许写）。

**什么时候用 CREATE INDEX，什么时候用 ALTER TABLE ADD INDEX？**

两种语法功能相同，推荐统一使用 ALTER TABLE 方式，因为可以在同一条语句中同时添加多个索引，减少 DDL 次数。

---

## 注意事项

- 添加索引对大表有额外的磁盘 I/O 开销，在磁盘 I/O 繁忙的生产环境，大表加索引应选择低峰期执行。
- 不要为每个查询场景单独建索引，应该分析常见的查询模式，设计覆盖多个场景的复合索引，减少总索引数量。

---

## 总结

`ALTER TABLE ADD INDEX` 为已有表添加索引，支持普通、唯一、全文、空间、函数等多种索引类型。MySQL 8.0 的在线 DDL 允许在不锁表的情况下添加普通索引（INPLACE + LOCK=NONE）。函数索引（MySQL 8.0.13+）可以对表达式建索引，支持 JSON 字段索引和大小写不敏感的字符串索引场景。
