# DEFAULT 默认值设置

`DEFAULT` 约束为列指定默认值，当 INSERT 语句没有为该列提供值时，MySQL 自动使用默认值。MySQL 8.0.13 起支持表达式作为 DEFAULT 值，使默认值的表达能力大幅增强。

---

## 语法

```sql
col_name data_type NOT NULL DEFAULT literal_value
col_name data_type NOT NULL DEFAULT (expression)  -- 表达式默认值，需括号（MySQL 8.0.13+）
col_name data_type DEFAULT NULL  -- NULL 作为默认值（列必须允许 NULL）
```

---

## 字面量默认值示例

```sql
CREATE TABLE config_items (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
    
    -- 整数默认值
    sort_order  INT NOT NULL DEFAULT 0,
    max_count   SMALLINT UNSIGNED NOT NULL DEFAULT 100,
    
    -- 字符串默认值
    status      VARCHAR(20) NOT NULL DEFAULT 'active',
    country     CHAR(2) NOT NULL DEFAULT 'CN',
    
    -- 枚举默认值
    level       ENUM('low', 'medium', 'high') NOT NULL DEFAULT 'medium',
    
    -- 数值默认值
    ratio       DECIMAL(5, 2) NOT NULL DEFAULT 1.00,
    
    -- 时间默认值
    created_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,  -- 当前时间（内置关键字）
    
    -- NULL 作为默认值
    remark      VARCHAR(500) DEFAULT NULL,
    
    PRIMARY KEY (id)
);

-- 演示默认值生效
INSERT INTO config_items (id) VALUES (1);  -- 只提供 id，其他都用默认值
SELECT * FROM config_items WHERE id = 1;
-- sort_order=0, max_count=100, status='active', country='CN', level='medium', ratio=1.00
```

## 表达式默认值（MySQL 8.0.13+）

表达式 DEFAULT 需要用括号包裹，支持函数调用和常量表达式：

```sql
CREATE TABLE tasks (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
    title       VARCHAR(200) NOT NULL,
    
    -- 表达式默认值（需要括号）
    created_at  DATE NOT NULL DEFAULT (CURRENT_DATE),          -- 今天的日期
    due_date    DATE NOT NULL DEFAULT (CURRENT_DATE + INTERVAL 7 DAY),  -- 7天后
    expire_at   DATETIME NOT NULL DEFAULT (NOW() + INTERVAL 30 DAY),   -- 30天后过期
    token       CHAR(36) NOT NULL DEFAULT (UUID()),            -- 随机 UUID
    
    -- UNIX 时间戳（整数形式）
    unix_ts     BIGINT UNSIGNED NOT NULL DEFAULT (UNIX_TIMESTAMP()),
    
    PRIMARY KEY (id)
);

INSERT INTO tasks (title) VALUES ('完成报告');
SELECT id, title, created_at, due_date, expire_at, token FROM tasks;
-- created_at: 2026-03-15
-- due_date:   2026-03-22（7天后）
-- token:      随机 UUID
```

## CURRENT_TIMESTAMP 作为 DEFAULT

`CURRENT_TIMESTAMP` 是为 DATETIME/TIMESTAMP 列提供默认值的特殊关键字（不需要括号）：

```sql
CREATE TABLE audit_log (
    id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    event       VARCHAR(100) NOT NULL,
    -- 以下三种写法等价
    ts1         TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    ts2         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    ts3         DATETIME NOT NULL DEFAULT NOW(),  -- NOW() 也可以不加括号
    PRIMARY KEY (id)
);
```

## 修改列的默认值

```sql
-- 添加/修改 DEFAULT 值
ALTER TABLE config_items ALTER COLUMN sort_order SET DEFAULT 10;

-- 删除 DEFAULT 约束（列变为无默认值）
ALTER TABLE config_items ALTER COLUMN sort_order DROP DEFAULT;

-- 也可以通过 MODIFY COLUMN 修改
ALTER TABLE config_items MODIFY COLUMN sort_order INT NOT NULL DEFAULT 5;
```

## 适用场景

- `created_at` 和 `updated_at` 列：`DEFAULT CURRENT_TIMESTAMP` 和 `ON UPDATE CURRENT_TIMESTAMP`
- 状态字段初始值：`DEFAULT 'pending'` 或 `DEFAULT 0`
- 可选数量/金额字段：`DEFAULT 0`
- 随机令牌：`DEFAULT (UUID())` 自动生成唯一令牌
- 计划到期日：`DEFAULT (CURRENT_DATE + INTERVAL 30 DAY)`

---

## 常见问题

**TEXT 和 BLOB 类型能设置 DEFAULT 值吗？**

TEXT 和 BLOB 类型不支持字面量 DEFAULT 值（只能 `DEFAULT NULL`）。MySQL 8.0.13+ 后，TEXT/BLOB 列可以使用表达式 DEFAULT（用括号），但实践中很少这样做。

**NULL 和空字符串哪个更适合作为字符串列的默认值？**

取决于业务语义。`DEFAULT NULL` 表示"未知/未设置"；`DEFAULT ''` 表示"明确的空字符串值"。如果需要区分"没有填写"和"填写了但是空"，用 NULL；如果不需要区分，用空字符串加 NOT NULL 约束更简洁。

---

## 注意事项

- 表达式 DEFAULT（如 `DEFAULT (UUID())`）在 MySQL 8.0.13 之前不支持，如果系统可能运行在旧版本上，需注意兼容性。
- `DEFAULT CURRENT_TIMESTAMP` 只对 DATETIME 和 TIMESTAMP 类型有效，对 DATE 类型需要用括号：`DEFAULT (CURRENT_DATE)`。
- AUTO_INCREMENT 列不能有 DEFAULT 值，设置了会忽略。

---

## 总结

`DEFAULT` 为列设置插入时的默认值，支持字面量（数字、字符串、NULL）和表达式（MySQL 8.0.13+，需括号）。`CURRENT_TIMESTAMP` 是 DATETIME/TIMESTAMP 列的特殊默认值关键字。修改默认值使用 `ALTER TABLE ... ALTER COLUMN ... SET DEFAULT` 或 `MODIFY COLUMN`。合理设置默认值可以减少 INSERT 语句的复杂度，并在数据库层面保证字段有合理的初始值。
