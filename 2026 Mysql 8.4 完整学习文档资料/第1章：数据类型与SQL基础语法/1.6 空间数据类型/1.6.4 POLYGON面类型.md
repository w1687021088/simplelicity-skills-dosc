# POLYGON 面类型

POLYGON 表示一个封闭的多边形区域，由外边界环和零个或多个内边界环（表示"洞"）组成。它是 MySQL 空间类型中用于描述面状地物的主要类型，如行政区划、建筑地块、配送区域等。

---

## 基本特性

| 属性 | 值 |
|------|---|
| 组成 | 一个外环 + 零或多个内环（孔洞）|
| WKT 格式 | `POLYGON((外环点序列))` 或 `POLYGON((外环), (内环1), ...)` |
| 闭合要求 | 第一个点和最后一个点必须相同 |
| 点序方向 | 外环应逆时针，内环应顺时针（OGC 标准）|

---

## 语法与创建示例

```sql
-- 配送区域表
CREATE TABLE delivery_zones (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
    name        VARCHAR(200) NOT NULL,
    boundary    POLYGON NOT NULL SRID 4326,
    PRIMARY KEY (id),
    SPATIAL INDEX idx_boundary (boundary)
);

-- 行政区划
CREATE TABLE districts (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
    name        VARCHAR(100) NOT NULL,
    shape       POLYGON NOT NULL SRID 4326,
    area_km2    DOUBLE COMMENT '面积（平方千米）',
    PRIMARY KEY (id),
    SPATIAL INDEX idx_shape (shape)
);

-- 插入简单矩形区域（逆时针方向，起点和终点相同）
INSERT INTO delivery_zones (name, boundary) VALUES (
    '朝阳区配送范围',
    ST_GeomFromText(
        'POLYGON((116.40 39.85, 116.55 39.85, 116.55 40.00, 116.40 40.00, 116.40 39.85))',
        4326
    )
);

-- 带"洞"的多边形（外环包含一个内部排除区域）
INSERT INTO delivery_zones (name, boundary) VALUES (
    '特殊配送区（含禁区）',
    ST_GeomFromText(
        'POLYGON(
            (116.40 39.85, 116.55 39.85, 116.55 40.00, 116.40 40.00, 116.40 39.85),
            (116.45 39.90, 116.50 39.90, 116.50 39.95, 116.45 39.95, 116.45 39.90)
        )',
        4326
    )
);
```

## 常用空间操作

```sql
-- 计算多边形面积（SRID 0 笛卡尔坐标下单位为坐标系单位的平方）
SET @poly = ST_GeomFromText('POLYGON((0 0, 10 0, 10 10, 0 10, 0 0))', 0);
SELECT ST_Area(@poly);  -- 100（100 平方单位）

-- SRID 4326 下面积（单位是度²，没有直接物理意义）
-- 实际应用中，面积计算通常需要在应用层转换，或使用 SRID 3857 投影坐标系

-- 判断点是否在多边形内
SET @zone = ST_GeomFromText(
    'POLYGON((116.40 39.85, 116.55 39.85, 116.55 40.00, 116.40 40.00, 116.40 39.85))',
    4326
);
SET @user_loc = ST_GeomFromText('POINT(116.47 39.92)', 4326);
SELECT ST_Within(@user_loc, @zone);     -- 1（点在多边形内）
SELECT ST_Contains(@zone, @user_loc);   -- 1（等效：多边形包含该点）

-- 地理围栏应用：判断用户是否在配送区域内
SELECT 
    name,
    ST_Contains(boundary, ST_GeomFromText('POINT(116.47 39.92)', 4326)) AS is_serviceable
FROM delivery_zones;

-- 查询包含指定点的所有区域（配合 SPATIAL INDEX）
SELECT name FROM delivery_zones
WHERE ST_Contains(boundary, ST_GeomFromText('POINT(116.47 39.92)', 4326));

-- 两个多边形是否相交
SELECT ST_Intersects(
    ST_GeomFromText('POLYGON((0 0, 4 0, 4 4, 0 4, 0 0))', 0),
    ST_GeomFromText('POLYGON((2 2, 6 2, 6 6, 2 6, 2 2))', 0)
);  -- 1（相交）

-- 获取外环边界
SELECT ST_AsText(ST_ExteriorRing(boundary)) FROM delivery_zones WHERE id = 1;

-- 获取内环数量
SELECT ST_NumInteriorRings(boundary) FROM delivery_zones;
```

## 适用场景

- **地理围栏**：判断用户/骑手是否在特定区域内（配送区、限速区）
- **行政区划**：省、市、区县的边界多边形
- **配送范围**：外卖、快递的配送区域多边形
- **园区/楼栋**：建筑物轮廓、园区围界
- **风险区域**：疫情管控区域、施工禁行区等

## 常见问题

**POLYGON 和 LINESTRING 的闭合版本有什么区别？**

闭合的 LINESTRING（首尾点相同）在几何语义上只是一条线，没有面积；POLYGON 明确表示一个封闭的多边形区域，有内外之分，可以计算面积和包含关系。`ST_Contains`、`ST_Within` 等包含关系判断只能用于 POLYGON，不适用于 LINESTRING。

**如何判断 POLYGON 的有效性？**

无效 POLYGON 包括：环不闭合、自交、内环与外环相交等情况。可用 `ST_IsValid()` 检查，用 `ST_MakeValid()` 修复（MySQL 8.0+）。

---

## 注意事项

- POLYGON 的外环点序应为逆时针（CCW），内环（孔洞）应为顺时针（CW）。MySQL 不强制这个顺序，但某些空间函数的正确性依赖于正确的点序方向。
- 在 SRID 4326 中，`ST_Area` 返回度² 而非平方千米，不能直接用于面积比较。要得到平方米，可先投影到 SRID 3857，或在应用层换算。

---

## 总结

POLYGON 是 MySQL 中表示封闭面状区域的空间类型，由外边界和可选的内孔洞环组成，每个环必须闭合（首尾坐标相同）。它最常见的应用是地理围栏（`ST_Contains`/`ST_Within` 判断点在区域内）和行政区划/配送范围的存储。配合 SPATIAL INDEX 可以高效处理大量区域的包含关系查询。
