# 空间参考系统标识 SRID

SRID（Spatial Reference System Identifier）是空间参考系统的唯一标识号，用于定义空间数据所在的坐标系统和投影方式。MySQL 8.0 起要求空间类型列显式声明 SRID，使空间计算结果更准确可靠。

---

## 什么是空间参考系统

空间参考系统（SRS，Spatial Reference System）定义了如何将地球表面上的位置用坐标来表示，包括：
- 使用哪种地球椭球体模型（如 WGS84）
- 坐标的单位（度、米等）
- 如何将三维球面投影到二维平面（投影方式）

不同 SRID 的坐标值含义不同，混用不同 SRID 的空间数据会导致距离、面积计算错误。

---

## 常用 SRID

| SRID | 名称 | 特点 | 适用场景 |
|------|------|------|---------|
| 0 | 无坐标系（笛卡尔）| 平面坐标，无地理意义 | 测试、非地理数据 |
| 4326 | WGS84 | 地理坐标（度），GPS 标准 | 地理位置数据（最常用）|
| 3857 | Web Mercator | 投影坐标（米），墨卡托投影 | 网络地图瓦片，面积/距离计算 |
| 4490 | CGCS2000 | 中国国家大地坐标系 | 国内政府地理信息系统 |

## MySQL 中 SRID 的使用

```sql
-- 查询 MySQL 支持的所有 SRS
SELECT srs_id, srs_name, definition FROM information_schema.ST_SPATIAL_REFERENCE_SYSTEMS
WHERE srs_id IN (0, 4326, 3857)
ORDER BY srs_id;

-- 查看具体 SRS 信息
SELECT * FROM information_schema.ST_SPATIAL_REFERENCE_SYSTEMS WHERE srs_id = 4326;
```

## 列上指定 SRID

```sql
-- MySQL 8.0 起，建议为空间列指定 SRID
-- 指定 SRID 后，该列只能存储同一 SRID 的空间对象

CREATE TABLE locations (
    id       INT UNSIGNED NOT NULL AUTO_INCREMENT,
    name     VARCHAR(100) NOT NULL,
    position POINT NOT NULL SRID 4326,  -- 只接受 WGS84 坐标的 POINT
    PRIMARY KEY (id),
    SPATIAL INDEX idx_pos (position)
);

-- 插入数据时必须提供 SRID 4326 的数据
INSERT INTO locations (name, position) VALUES
('测试点', ST_GeomFromText('POINT(116.4 39.9)', 4326));

-- 尝试插入不同 SRID 会报错
INSERT INTO locations (name, position) VALUES
('错误点', ST_GeomFromText('POINT(116.4 39.9)', 0));
-- ERROR 3643: The SRID of the geometry (0) does not match the SRID of the column (4326).

-- SRID 为 0（无约束）的列接受任意 SRID 的数据
CREATE TABLE geo_free (
    id    INT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
    shape GEOMETRY NOT NULL  -- 无 SRID 约束，接受任意 SRID
);
```

## SRID 4326 vs SRID 0 的计算差异

```sql
-- SRID 0（笛卡尔坐标）：ST_Distance 返回欧几里得距离（坐标单位）
SET @p1 = ST_GeomFromText('POINT(0 0)', 0);
SET @p2 = ST_GeomFromText('POINT(3 4)', 0);
SELECT ST_Distance(@p1, @p2);  -- 5.0（勾股定理：sqrt(3²+4²)）

-- SRID 4326（地理坐标）：ST_Distance 返回度数（非米）
SET @beijing  = ST_GeomFromText('POINT(116.4 39.9)', 4326);
SET @shanghai = ST_GeomFromText('POINT(121.5 31.2)', 4326);
SELECT ST_Distance(@beijing, @shanghai);  -- 约 10.x（度数，无物理意义）

-- SRID 4326：ST_Distance_Sphere 返回球面距离（米）
SELECT ST_Distance_Sphere(@beijing, @shanghai);  -- 约 1068 千米（米）
-- 约 1068000 米

-- 投影到 SRID 3857 后 ST_Distance 返回米
SELECT ST_Distance(
    ST_Transform(ST_GeomFromText('POINT(116.4 39.9)', 4326), 3857),
    ST_Transform(ST_GeomFromText('POINT(121.5 31.2)', 4326), 3857)
);  -- 投影坐标系下的米数（有一定畸变，不如 ST_Distance_Sphere 精确）
```

## 坐标系转换

```sql
-- ST_Transform：在不同 SRID 之间转换坐标
-- 将 WGS84（4326）坐标转为 Web Mercator（3857）
SELECT ST_AsText(
    ST_Transform(ST_GeomFromText('POINT(116.4 39.9)', 4326), 3857)
);
-- 输出：POINT(12954073.59... 4848055.43...)（3857 坐标，单位米）

-- 将 3857 坐标转回 4326
SELECT ST_AsText(
    ST_Transform(ST_GeomFromText('POINT(12954073.59 4848055.43)', 3857), 4326)
);
-- 输出：POINT(116.4 39.9)（近似）
```

## SPATIAL INDEX 与 SRID 的关系

```sql
-- SPATIAL INDEX 要求列为 NOT NULL 且有明确 SRID（或 SRID 0）
-- MySQL 8.0 起，SRID 不为 0 时，空间索引才能使用正确的地理计算

-- 以下创建可以正确利用空间索引做地理查询
CREATE TABLE shops (
    id   INT PRIMARY KEY AUTO_INCREMENT,
    pos  POINT NOT NULL SRID 4326,
    SPATIAL INDEX idx_pos (pos)
);

-- SRID 不同的数据不能插入指定了 SRID 的列，这保证了索引数据的 SRID 一致性
```

## 适用场景

理解 SRID 对以下场景有直接影响：
- **附近搜索**：必须使用 `ST_Distance_Sphere`（SRID 4326）或投影坐标（SRID 3857）才能得到正确的米制距离
- **面积计算**：地理面积计算需要在适当的投影坐标系（如 3857）下进行
- **坐标精确性**：不同 SRID 的坐标值范围和精度不同，混用会导致坐标偏移

## 常见问题

**中国地图常用的坐标系（GCJ-02、BD-09）有对应的 SRID 吗？**

GCJ-02（火星坐标系，高德/腾讯使用）和 BD-09（百度坐标系）没有正式的 SRID 定义，因为它们是中国特有的加密偏移坐标系，不在国际标准 EPSG 体系内。在 MySQL 中存储时通常用 SRID 4326，但坐标值填入的是 GCJ-02 或 BD-09 的坐标，坐标系转换在应用层完成。

**MySQL 支持自定义 SRID 吗？**

MySQL 8.0+ 支持通过 `ST_SRID` 函数设置 SRID，也支持通过 `CREATE SPATIAL REFERENCE SYSTEM` 定义自定义 SRS（需要 SUPER 权限）。

---

## 注意事项

- 列上指定了 SRID 后，该列只接受该 SRID 的空间对象，混用会报错。这是优点（确保数据一致性），也是约束（迁移不同坐标系数据时需要注意）。
- SRID 0（笛卡尔坐标系）和 SRID 4326 的空间函数计算语义不同，在生产代码中不要混用同一段距离计算逻辑处理不同 SRID 的数据。

---

## 总结

SRID 是空间参考系统的标识号，定义了空间数据的坐标含义。`SRID 4326`（WGS84）是地理位置数据的国际标准，用于 GPS 坐标；`SRID 3857`（Web Mercator）是网络地图的投影标准，适合距离/面积计算；`SRID 0` 是无地理意义的笛卡尔坐标系。MySQL 8.0 起推荐在空间列上显式声明 SRID，以保证数据一致性和空间函数计算的正确性。
