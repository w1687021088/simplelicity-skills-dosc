# LINESTRING 线类型

LINESTRING 表示由两个或多个点按顺序连接而成的折线，是 MySQL 空间类型中用于描述线状地物的类型。常见的应用包括道路路径、行驶轨迹、河流走向等。

---

## 基本特性

| 属性 | 值 |
|------|---|
| 最少点数 | 2 个点 |
| WKT 格式 | `LINESTRING(x1 y1, x2 y2, x3 y3, ...)` |
| 是否闭合 | 不要求闭合（闭合的 LINESTRING 不等于 POLYGON）|
| 存储内容 | 有序的点序列 |

---

## 创建示例

```sql
-- 路线规划记录
CREATE TABLE routes (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
    name        VARCHAR(200) NOT NULL,
    path        LINESTRING NOT NULL SRID 4326 COMMENT '路线路径',
    distance_m  DOUBLE COMMENT '路线长度（米）',
    PRIMARY KEY (id),
    SPATIAL INDEX idx_path (path)
);

-- 骑手轨迹
CREATE TABLE rider_tracks (
    id          BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
    rider_id    INT UNSIGNED NOT NULL,
    track       LINESTRING NOT NULL SRID 4326 COMMENT '行驶轨迹',
    recorded_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id)
);

-- 插入路线数据
INSERT INTO routes (name, path, distance_m) VALUES (
    '北京二环路东段',
    ST_GeomFromText('LINESTRING(116.4074 39.9200, 116.4200 39.9300, 116.4350 39.9280, 116.4480 39.9150)', 4326),
    NULL
);

-- 计算并更新距离
UPDATE routes SET distance_m = ST_Length(ST_Transform(path, 3857)) WHERE id = 1;
-- 注意：SRID 4326 下 ST_Length 返回度数，需要转换到投影坐标系（如 SRID 3857）才能得到米
```

## 常用操作

```sql
-- 提取 LINESTRING 的端点
SET @line = ST_GeomFromText('LINESTRING(116.4 39.9, 116.45 39.92, 116.5 39.95)', 4326);

SELECT ST_AsText(ST_StartPoint(@line)) AS start_pt;  -- POINT(116.4 39.9)
SELECT ST_AsText(ST_EndPoint(@line))   AS end_pt;    -- POINT(116.5 39.95)

-- 获取点数量
SELECT ST_NumPoints(@line);  -- 3

-- 获取第 N 个点（从 1 开始）
SELECT ST_AsText(ST_PointN(@line, 2));  -- POINT(116.45 39.92)

-- 计算线的长度（在投影坐标系中得到米）
-- SRID 3857 是 Web Mercator 投影，单位为米
SELECT ST_Length(ST_GeomFromText('LINESTRING(0 0, 0 1, 1 1)', 0));  -- 笛卡尔坐标下的长度

-- 判断两条线是否相交
SET @line1 = ST_GeomFromText('LINESTRING(0 0, 2 2)', 0);
SET @line2 = ST_GeomFromText('LINESTRING(0 2, 2 0)', 0);
SELECT ST_Intersects(@line1, @line2);  -- 1（相交）

-- 获取两条线的交点
SELECT ST_AsText(ST_Intersection(@line1, @line2));  -- POINT(1 1)
```

## 适用场景

- **路线/轨迹存储**：用户行驶轨迹、快递员配送路线
- **道路网络**：地图中的道路几何数据
- **管道/电缆**：水管、电缆的走线路径
- **行政边界**：行政区划的边界线（非封闭时）

---

## 常见问题

**LINESTRING 可以自交（自己和自己相交）吗？**

可以存储自交的 LINESTRING，但它在几何拓扑上是无效的（`ST_IsValid()` 返回 0）。某些空间运算（如求面积、缓冲区）在自交 LINESTRING 上可能产生意外结果，应尽量确保 LINESTRING 不自交。

---

## 注意事项

- SRID 4326 地理坐标系下，`ST_Length` 返回的是角度（度数）而非米，如需得到以米为单位的线段长度，应转换到适当的投影坐标系（如 SRID 3857 Web Mercator）后再计算，或直接用 `ST_Distance_Sphere` 逐段累加距离。
- 存储大量点的 LINESTRING（如几千个 GPS 轨迹点）会使数据行体积大，考虑对轨迹做点抽稀（Douglas-Peucker 算法）后再存储。

---

## 总结

LINESTRING 由两个以上有序坐标点连接而成，用于表示线状地物（道路、轨迹、河流等）。配合 `ST_StartPoint`、`ST_EndPoint`、`ST_PointN`、`ST_NumPoints` 等函数可以操作线上的点；`ST_Intersects` 判断两线是否相交；SRID 4326 下计算长度需注意单位转换。
