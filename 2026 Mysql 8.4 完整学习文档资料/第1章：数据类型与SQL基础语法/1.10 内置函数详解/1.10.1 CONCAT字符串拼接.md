# CONCAT 字符串拼接

`CONCAT()` 函数将两个或多个字符串拼接为一个字符串。它是 MySQL 中最基础、使用最频繁的字符串函数之一，广泛用于构建动态 SQL、格式化输出、组合字段值等场景。

---

## 语法

```sql
CONCAT(str1, str2, ...)
CONCAT_WS(separator, str1, str2, ...)  -- 带分隔符的拼接
```

---

## 基本示例

```sql
-- 基础拼接
SELECT CONCAT('Hello', ' ', 'World');
-- 结果：Hello World

-- 拼接列值与字符串
SELECT CONCAT(first_name, ' ', last_name) AS full_name FROM users;
-- 将 first_name 和 last_name 拼接成完整姓名

-- 拼接多个列
SELECT CONCAT(city, ', ', province, ', ', country) AS full_address FROM addresses;

-- CONCAT 中有 NULL 时，整个结果为 NULL
SELECT CONCAT('abc', NULL, 'def');
-- 结果：NULL（任意参数为 NULL，结果就是 NULL）
```

---

## CONCAT_WS（带分隔符拼接，自动跳过 NULL）

```sql
-- CONCAT_WS(separator, str1, str2, ...)
-- separator：每个字符串之间插入的分隔符
-- 自动跳过 NULL 值（这是与 CONCAT 的重要区别）

SELECT CONCAT_WS('-', '2026', '03', '15');
-- 结果：2026-03-15

SELECT CONCAT_WS(', ', city, NULL, country);
-- 结果：city值, country值（NULL 被跳过，不产生多余的逗号）

-- 拼接用户完整地址（部分字段可能为 NULL）
SELECT CONCAT_WS(', ', address_line1, address_line2, city, province, postal_code)
    AS full_address
FROM addresses;
-- NULL 的地址行不会出现在结果中，不会有多余逗号
```

---

## 常见应用场景

```sql
-- 场景1：构建全名（CONCAT 方式需要处理 NULL）
SELECT 
    COALESCE(CONCAT(first_name, ' ', last_name), first_name, last_name, '未知') AS full_name
FROM users;

-- 场景2：构建动态 SQL（在存储过程中）
SET @table_name = 'orders';
SET @sql = CONCAT('SELECT COUNT(*) FROM ', @table_name, ' WHERE status = 1');
PREPARE stmt FROM @sql;
EXECUTE stmt;
DEALLOCATE PREPARE stmt;

-- 场景3：生成 CSV 格式的多列值
SELECT CONCAT('"', REPLACE(name, '"', '""'), '"', ',',
              '"', email, '"', ',',
              '"', phone, '"') AS csv_row
FROM users;

-- 场景4：拼接 HTML/URL
SELECT CONCAT('<a href="/user/', id, '">', username, '</a>') AS user_link
FROM users;
```

## GROUP_CONCAT（分组内多行拼接）

```sql
-- GROUP_CONCAT 将分组内多行的值拼接成一个字符串
SELECT dept_id,
    GROUP_CONCAT(name ORDER BY name SEPARATOR ', ') AS employee_names
FROM employees
GROUP BY dept_id;
-- 技术部: 李四, 张三
-- 市场部: 王五

-- 带去重
SELECT dept_id,
    GROUP_CONCAT(DISTINCT city ORDER BY city SEPARATOR '|') AS cities
FROM employees
GROUP BY dept_id;

-- 修改最大长度（默认 1024 字节）
SET SESSION group_concat_max_len = 65536;
```

---

## 适用场景

- **格式化输出**：将多列组合为可读的字符串（全名、完整地址、标签列表）
- **动态 SQL 构建**：在存储过程中拼接 SQL 语句
- **数据导出**：生成 CSV 行或其他格式
- **GROUP_CONCAT**：将一对多关系的数据合并为单行显示

---

## 常见问题

**CONCAT 和 `||` 操作符有什么区别？**

MySQL 默认不支持 `||` 作为字符串拼接（它是逻辑 OR）。如果 `PIPES_AS_CONCAT` SQL 模式开启，则 `||` 可用于字符串拼接。生产代码中推荐明确使用 `CONCAT()` 函数，避免依赖 SQL 模式。

---

## 注意事项

- `CONCAT()` 中只要有一个参数是 NULL，整个结果就是 NULL。处理可能含 NULL 的列时，改用 `CONCAT_WS()` 或用 `COALESCE(col, '')` 将 NULL 转为空字符串后再拼接。
- `GROUP_CONCAT` 的结果最大长度由 `group_concat_max_len` 控制，默认仅 1024 字节，对于内容多的分组需要适当调大。

---

## 总结

`CONCAT(str1, str2, ...)` 将多个字符串拼接，任意参数为 NULL 时结果为 NULL。`CONCAT_WS(sep, str1, str2, ...)` 带分隔符拼接且自动跳过 NULL，更适合可能含 NULL 的场景。`GROUP_CONCAT` 将分组内多行值拼接为单个字符串，是多行聚合为列的常用手段。
