# 其他常用聚合函数（COUNT, SUM, AVG, MAX, MIN）

聚合函数对一组值进行计算，返回单个汇总值。它们通常与 GROUP BY 一起使用，将数据按组聚合。如果不使用 GROUP BY，聚合函数会对整张表的所有行进行计算。这五个聚合函数是 SQL 中使用频率最高的，几乎所有业务报表和数据分析都离不开它们。

---

## 函数一览

| 函数 | 作用 | NULL 处理 | 返回类型 |
|------|------|-----------|---------|
| COUNT(expr) | 统计非 NULL 的行数 | 忽略 NULL | BIGINT |
| COUNT(*) | 统计所有行数（包含 NULL） | 不忽略 | BIGINT |
| SUM(expr) | 求和 | 忽略 NULL | DECIMAL（整数/DECIMAL参数）或 DOUBLE（浮点参数） |
| AVG(expr) | 求平均值 | 忽略 NULL | DECIMAL 或 DOUBLE |
| MAX(expr) | 求最大值 | 忽略 NULL | 与参数类型一致 |
| MIN(expr) | 求最小值 | 忽略 NULL | 与参数类型一致 |

所有聚合函数（除 COUNT(*)）在计算时都会跳过 NULL 值，这是 SQL 标准规定的行为。

## COUNT 函数

COUNT 有两种常见用法：`COUNT(*)` 统计所有行（包括 NULL 行），`COUNT(expr)` 只统计 expr 不为 NULL 的行。

```sql
-- COUNT(*)：统计总行数（包括 salary 为 NULL 的行）
SELECT COUNT(*) AS total_employees FROM employees;
-- 结果：8

-- COUNT(salary)：只统计 salary 不为 NULL 的行
SELECT COUNT(salary) AS has_salary FROM employees;
-- 结果：7（孙八的 salary 为 NULL，被排除）

-- COUNT(DISTINCT dept)：统计不重复的部门数量
SELECT COUNT(DISTINCT dept) AS dept_count FROM employees;
-- 结果：3

-- 按部门统计人数
SELECT dept, COUNT(*) AS head_count
FROM employees
GROUP BY dept;
-- +---------+------------+
-- | dept    | head_count |
-- +---------+------------+
-- | 技术部  |          3 |
-- | 市场部  |          3 |
-- | 财务部  |          2 |
-- +---------+------------+
```

## SUM 函数

SUM 对一组数值求和。参数必须是数值类型（或能隐式转换为数值）。SUM 忽略 NULL 值。

```sql
-- 全公司薪资总额（NULL 被忽略，不参与计算）
SELECT SUM(salary) AS total_salary FROM employees;
-- 结果：110000.00（7 个有薪资的人之和）

-- 按部门统计薪资总额
SELECT dept, SUM(salary) AS dept_salary
FROM employees
GROUP BY dept;
-- +---------+-------------+
-- | dept    | dept_salary |
-- +---------+-------------+
-- | 技术部  |    55000.00 |
-- | 市场部  |    26000.00 |  -- 孙八的 NULL 被忽略
-- | 财务部  |    29000.00 |
-- +---------+-------------+

-- SUM 配合条件表达式：统计月薪超过 15000 的人数
SELECT SUM(CASE WHEN salary > 15000 THEN 1 ELSE 0 END) AS high_salary_count
FROM employees;
-- 结果：3（李四18000、王五22000、周九16000）

-- SUM(DISTINCT)：对不重复的值求和
SELECT SUM(DISTINCT salary) AS unique_salary_sum FROM employees;
-- 如果有重复薪资值，只算一次
```

## AVG 函数

AVG 计算一组值的算术平均值。它等价于 SUM(expr) / COUNT(expr)，注意分母是非 NULL 的行数，不是总行数。

```sql
-- 全公司平均薪资
SELECT AVG(salary) AS avg_salary FROM employees;
-- 结果：15714.285714（110000 / 7，不是 110000 / 8）
-- 孙八的 NULL 不参与分母计算

-- 按部门统计平均薪资
SELECT dept,
    AVG(salary) AS avg_salary,
    COUNT(salary) AS sample_size   -- 显示参与计算的样本数
FROM employees
GROUP BY dept;
-- +---------+-------------+-------------+
-- | dept    | avg_salary  | sample_size |
-- +---------+-------------+-------------+
-- | 技术部  | 18333.33    |           3 |
-- | 市场部  | 13000.00    |           2 |  -- 只有赵六和钱七参与
-- | 财务部  | 14500.00    |           2 |
-- +---------+-------------+-------------+

-- AVG 在 HAVING 子句中使用（筛选平均薪资超过 15000 的部门）
SELECT dept, AVG(salary) AS avg_salary
FROM employees
GROUP BY dept
HAVING AVG(salary) > 15000;
-- 只返回技术部（avg 18333.33）
```

## MAX 和 MIN 函数

MAX 和 MIN 不仅适用于数值，也适用于字符串（按字典序比较）和日期时间类型。

```sql
-- 最高和最低薪资
SELECT
    MAX(salary) AS max_salary,
    MIN(salary) AS min_salary,
    MAX(salary) - MIN(salary) AS salary_range
FROM employees;
-- max_salary: 22000.00, min_salary: 12000.00, salary_range: 10000.00

-- 最早和最晚入职日期
SELECT
    MIN(hire_date) AS earliest_hire,
    MAX(hire_date) AS latest_hire
FROM employees;
-- earliest_hire: 2020-01-10, latest_hire: 2024-09-01

-- 按部门统计薪资范围
SELECT dept,
    MIN(salary) AS min_sal,
    MAX(salary) AS max_sal,
    MAX(salary) - MIN(salary) AS sal_diff
FROM employees
GROUP BY dept;

-- 字符串列的 MAX/MIN（按字典序）
SELECT MAX(name) AS last_name, MIN(name) AS first_name FROM employees;
-- 按照 UTF8 字符集的排序规则比较

-- 查找薪资最高的员工（子查询方式）
SELECT name, salary
FROM employees
WHERE salary = (SELECT MAX(salary) FROM employees);
-- 结果：王五, 22000.00
```

## 多个聚合函数组合使用

在一条 SQL 中可以同时使用多个聚合函数，构建完整的统计报告。

```sql
-- 完整的部门统计报告
SELECT
    dept                       AS 部门,
    COUNT(*)                   AS 总人数,
    COUNT(salary)              AS 有薪人数,
    SUM(salary)                AS 薪资总额,
    AVG(salary)                AS 平均薪资,
    MIN(salary)                AS 最低薪资,
    MAX(salary)                AS 最高薪资,
    MAX(salary) - MIN(salary)  AS 薪资极差
FROM employees
GROUP BY dept
ORDER BY 薪资总额 DESC;

-- 全公司总览（不加 GROUP BY，对全表聚合）
SELECT
    COUNT(*)        AS 总人数,
    SUM(salary)     AS 薪资总额,
    ROUND(AVG(salary), 2) AS 平均薪资,
    MIN(hire_date)  AS 最早入职,
    MAX(hire_date)  AS 最近入职
FROM employees;
```

## 聚合函数作为窗口函数

MySQL 8.0+ 中，这五个聚合函数都可以配合 OVER() 子句作为窗口函数使用，在不折叠行的情况下计算聚合值。

```sql
-- 每个员工显示自己的薪资和所在部门的平均薪资
SELECT
    name,
    dept,
    salary,
    AVG(salary) OVER (PARTITION BY dept) AS dept_avg,
    salary - AVG(salary) OVER (PARTITION BY dept) AS diff_from_avg
FROM employees
WHERE salary IS NOT NULL;

-- 按入职日期排序，计算累计薪资总额
SELECT
    name,
    hire_date,
    salary,
    SUM(salary) OVER (ORDER BY hire_date) AS running_total
FROM employees
WHERE salary IS NOT NULL
ORDER BY hire_date;

-- 显示每个员工在部门中的薪资排名信息
SELECT
    name,
    dept,
    salary,
    MIN(salary) OVER (PARTITION BY dept) AS dept_min,
    MAX(salary) OVER (PARTITION BY dept) AS dept_max,
    COUNT(*)    OVER (PARTITION BY dept) AS dept_size
FROM employees
WHERE salary IS NOT NULL;
```

## GROUP BY 与 HAVING 的配合

GROUP BY 将数据分组，聚合函数对每组计算。HAVING 用于过滤分组后的结果（WHERE 在分组前过滤行，HAVING 在分组后过滤组）。

```sql
-- WHERE 和 HAVING 的区别
-- WHERE：在聚合之前过滤行
-- HAVING：在聚合之后过滤组

-- 查找平均薪资超过 14000 且至少有 2 人有薪资的部门
SELECT
    dept,
    COUNT(salary) AS cnt,
    AVG(salary) AS avg_sal
FROM employees
WHERE salary IS NOT NULL    -- WHERE 先过滤掉 NULL 薪资的行
GROUP BY dept
HAVING COUNT(salary) >= 2   -- HAVING 再过滤掉不足 2 人的组
   AND AVG(salary) > 14000;
```

## NULL 值对聚合函数的影响

理解 NULL 的处理方式对正确使用聚合函数至关重要。

```sql
-- 对比 COUNT(*) 和 COUNT(salary)
SELECT
    COUNT(*)       AS total_rows,     -- 8（包含 NULL 行）
    COUNT(salary)  AS non_null_rows,  -- 7（排除 NULL）
    SUM(salary)    AS total,          -- 110000
    AVG(salary)    AS avg_excl_null,  -- 110000/7 = 15714.29
    SUM(salary) / COUNT(*) AS avg_incl_null  -- 110000/8 = 13750.00
FROM employees;
-- avg_excl_null 和 avg_incl_null 结果不同！
-- AVG 默认忽略 NULL，如果想把 NULL 当 0 参与平均值计算：

SELECT AVG(IFNULL(salary, 0)) AS avg_with_zero FROM employees;
-- 结果：110000/8 = 13750.00（NULL 被替换为 0 后参与计算）

-- 所有值都是 NULL 时，聚合函数返回什么？
SELECT
    COUNT(salary),  -- 0
    SUM(salary),    -- NULL（不是 0）
    AVG(salary),    -- NULL
    MAX(salary),    -- NULL
    MIN(salary)     -- NULL
FROM employees
WHERE dept = '不存在的部门';
-- COUNT 返回 0，其他聚合函数在无行参与计算时返回 NULL
```

## 适用场景

- **COUNT**：统计记录数、去重计数、判断数据是否存在（COUNT > 0）
- **SUM**：销售额汇总、库存量统计、流量统计等需要求和的场景
- **AVG**：计算平均成绩、平均响应时间、平均单价等
- **MAX/MIN**：查找最高分、最低价、最早/最晚日期、最大/最小 ID 等

## 常见问题

**COUNT(1) 和 COUNT(*) 有性能区别吗？**

在 MySQL 8.0+ 中，`COUNT(1)` 和 `COUNT(*)` 的执行计划完全相同，优化器会统一处理。两者性能没有差异，选哪个都可以。`COUNT(*)` 是 SQL 标准推荐的写法。

**SUM 和 AVG 能用于日期时间列吗？**

不能直接用。SUM 和 AVG 会将日期时间值转换为数值，得到的结果没有实际意义。如果需要对时间求和（比如计算总工时），应先转换为秒数再计算：

```sql
-- 错误做法
SELECT SUM(work_time) FROM tasks;  -- 结果无意义

-- 正确做法：先转为秒，聚合后再转回时间
SELECT SEC_TO_TIME(SUM(TIME_TO_SEC(work_time))) AS total_work
FROM tasks;
```

**GROUP BY 中未出现的列能写在 SELECT 中吗？**

MySQL 8.0 默认开启 `ONLY_FULL_GROUP_BY` 模式，SELECT 中的非聚合列必须出现在 GROUP BY 中，否则报错。这是 SQL 标准要求，避免查询结果不确定。

```sql
-- 会报错（name 不在 GROUP BY 中）
SELECT name, dept, AVG(salary) FROM employees GROUP BY dept;
-- ERROR 1055: 'name' isn't in GROUP BY

-- 正确做法
SELECT dept, AVG(salary) FROM employees GROUP BY dept;
```

## 注意事项

- SUM 和 AVG 的返回类型取决于输入类型：整数和 DECIMAL 参数返回 DECIMAL，FLOAT/DOUBLE 参数返回 DOUBLE。在精度要求高的金融场景中，确保参与计算的列是 DECIMAL 类型。
- 当表中数据量非常大时，COUNT(*) 在 InnoDB 中需要遍历索引来计数（InnoDB 不像 MyISAM 那样维护精确行数），可能会比较慢。可以通过 `SHOW TABLE STATUS` 获取近似行数（Rows 字段），或者维护一张计数器表。
- 在窗口函数中使用聚合函数时，不要和普通聚合混用。一条 SQL 中如果同时有 GROUP BY 聚合和窗口函数，窗口函数是在 GROUP BY 聚合之后的结果集上执行的。

---

## 总结

COUNT、SUM、AVG、MAX、MIN 是 SQL 中最基础也最常用的五个聚合函数。COUNT(*) 统计所有行（含 NULL），COUNT(expr) 只统计非 NULL 行；SUM/AVG/MAX/MIN 都会忽略 NULL 值。它们与 GROUP BY 配合实现分组聚合，与 HAVING 配合过滤聚合结果，在 MySQL 8.0+ 中还可以作为窗口函数使用（配合 OVER 子句）。使用时要注意 NULL 对计算结果的影响——特别是 AVG 的分母只计算非 NULL 行数，如果需要把 NULL 当 0 处理，要用 IFNULL 显式转换。
