# SUBSTRING 字符串截取

`SUBSTRING()` 函数从字符串中提取子字符串，可以指定起始位置和长度。MySQL 中 `SUBSTRING()`、`SUBSTR()` 和 `MID()` 是完全等价的同义函数，可以互换使用。

---

## 语法

```sql
SUBSTRING(str, pos)                -- 从 pos 位置截取到末尾
SUBSTRING(str, pos, len)           -- 从 pos 位置截取 len 个字符
SUBSTRING(str FROM pos)            -- SQL 标准写法（等价于第一种）
SUBSTRING(str FROM pos FOR len)    -- SQL 标准写法（等价于第二种）

-- 等价函数
SUBSTR(str, pos, len)
MID(str, pos, len)
```

- `pos`：起始位置，从 1 开始计数（而非 0）
- 正数：从字符串左端数起；负数：从字符串右端数起
- `len`：截取的字符数（可选，不指定则截到末尾）

---

## 基本示例

```sql
-- 从第 2 个字符截取到末尾
SELECT SUBSTRING('Hello World', 2);         -- 'ello World'

-- 从第 7 个字符截取 5 个字符
SELECT SUBSTRING('Hello World', 7, 5);      -- 'World'

-- 负索引：从倒数第 5 个字符截取到末尾
SELECT SUBSTRING('Hello World', -5);        -- 'World'

-- 负索引 + 长度：从倒数第 5 个字符截取 3 个字符
SELECT SUBSTRING('Hello World', -5, 3);     -- 'Wor'

-- SQL 标准写法
SELECT SUBSTRING('Hello World' FROM 7 FOR 5); -- 'World'
```

---

## 常见应用

```sql
-- 提取手机号的中间部分（脱敏处理）
SELECT CONCAT(
    SUBSTRING(phone, 1, 3),
    '****',
    SUBSTRING(phone, -4)
) AS masked_phone FROM users;
-- 13812345678 → 138****5678

-- 提取订单号的年月前缀
SELECT order_no,
    SUBSTRING(order_no, 1, 6) AS ym_prefix  -- 如 202603
FROM orders;

-- 从 JSON 字符串中提取固定格式的部分（不推荐，应用 JSON 函数更好）
-- 但在特殊场景如日志分析中 SUBSTRING 很实用

-- LEFT 和 RIGHT（SUBSTRING 的特化版本）
SELECT LEFT('Hello World', 5);    -- 'Hello'（等价于 SUBSTRING(str, 1, 5)）
SELECT RIGHT('Hello World', 5);   -- 'World'（等价于 SUBSTRING(str, -5)）
```

## 配合 LOCATE/INSTR 动态截取

```sql
-- LOCATE(substr, str)：返回 substr 在 str 中第一次出现的位置
-- 结合 SUBSTRING 实现动态截取

-- 提取 @ 之前的用户名（email -> username）
SELECT 
    email,
    SUBSTRING(email, 1, LOCATE('@', email) - 1) AS username
FROM users;
-- 'alice@example.com' → 'alice'

-- 提取 @ 之后的域名
SELECT 
    email,
    SUBSTRING(email, LOCATE('@', email) + 1) AS domain
FROM users;
-- 'alice@example.com' → 'example.com'

-- INSTR(str, substr)：等价于 LOCATE，参数顺序不同
SELECT INSTR('Hello World', 'World');  -- 7
```

## 字节截取（SUBSTRING 按字符 vs SUBSTR_BYTES）

```sql
-- SUBSTRING 按字符计数（Unicode 字符算 1 个字符，不管占几个字节）
SELECT LENGTH(SUBSTRING('你好世界', 1, 2));      -- 2个字符，LENGTH 返回 6（UTF-8 每个汉字3字节）
SELECT CHAR_LENGTH(SUBSTRING('你好世界', 1, 2)); -- 2（字符数）

-- 如果需要按字节截取（不常用），用 SUBSTRING 配合 BINARY 或 MID 的字节模式
```

## 适用场景

- **数据脱敏**：手机号、身份证号、银行卡号的中间部分替换为 `*`
- **字符串解析**：从固定格式的字符串中提取特定片段
- **前缀/后缀匹配**：提取字段的前 N 或后 N 个字符用于分类或过滤
- **动态截取**：结合 LOCATE/INSTR 从分隔符位置动态截取

---

## 常见问题

**pos 超出字符串长度时返回什么？**

返回空字符串 `''`（不报错）。例如 `SUBSTRING('abc', 10)` 返回 `''`。

---

## 注意事项

- `SUBSTRING` 的位置从 **1** 开始，不是 0。传入 0 时等同于传入 1（从第一个字符开始）。
- 处理多字节字符集（如 UTF-8 中文）时，`SUBSTRING` 按**字符**计数，不按字节。`SUBSTR(str, 1, 2)` 对中文字符串截取前 2 个汉字（6 字节），而不是前 2 字节。

---

## 总结

`SUBSTRING(str, pos[, len])` 从字符串 str 的第 pos 个字符开始截取，不指定 len 则截到末尾。位置从 1 开始计数，支持负数索引（从末尾倒数）。`LEFT(str, n)` 和 `RIGHT(str, n)` 是常用的简化写法。配合 `LOCATE()` 可实现基于分隔符的动态截取。按字符计数，对多字节字符集友好。
