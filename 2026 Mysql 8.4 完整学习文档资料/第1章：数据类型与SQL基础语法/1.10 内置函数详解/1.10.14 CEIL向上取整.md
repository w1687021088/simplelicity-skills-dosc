# CEIL 向上取整

`CEIL()` 函数返回不小于参数值的最小整数，即向上取整（天花板函数）。`CEILING()` 是其完全等价的别名。它与 `FLOOR()`（向下取整）和 `ROUND()`（四舍五入）一起构成 MySQL 的三种基本舍入函数。

---

## 语法

```sql
CEIL(X)
CEILING(X)     -- 完全等价于 CEIL(X)
```

---

## 基本示例

```sql
-- 正数向上取整
SELECT CEIL(3.0);    -- 3（已经是整数，不变）
SELECT CEIL(3.1);    -- 4（大于 3 的最小整数）
SELECT CEIL(3.9);    -- 4
SELECT CEIL(3.01);   -- 4

-- 负数向上取整（向 0 的方向）
SELECT CEIL(-3.1);   -- -3（大于 -3.1 的最小整数是 -3）
SELECT CEIL(-3.9);   -- -3

-- 比较
SELECT FLOOR(3.5), CEIL(3.5), ROUND(3.5);
-- 3  |  4  |  4
SELECT FLOOR(-3.5), CEIL(-3.5), ROUND(-3.5);
-- -4  |  -3  |  -4
```

## 常见业务场景

```sql
-- 分页总页数计算（向上取整确保最后一页不丢失）
SELECT CEIL(COUNT(*) / 20.0) AS total_pages FROM orders;
-- 如果有 105 条记录，每页 20 条，需要 6 页（CEIL(105/20) = CEIL(5.25) = 6）
-- 不用 CEIL 的话 INT(105/20) = 5 页，会丢失最后 5 条

-- 按天收费的租赁费计算（不足一天按一天计）
SELECT order_id,
    start_at,
    return_at,
    CEIL(TIMESTAMPDIFF(HOUR, start_at, return_at) / 24.0) AS rental_days,
    CEIL(TIMESTAMPDIFF(HOUR, start_at, return_at) / 24.0) * daily_rate AS total_fee
FROM rentals;
-- 租了 25 小时 → CEIL(25/24) = 2 天

-- 成绩进位（不足 10 分进到下一个 10 分组）
SELECT student_id, score,
    CEIL(score / 10.0) * 10 AS score_group
FROM exam_results;
-- score=81 → CEIL(8.1)*10 = 9*10 = 90（归入 90 分档）

-- 保证库存批次数（每批最多 100 件，计算需要多少批）
SELECT product_id,
    stock_qty,
    CEIL(stock_qty / 100.0) AS batch_count
FROM inventory;
```

## CEIL vs FLOOR vs ROUND vs TRUNCATE

```sql
-- 对正数 3.2 的处理
SELECT CEIL(3.2),       -- 4（向上：大于等于 3.2 的最小整数）
       FLOOR(3.2),      -- 3（向下：小于等于 3.2 的最大整数）
       ROUND(3.2),      -- 3（四舍五入）
       TRUNCATE(3.2,0); -- 3（直接截断小数）

-- 对负数 -3.2 的处理
SELECT CEIL(-3.2),       -- -3（向上：大于等于 -3.2 的最小整数，朝 0 方向）
       FLOOR(-3.2),      -- -4（向下：小于等于 -3.2 的最大整数，远离 0 方向）
       ROUND(-3.2),      -- -3（四舍五入）
       TRUNCATE(-3.2,0); -- -3（截断小数，朝 0 方向）
```

## 适用场景

- **分页总页数**：`CEIL(total_rows / page_size)` 确保不丢行
- **按天/批次计费**：不足一个周期按一个周期计费
- **资源分配**：最小化容器数（装 n 件物品到每个容量 m 的箱子需要 CEIL(n/m) 个箱子）
- **数据分桶**：将数据向上分配到桶

---

## 常见问题

**CEIL(3.0) 返回什么？**

返回 3。当参数本身是整数（或小数部分为 0）时，CEIL 直接返回该值，不做任何上调。

---

## 注意事项

- 当除法运算符 `/` 两端都是整数时，MySQL 会进行整数除法并截断（如 `105 / 20 = 5`，不是 5.25）。在 CEIL 中使用除法时，确保其中一个操作数是小数（如 `/ 20.0` 或 `/ 20.00`），否则 CEIL 的结果也会是错误的：`CEIL(105 / 20)` = `CEIL(5)` = 5（错误），`CEIL(105 / 20.0)` = `CEIL(5.25)` = 6（正确）。

---

## 总结

`CEIL(X)` 返回大于或等于 X 的最小整数（向上取整）。正数向上（远离 0），负数也是向上（朝向 0）。最典型用途是计算分页总页数和不足一个周期的进位计费。使用除法配合 CEIL 时，确保除数含小数点（如 `20.0`）以避免整数截断导致结果错误。
