# ABS 绝对值

`ABS()` 函数返回数值的绝对值，即去掉符号后的值。正数返回本身，负数返回其相反数，零返回零。它在数据分析、差值计算、距离度量等场景中非常实用。

---

## 语法

```sql
ABS(X)
```

---

## 基本示例

```sql
SELECT ABS(5);      -- 5
SELECT ABS(-5);     -- 5
SELECT ABS(0);      -- 0
SELECT ABS(-3.14);  -- 3.14
SELECT ABS(NULL);   -- NULL（NULL 的绝对值仍是 NULL）
```

---

## 常见业务场景

```sql
-- 场景1：找出价格偏差超过 10% 的商品（与市场均价对比）
SELECT product_id, our_price, market_avg_price,
    ABS(our_price - market_avg_price) AS price_diff,
    ROUND(ABS(our_price - market_avg_price) / market_avg_price * 100, 2) AS diff_pct
FROM price_comparison
WHERE ABS(our_price - market_avg_price) / market_avg_price > 0.1;

-- 场景2：查找两个用户位置距离（简单欧几里得距离）
SELECT u1.id AS user1, u2.id AS user2,
    SQRT(POW(u1.longitude - u2.longitude, 2) + POW(u1.latitude - u2.latitude, 2)) AS distance
FROM users u1, users u2
WHERE u1.id < u2.id  -- 避免重复对
  AND SQRT(POW(u1.longitude - u2.longitude, 2) + POW(u1.latitude - u2.latitude, 2)) < 0.01;

-- 场景3：找出库存偏差超过阈值的商品
SELECT product_id,
    actual_stock - expected_stock AS stock_diff,
    ABS(actual_stock - expected_stock) AS abs_diff
FROM inventory_check
WHERE ABS(actual_stock - expected_stock) > 10
ORDER BY abs_diff DESC;

-- 场景4：计算账户余额与目标余额的差值（不分正负）
SELECT account_id, balance, target_balance,
    ABS(balance - target_balance) AS deviation
FROM accounts
ORDER BY deviation DESC LIMIT 20;

-- 场景5：自连接中找出薪资差距（不分大小方向）
SELECT a.name AS emp1, b.name AS emp2,
    ABS(a.salary - b.salary) AS salary_diff
FROM employees a
INNER JOIN employees b ON a.dept_id = b.dept_id AND a.id < b.id
WHERE ABS(a.salary - b.salary) > 5000
ORDER BY salary_diff DESC;
```

## ABS 与 SIGN 函数

```sql
-- SIGN：返回数值的符号（-1、0 或 1）
SELECT SIGN(5);    --  1（正数）
SELECT SIGN(0);    --  0（零）
SELECT SIGN(-5);   -- -1（负数）

-- 使用 ABS 和 SIGN 重构原值
SELECT x, ABS(x) * SIGN(x) AS reconstructed FROM (SELECT -7.5 AS x) t;
-- ABS(-7.5) = 7.5，SIGN(-7.5) = -1，7.5 * (-1) = -7.5（恢复原值）

-- 应用：将差值标准化为 ±1（只保留方向信息）
SELECT order_id,
    expected_amount - actual_amount AS diff,
    SIGN(expected_amount - actual_amount) AS direction  -- 1=多收，-1=少收，0=准确
FROM payment_check;
```

## 适用场景

- **偏差检测**：找出与基准值偏差超过阈值的数据（价格偏差、库存偏差）
- **距离计算**：一维距离（数值差的绝对值）、坐标距离（配合 SQRT+POW）
- **双向对比**：不关心哪个大哪个小，只关心差距大小

## 常见问题

**ABS 对 NULL 的处理？**

`ABS(NULL)` 返回 `NULL`，与其他大多数 MySQL 函数一样，NULL 传入 NULL 传出。在计算偏差前，应先处理可能为 NULL 的列：`ABS(COALESCE(col1, 0) - COALESCE(col2, 0))`。

---

## 注意事项

- 在 WHERE 条件中使用 `ABS(col - constant) > threshold` 会导致 `col` 列上的索引失效（因为对列做了函数运算）。如果 `col` 列有索引且查询频繁，改写为范围条件：`WHERE col < constant - threshold OR col > constant + threshold`，这样可以利用索引。

---

## 总结

`ABS(X)` 返回 X 的绝对值，正数不变，负数取反，NULL 传出 NULL。常用于偏差检测、距离度量和双向差值比较。在 WHERE 中对列调用 ABS 会导致索引失效，可以改写为等价的范围条件（`col < val - threshold OR col > val + threshold`）来保留索引可用性。
