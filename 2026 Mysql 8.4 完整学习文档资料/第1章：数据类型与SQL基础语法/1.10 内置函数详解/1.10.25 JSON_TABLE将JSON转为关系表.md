# JSON_TABLE 将 JSON 转为关系表

`JSON_TABLE()` 是 MySQL 8.0 引入的强大函数，能够将 JSON 文档中的数组或嵌套结构"展开"为关系型的行列格式，可以像普通表一样在 FROM 子句中引用，与其他表进行 JOIN 操作。它是 JSON 数据与关系型查询之间最重要的桥梁。

---

## 语法

```sql
JSON_TABLE(
    json_doc,
    path
    COLUMNS (
        col_name data_type PATH col_path [DEFAULT default_val ON ERROR | ON EMPTY],
        col_name FOR ORDINALITY,           -- 生成行号（1, 2, 3...）
        NESTED PATH nested_path COLUMNS (  -- 展开嵌套数组
            ...
        )
    )
) AS alias
```

---

## 基本示例：展开 JSON 数组

```sql
-- 将 JSON 数组展开为行
SELECT * FROM JSON_TABLE(
    '[{"name":"张三","age":30},{"name":"李四","age":25}]',
    '$[*]'
    COLUMNS (
        name VARCHAR(50) PATH '$.name',
        age  INT         PATH '$.age'
    )
) AS jt;

-- 结果：
-- name | age
-- 张三 |  30
-- 李四 |  25

-- 行号（FOR ORDINALITY）
SELECT * FROM JSON_TABLE(
    '["apple","banana","cherry"]',
    '$[*]'
    COLUMNS (
        row_num INT      FOR ORDINALITY,   -- 自动生成 1, 2, 3...
        fruit   VARCHAR(50) PATH '$'       -- $：当前数组元素本身
    )
) AS jt;

-- 结果：
-- row_num | fruit
--    1    | apple
--    2    | banana
--    3    | cherry
```

## 从表的 JSON 列中展开数据

```sql
-- orders 表的 items 列存储 JSON 数组：
-- [{"product_id":1,"qty":2,"price":99.99},{"product_id":3,"qty":1,"price":199.99}]

SELECT o.id AS order_id, o.user_id, item.*
FROM orders o,
JSON_TABLE(
    o.items,
    '$[*]'
    COLUMNS (
        product_id INT            PATH '$.product_id',
        qty        INT            PATH '$.qty',
        price      DECIMAL(10,2)  PATH '$.price',
        subtotal   DECIMAL(10,2)  PATH '$.price'   -- 可以多次引用同一路径
    )
) AS item
WHERE o.status = 2;

-- 将 JSON 数组列的数据展开为明细行，可以统计、JOIN 等
```

## 展开嵌套 JSON（NESTED PATH）

```sql
-- 假设 product_json：
-- {"id":1,"name":"T恤","colors":["红","蓝"],"sizes":["S","M","L"]}

SELECT p.*
FROM JSON_TABLE(
    '{"id":1,"name":"T恤","colors":["红","蓝"],"sizes":["S","M","L"]}',
    '$'
    COLUMNS (
        product_id   INT          PATH '$.id',
        product_name VARCHAR(100) PATH '$.name',
        NESTED PATH '$.colors[*]' COLUMNS (
            color VARCHAR(20) PATH '$'
        )
    )
) AS p;

-- 结果（每个颜色一行）：
-- product_id | product_name | color
--     1      |    T恤       |  红
--     1      |    T恤       |  蓝
```

## ON ERROR 和 ON EMPTY 子句

```sql
-- 处理路径不存在（EMPTY）或类型转换失败（ERROR）
SELECT * FROM JSON_TABLE(
    '[{"name":"张三","age":30},{"name":"李四"},{"name":"王五","age":"invalid"}]',
    '$[*]'
    COLUMNS (
        name VARCHAR(50) PATH '$.name',
        age  INT         PATH '$.age'
            DEFAULT 0    ON EMPTY    -- 路径不存在时默认 0（李四没有 age）
            DEFAULT -1   ON ERROR    -- 类型转换失败时默认 -1（王五的 age 不是整数）
    )
) AS jt;

-- 结果：
-- name | age
-- 张三 |  30
-- 李四 |   0（ON EMPTY）
-- 王五 |  -1（ON ERROR）
```

## 实际应用：JSON 存储的订单明细分析

```sql
-- 统计每个商品的总销售数量和金额（从 JSON 格式的订单明细中汇总）
SELECT 
    item.product_id,
    SUM(item.qty)   AS total_qty,
    SUM(item.qty * item.price) AS total_revenue
FROM orders o,
JSON_TABLE(
    o.items,
    '$[*]'
    COLUMNS (
        product_id INT           PATH '$.product_id',
        qty        INT           PATH '$.qty',
        price      DECIMAL(10,2) PATH '$.price'
    )
) AS item
WHERE o.status = 2
  AND o.created_at >= '2026-01-01'
GROUP BY item.product_id
ORDER BY total_revenue DESC;
```

## JSON_TABLE 与 LATERAL 结合（MySQL 8.0+）

```sql
-- 等价于 LATERAL JOIN 的写法（更符合 SQL 标准）
SELECT o.id, item.*
FROM orders o
CROSS JOIN LATERAL JSON_TABLE(
    o.items,
    '$[*]'
    COLUMNS (
        product_id INT           PATH '$.product_id',
        qty        INT           PATH '$.qty'
    )
) AS item;
-- 效果与逗号分隔写法相同，但语义更清晰
```

## 适用场景

- **JSON 数组列展开为明细行**：将存储在单列 JSON 数组中的明细数据展开参与统计
- **JSON 格式数据导入分析**：将外部导入的 JSON 数据在不建表的情况下直接查询分析
- **嵌套 JSON 平铺**：将深层嵌套的 JSON 结构展平为二维表格用于报表
- **JSON 数据迁移**：将 JSON 列的数据展开后迁移到关系型结构的新表中

---

## 常见问题

**JSON_TABLE 和先 SELECT JSON_EXTRACT 再 UNION 展开的性能哪个好？**

JSON_TABLE 是专为 JSON 数据关系化设计的，MySQL 内部对其有专门的优化（无需手动管理展开逻辑），代码也更简洁。多层嵌套的 JSON 展开用 JSON_TABLE + NESTED PATH 只需一个查询，而手动展开需要多个子查询或复杂的表达式。JSON_TABLE 是推荐方式。

---

## 注意事项

- `JSON_TABLE` 只在 MySQL 8.0+ 中可用（MySQL 5.7 不支持）。
- 当 JSON 数组很大（数百甚至数千个元素）时，展开后的行数会成倍增加，可能产生大量内存使用。对大数组 JSON 列做全表 JSON_TABLE 展开时要评估查询的内存消耗，必要时加 WHERE 先过滤行数。

---

## 总结

`JSON_TABLE(json_doc, path COLUMNS(...))` 将 JSON 数组/对象展开为关系型行列结构，可以在 FROM 子句中像普通表一样使用。支持 FOR ORDINALITY（自动行号）、ON EMPTY / ON ERROR（异常处理默认值）、NESTED PATH（嵌套数组展开）等特性。是处理 JSON 列数据统计分析和数据迁移的核心函数，仅支持 MySQL 8.0+。
