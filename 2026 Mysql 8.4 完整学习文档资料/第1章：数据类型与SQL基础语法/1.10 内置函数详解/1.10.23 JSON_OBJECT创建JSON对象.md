# JSON_OBJECT 创建 JSON 对象

`JSON_OBJECT()` 函数接受键值对参数，返回一个 JSON 对象。它是在 SQL 查询中动态构建 JSON 格式数据的主要方式，常用于将关系型数据转换为 JSON 格式输出，或者在存储 JSON 前先构造好 JSON 文档。

---

## 语法

```sql
JSON_OBJECT([key, val[, key, val ...]])
-- 参数：成对的键值，key 是字符串，val 可以是任意 MySQL 数据类型
-- 返回：一个 JSON 对象
-- 零参数时返回空对象 {}
```

---

## 基本示例

```sql
-- 创建简单 JSON 对象
SELECT JSON_OBJECT('name', '张三', 'age', 30, 'city', '北京');
-- 结果：{"name": "张三", "age": 30, "city": "北京"}

-- 空对象
SELECT JSON_OBJECT();
-- 结果：{}

-- NULL 值
SELECT JSON_OBJECT('name', '张三', 'phone', NULL);
-- 结果：{"name": "张三", "phone": null}（NULL 转为 JSON null）

-- 将列值构建为 JSON 对象
SELECT JSON_OBJECT('id', id, 'name', username, 'email', email) AS user_json
FROM users;
-- 结果：{"id": 1, "name": "alice", "email": "alice@example.com"}
```

---

## 在查询中构建嵌套 JSON

```sql
-- 构建包含嵌套对象的 JSON
SELECT JSON_OBJECT(
    'id', o.id,
    'amount', o.amount,
    'status', o.status,
    'customer', JSON_OBJECT(
        'id', u.id,
        'name', u.username,
        'email', u.email
    )
) AS order_json
FROM orders o
INNER JOIN users u ON u.id = o.user_id
WHERE o.id = 100;

-- 结果：
-- {
--   "id": 100,
--   "amount": 299.99,
--   "status": 2,
--   "customer": {"id": 5, "name": "alice", "email": "alice@example.com"}
-- }
```

---

## 构建包含数组的 JSON 对象

```sql
-- 配合 JSON_ARRAYAGG 聚合子表数据为数组
SELECT JSON_OBJECT(
    'order_id', o.id,
    'user_id', o.user_id,
    'items', JSON_ARRAYAGG(
        JSON_OBJECT(
            'product_id', oi.product_id,
            'qty', oi.quantity,
            'price', oi.unit_price
        )
    )
) AS order_detail
FROM orders o
INNER JOIN order_items oi ON oi.order_id = o.id
WHERE o.id = 100
GROUP BY o.id, o.user_id;

-- 结果：
-- {
--   "order_id": 100,
--   "user_id": 5,
--   "items": [
--     {"product_id": 1, "qty": 2, "price": 99.99},
--     {"product_id": 3, "qty": 1, "price": 199.99}
--   ]
-- }
```

## 在 INSERT 中使用 JSON_OBJECT

```sql
-- 在插入时构建 JSON 存储（比手动拼接 JSON 字符串安全）
INSERT INTO user_profiles (user_id, profile)
VALUES (
    100,
    JSON_OBJECT(
        'nickname', '小张',
        'bio', '热爱技术',
        'tags', JSON_ARRAY('java', 'mysql'),
        'settings', JSON_OBJECT('theme', 'dark', 'notifications', TRUE)
    )
);

-- 相比手动拼接字符串，JSON_OBJECT 自动处理特殊字符转义和格式
-- 以下手动拼接容易出错：
-- INSERT ... VALUES (100, '{"nickname": "小张", ...}')
```

## JSON_OBJECTAGG（聚合生成 JSON 对象）

```sql
-- JSON_OBJECTAGG(key_col, value_col)：将分组内的行聚合成一个 JSON 对象
-- 每行的 key_col 成为 key，value_col 成为 value

SELECT 
    order_id,
    JSON_OBJECTAGG(product_id, quantity) AS product_quantities
FROM order_items
GROUP BY order_id;
-- 结果：每个订单对应 {"1": 2, "3": 1}（产品ID -> 数量的映射）

-- 实际应用：将行数据透视为 JSON 键值对
SELECT 
    user_id,
    JSON_OBJECTAGG(preference_key, preference_value) AS preferences
FROM user_preferences
GROUP BY user_id;
```

## 适用场景

- **API 响应构建**：在数据库层面组装 JSON 格式的 API 响应数据（减少应用层处理）
- **多表数据合并为单 JSON**：将主表 + 明细表的数据合并为嵌套 JSON
- **存储前构造 JSON**：安全地构建要存储到 JSON 列的文档
- **报表输出**：将统计结果以 JSON 键值对的形式输出

---

## 常见问题

**JSON_OBJECT 的 key 可以重复吗？**

MySQL 允许传入重复的 key，但 JSON 规范不建议这样做，大多数解析器只保留最后一个重复 key 的值。在实际使用中应确保 key 不重复，避免产生歧义。

---

## 注意事项

- `JSON_OBJECT` 的 key 参数必须是字符串（可以是列名但内容须为字符串类型），如果 key 为 NULL，MySQL 会报错（`ERROR: JSON documents may not contain NULL member names`）。
- 与手动拼接 JSON 字符串相比，`JSON_OBJECT` 会自动对值中的特殊字符（双引号、反斜线等）进行 JSON 转义，更安全可靠。

---

## 总结

`JSON_OBJECT(key1, val1, key2, val2, ...)` 根据键值对参数构建 JSON 对象，支持嵌套（value 可以是另一个 JSON_OBJECT 或 JSON_ARRAY）。配合 `JSON_ARRAYAGG` 可以将一对多的关系数据聚合为包含数组的嵌套 JSON。`JSON_OBJECTAGG(key_col, val_col)` 将分组内的多行聚合为一个 JSON 对象。相比手动拼接字符串，这类函数能自动处理转义，避免 JSON 格式错误。
