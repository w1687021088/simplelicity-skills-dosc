# DATEDIFF 日期差值计算

`DATEDIFF()` 计算两个日期之间相差的天数，返回值为整数（可为负数）。它只关注日期部分，忽略时间部分，是计算"距今多少天"、"两事件间隔多少天"等场景的常用函数。

---

## 语法

```sql
DATEDIFF(date1, date2)    -- 返回 date1 - date2 的天数差（整数）
TIMESTAMPDIFF(unit, dt1, dt2)  -- 按指定单位计算差值（更通用）
```

- `DATEDIFF` 只能返回天数差，不支持其他单位
- `TIMESTAMPDIFF` 支持任意单位（YEAR、MONTH、DAY、HOUR、MINUTE、SECOND 等）

---

## 基本示例

```sql
-- 基础用法
SELECT DATEDIFF('2026-03-22', '2026-03-15');   -- 7（date1 - date2）
SELECT DATEDIFF('2026-03-15', '2026-03-22');   -- -7（date1 < date2，返回负数）

-- 与当前日期比较
SELECT DATEDIFF(CURDATE(), '2026-01-01') AS days_since_new_year;
SELECT DATEDIFF('2026-12-31', CURDATE()) AS days_until_year_end;

-- DATEDIFF 忽略时间部分
SELECT DATEDIFF('2026-03-15 23:59:59', '2026-03-15 00:00:01');
-- 结果：0（只看日期部分，两个日期相同）

-- 含时间的日期差：使用 TIMESTAMPDIFF
SELECT TIMESTAMPDIFF(HOUR, '2026-03-15 08:00:00', '2026-03-16 10:30:00');
-- 结果：26（小时差）
```

---

## TIMESTAMPDIFF（多单位差值）

```sql
-- TIMESTAMPDIFF(unit, datetime_expr1, datetime_expr2)
-- 返回 datetime_expr2 - datetime_expr1（注意顺序与 DATEDIFF 相反）

SELECT TIMESTAMPDIFF(YEAR,  '2000-05-01', CURDATE()) AS age_years;     -- 年龄
SELECT TIMESTAMPDIFF(MONTH, '2026-01-15', '2026-04-15');               -- 月数差：3
SELECT TIMESTAMPDIFF(DAY,   '2026-01-01', '2026-03-15');               -- 天数差：73
SELECT TIMESTAMPDIFF(HOUR,  NOW() - INTERVAL 2 HOUR, NOW());           -- 小时差：2
SELECT TIMESTAMPDIFF(MINUTE,'2026-03-15 14:00:00', '2026-03-15 16:30:00'); -- 150分钟
SELECT TIMESTAMPDIFF(SECOND,'2026-03-15 14:00:00', '2026-03-15 14:01:30'); -- 90秒
```

## 常见业务场景

```sql
-- 计算用户注册至今的天数
SELECT id, username,
    DATEDIFF(CURDATE(), DATE(created_at)) AS days_since_register
FROM users
ORDER BY days_since_register DESC;

-- 计算合同剩余天数
SELECT contract_id, client_name, expire_date,
    DATEDIFF(expire_date, CURDATE()) AS days_remaining
FROM contracts
WHERE expire_date >= CURDATE()
ORDER BY days_remaining ASC;
-- days_remaining = 0：今天到期
-- days_remaining < 0：已过期（若无 WHERE 过滤的话）

-- 计算用户年龄（精确到年）
SELECT id, username, birthday,
    TIMESTAMPDIFF(YEAR, birthday, CURDATE()) AS age
FROM users
WHERE birthday IS NOT NULL;

-- 查找超过 30 天未付款的订单
SELECT * FROM orders
WHERE status = 0   -- 待付款
  AND DATEDIFF(CURDATE(), DATE(created_at)) > 30;

-- 统计各年龄段用户数量
SELECT 
    CASE 
        WHEN age < 18 THEN '18岁以下'
        WHEN age BETWEEN 18 AND 30 THEN '18-30岁'
        WHEN age BETWEEN 31 AND 50 THEN '31-50岁'
        ELSE '50岁以上'
    END AS age_group,
    COUNT(*) AS user_count
FROM (
    SELECT TIMESTAMPDIFF(YEAR, birthday, CURDATE()) AS age
    FROM users WHERE birthday IS NOT NULL
) t
GROUP BY age_group;
```

## DATEDIFF vs TIMESTAMPDIFF 对比

| 函数 | 计算方向 | 支持的单位 | 处理时间部分 |
|------|---------|----------|------------|
| `DATEDIFF(d1, d2)` | d1 - d2 | 只有天 | 忽略时间 |
| `TIMESTAMPDIFF(unit, dt1, dt2)` | dt2 - dt1 | 年/月/日/时/分/秒 | 精确到秒 |

---

## 适用场景

- **年龄计算**：`TIMESTAMPDIFF(YEAR, birthday, CURDATE())`
- **有效期剩余天数**：`DATEDIFF(expire_date, CURDATE())`
- **超时判断**：未处理订单超过 N 天的记录
- **订阅/会员期限统计**：按剩余天数分段统计

---

## 常见问题

**DATEDIFF 和 TIMESTAMPDIFF(DAY, ...) 有区别吗？**

有细微差别：
- `DATEDIFF('2026-03-16 01:00:00', '2026-03-15 23:00:00')` = 1（只看日期，忽略时间）
- `TIMESTAMPDIFF(DAY, '2026-03-15 23:00:00', '2026-03-16 01:00:00')` = 0（时间差只有 2 小时，不足 1 天）

对需要精确到小时的场景用 `TIMESTAMPDIFF(HOUR, ...)`，只需要按自然日数天用 `DATEDIFF`。

---

## 注意事项

- `DATEDIFF(d1, d2)` 的参数顺序是 d1 - d2，而 `TIMESTAMPDIFF(unit, dt1, dt2)` 的结果是 dt2 - dt1，两者**顺序相反**，使用时注意不要弄错。
- 年龄计算用 `TIMESTAMPDIFF(YEAR, birthday, CURDATE())` 比 `FLOOR(DATEDIFF(CURDATE(), birthday) / 365)` 更准确，因为后者会因闰年导致偏差。

---

## 总结

`DATEDIFF(d1, d2)` 返回 d1 - d2 的天数差（只看日期，忽略时间），结果可为负。`TIMESTAMPDIFF(unit, dt1, dt2)` 返回 dt2 - dt1 的指定单位差值，支持年/月/日/时/分/秒，精度更高。年龄计算用 `TIMESTAMPDIFF(YEAR, birthday, CURDATE())` 最准确。注意两个函数参数顺序不同（一个是 d1-d2，一个是 dt2-dt1）。
