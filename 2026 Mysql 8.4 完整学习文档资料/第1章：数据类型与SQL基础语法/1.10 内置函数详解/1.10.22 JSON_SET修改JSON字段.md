# JSON_SET 修改 JSON 字段

`JSON_SET()` 在 JSON 文档中插入或替换指定路径的值：路径存在时替换，路径不存在时插入。MySQL 还提供了 `JSON_INSERT()`（只插入，不替换）和 `JSON_REPLACE()`（只替换，不插入）作为两种更严格的变体。这三个函数是 JSON 列原地修改的核心工具。

---

## 语法

```sql
JSON_SET(json_doc, path, val [, path, val ...])
JSON_INSERT(json_doc, path, val [, path, val ...])
JSON_REPLACE(json_doc, path, val [, path, val ...])
JSON_REMOVE(json_doc, path [, path ...])

-- 三者行为对比：
-- JSON_SET：存在则替换，不存在则插入
-- JSON_INSERT：只插入（不存在时插入，存在时不动）
-- JSON_REPLACE：只替换（存在时替换，不存在时不动）
-- JSON_REMOVE：删除指定路径的值
```

---

## 基本示例

```sql
-- 原始 JSON：{"name":"张三","age":30}

-- JSON_SET：插入新字段 city，替换已有 age
SELECT JSON_SET('{"name":"张三","age":30}', '$.city', '北京', '$.age', 31);
-- 结果：{"name": "张三", "age": 31, "city": "北京"}

-- JSON_INSERT：只插入（age 已存在，不替换）
SELECT JSON_INSERT('{"name":"张三","age":30}', '$.city', '北京', '$.age', 31);
-- 结果：{"name": "张三", "age": 30, "city": "北京"}（age 保持 30，city 被插入）

-- JSON_REPLACE：只替换（city 不存在，不插入）
SELECT JSON_REPLACE('{"name":"张三","age":30}', '$.city', '北京', '$.age', 31);
-- 结果：{"name": "张三", "age": 31}（age 被替换为 31，city 不存在所以没有插入）

-- JSON_REMOVE：删除字段
SELECT JSON_REMOVE('{"name":"张三","age":30,"city":"北京"}', '$.city');
-- 结果：{"name": "张三", "age": 30}
```

---

## 在 UPDATE 中修改 JSON 列

```sql
-- 修改 JSON 列中的特定字段（其他字段不受影响）
UPDATE users
SET profile = JSON_SET(profile, '$.age', 31, '$.city', '上海')
WHERE id = 1;

-- 添加新字段（不存在则插入，存在则覆盖）
UPDATE products
SET attributes = JSON_SET(attributes, '$.color', '红色', '$.size', 'L')
WHERE id = 100;

-- 删除 JSON 中的某个字段
UPDATE users
SET profile = JSON_REMOVE(profile, '$.temp_field')
WHERE JSON_CONTAINS_PATH(profile, 'one', '$.temp_field');

-- 数组追加：在 JSON 数组末尾添加元素
UPDATE users
SET profile = JSON_ARRAY_APPEND(profile, '$.tags', 'new_tag')
WHERE id = 1;
-- profile 的 tags 从 ["java","mysql"] 变为 ["java","mysql","new_tag"]
```

---

## JSON_ARRAY_APPEND 和 JSON_ARRAY_INSERT

```sql
-- JSON_ARRAY_APPEND：在数组末尾追加
SELECT JSON_ARRAY_APPEND('{"tags":["java","python"]}', '$.tags', 'mysql');
-- 结果：{"tags": ["java", "python", "mysql"]}

-- JSON_ARRAY_INSERT：在数组指定位置插入
SELECT JSON_ARRAY_INSERT('{"tags":["java","python"]}', '$.tags[1]', 'mysql');
-- 结果：{"tags": ["java", "mysql", "python"]}（在位置 1 插入，原来的元素后移）

-- 批量追加（UPDATE 中常用）
UPDATE posts
SET meta = JSON_ARRAY_APPEND(meta, '$.like_users', 999)
WHERE id = 100;
```

## JSON 合并（JSON_MERGE_PATCH / JSON_MERGE_PRESERVE）

```sql
-- JSON_MERGE_PATCH：合并两个 JSON 对象（后者覆盖前者的同名 key）
SELECT JSON_MERGE_PATCH(
    '{"name":"张三","age":30}',
    '{"age":31,"city":"北京"}'
);
-- 结果：{"name": "张三", "age": 31, "city": "北京"}

-- JSON_MERGE_PRESERVE：保留所有值（同名 key 的值合并为数组）
SELECT JSON_MERGE_PRESERVE(
    '{"tags":["java"]}',
    '{"tags":["mysql"]}'
);
-- 结果：{"tags": ["java", "mysql"]}（两个数组合并）
```

## 三种修改函数对比

| 情况 | JSON_SET | JSON_INSERT | JSON_REPLACE |
|------|---------|-------------|--------------|
| 路径存在 | 替换 | 不动（保留原值）| 替换 |
| 路径不存在 | 插入 | 插入 | 不动 |
| 适用场景 | 最通用（upsert 语义）| 只填充缺失字段 | 只更新已有字段 |

---

## 适用场景

- **用户扩展属性更新**：更新存在的属性，同时添加新属性（JSON_SET）
- **配置项管理**：按 key 更新 JSON 格式的配置值
- **数组类型数据维护**：在 JSON 数组中追加或删除元素（收藏、标签等）
- **数据迁移**：将新字段以 JSON 格式追加到现有 JSON 列（平滑扩展而不 ALTER TABLE）

---

## 常见问题

**修改 JSON 字段时是否会产生额外的存储开销？**

MySQL 对 JSON 列的修改是"先读取完整 JSON，修改后整体写回"，不支持就地（in-place）修改部分字节。对于频繁修改的大 JSON 文档，会产生较多的 IO 和存储碎片。如果 JSON 中某个字段被频繁读写，考虑将其提取为独立列。

---

## 注意事项

- `JSON_SET`、`JSON_INSERT`、`JSON_REPLACE` 都不会修改传入的 JSON 文档本身（它们是函数，返回新的 JSON 值）。必须在 UPDATE 语句中将结果重新赋值给列才能持久化修改：`SET col = JSON_SET(col, ...)`。
- 使用 `JSON_REMOVE` 删除数组元素时，按位置删除（`$[1]`）会导致后续元素的位置改变，注意位置偏移问题。

---

## 总结

`JSON_SET(doc, path, val, ...)` 是最常用的 JSON 修改函数，路径存在时替换，不存在时插入（upsert 语义）。`JSON_INSERT` 只插入不替换，`JSON_REPLACE` 只替换不插入。`JSON_REMOVE` 删除指定路径。`JSON_ARRAY_APPEND` 在数组末尾追加元素。所有修改函数都返回新值，必须在 UPDATE 中赋值才能持久化。
