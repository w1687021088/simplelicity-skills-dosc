# TRIM 去除空格

`TRIM()` 函数去除字符串首尾的空格或指定字符。`LTRIM()` 只去除左侧（开头），`RTRIM()` 只去除右侧（结尾）。这几个函数在数据清理和格式化中非常常用，特别是处理用户输入或从外部导入的数据时。

---

## 语法

```sql
TRIM(str)                              -- 去除首尾空格
TRIM([BOTH|LEADING|TRAILING] [remstr FROM] str)  -- 指定位置和字符
LTRIM(str)                             -- 只去除左侧空格
RTRIM(str)                             -- 只去除右侧空格
```

---

## 基本示例

```sql
-- 去除首尾空格
SELECT TRIM('  Hello World  ');     -- 'Hello World'
SELECT LTRIM('  Hello World  ');    -- 'Hello World  '（只去左侧）
SELECT RTRIM('  Hello World  ');    -- '  Hello World'（只去右侧）

-- 去除指定字符（不仅限于空格）
SELECT TRIM('/' FROM '/var/lib/mysql/');   -- 'var/lib/mysql'（去除首尾的 /）
SELECT TRIM(LEADING '0' FROM '000123');    -- '123'（去除开头的 0）
SELECT TRIM(TRAILING '.' FROM 'Hello..'); -- 'Hello'（去除结尾的 .）
SELECT TRIM(BOTH 'x' FROM 'xxxHelloxx'); -- 'Hello'（去除首尾的 x）
```

---

## 在 UPDATE 中批量清理数据

```sql
-- 清理用户名的首尾空格（处理注册时的输入错误）
UPDATE users
SET username = TRIM(username)
WHERE username != TRIM(username);  -- 只更新需要清理的行

-- 同时清理多个列
UPDATE contacts
SET 
    first_name = TRIM(first_name),
    last_name  = TRIM(last_name),
    email      = TRIM(LOWER(email))  -- 去空格同时转小写
WHERE first_name != TRIM(first_name)
   OR last_name  != TRIM(last_name);
```

---

## TRIM 与 REPLACE 的区别

```sql
-- TRIM：只去除首尾的指定字符（中间的不动）
SELECT TRIM(' ' FROM '  Hello  World  ');  -- 'Hello  World'（中间空格保留）

-- REPLACE：替换所有出现的字符（包括中间的）
SELECT REPLACE('  Hello  World  ', ' ', '');  -- 'HelloWorld'（所有空格都去掉）

-- 去除字符串中所有多余空格（只保留单个空格）
-- TRIM + REPLACE 组合无法直接做到，需要用 REGEXP_REPLACE
SELECT REGEXP_REPLACE(TRIM('  Hello   World  '), ' +', ' ');  -- 'Hello World'
```

## 适用场景

- **用户输入清理**：去除注册表单中用户名、邮箱的首尾空格
- **导入数据规范化**：从 CSV 或外部系统导入的数据常有多余空格
- **数字字符串清理**：`TRIM(LEADING '0' FROM order_no)` 去除订单号的前导零
- **特殊字符清理**：去除首尾的斜线、引号、特殊标记

---

## 常见问题

**TRIM 能去除 Tab 和换行符吗？**

标准 `TRIM()` 只去除空格（ASCII 32）。要去除 Tab（`\t`，ASCII 9）和换行符（`\n`，ASCII 10），需要用 `REPLACE()` 或 `REGEXP_REPLACE()`：

```sql
SELECT REGEXP_REPLACE(TRIM(str), '^[\\s]+|[\\s]+$', '');  -- 去除首尾所有空白字符
-- 或者：
SELECT REPLACE(REPLACE(REPLACE(TRIM(str), '\t', ''), '\n', ''), '\r', '');
```

---

## 注意事项

- `TRIM()` 去除的是**首尾**字符，不能去除字符串中间的空格（需要用 `REPLACE` 或 `REGEXP_REPLACE`）。
- TRIM 只去除指定的**单个字符**（一次 TRIM 去除的是最外层的所有连续出现的该字符），不能同时去除多种不同字符。如果要同时去除多种字符，需要多次 TRIM 或使用 REGEXP_REPLACE。

---

## 总结

`TRIM(str)` 去除首尾空格，`LTRIM` 只去左侧，`RTRIM` 只去右侧。通过 `TRIM([BOTH|LEADING|TRAILING] char FROM str)` 可指定要去除的字符和位置。TRIM 只处理首尾，中间的字符不受影响（用 REPLACE 处理中间）。数据清理时常与 LOWER/UPPER 配合使用。
