# DATE_ADD 日期加法

`DATE_ADD()` 在日期或日期时间值上加上一个时间间隔，返回新的日期时间值。它支持多种时间单位（年、月、日、时、分、秒等），是实现有效期计算、截止日期推算、统计周期偏移的核心函数。

---

## 语法

```sql
DATE_ADD(date, INTERVAL expr unit)
ADDDATE(date, INTERVAL expr unit)     -- DATE_ADD 的同义函数
date + INTERVAL expr unit             -- 运算符写法（等价）
```

`unit` 支持的时间单位：`MICROSECOND`、`SECOND`、`MINUTE`、`HOUR`、`DAY`、`WEEK`、`MONTH`、`QUARTER`、`YEAR`，以及复合单位如 `SECOND_MICROSECOND`、`MINUTE_SECOND`、`HOUR_MINUTE`、`DAY_HOUR`、`YEAR_MONTH` 等。

---

## 基本示例

```sql
-- 加天数
SELECT DATE_ADD('2026-03-15', INTERVAL 7 DAY);   -- 2026-03-22
SELECT DATE_ADD('2026-03-15', INTERVAL -7 DAY);  -- 2026-03-08（负数等于减法）

-- 加月数（自动处理月末）
SELECT DATE_ADD('2026-01-31', INTERVAL 1 MONTH);  -- 2026-02-28（2月没有31日）

-- 加年
SELECT DATE_ADD('2024-02-29', INTERVAL 1 YEAR);   -- 2025-02-28（2025年不是闰年）

-- 加小时和分钟
SELECT DATE_ADD(NOW(), INTERVAL 2 HOUR);
SELECT DATE_ADD(NOW(), INTERVAL 90 MINUTE);

-- 加周
SELECT DATE_ADD(CURDATE(), INTERVAL 2 WEEK);      -- 14天后

-- 运算符写法（完全等价）
SELECT '2026-03-15' + INTERVAL 7 DAY;             -- 2026-03-22
SELECT NOW() + INTERVAL 1 HOUR;
```

## 常见业务场景

```sql
-- 计算 VIP 到期时间（购买时间 + 365 天）
UPDATE vip_members
SET expire_at = DATE_ADD(purchase_at, INTERVAL 1 YEAR)
WHERE order_id = 10001;

-- 查询 7 天内到期的 VIP
SELECT user_id, expire_at
FROM vip_members
WHERE expire_at BETWEEN NOW() AND DATE_ADD(NOW(), INTERVAL 7 DAY);

-- 生成下月第一天（月报统计的截止日期）
SELECT DATE_ADD(DATE_FORMAT(CURDATE(), '%Y-%m-01'), INTERVAL 1 MONTH) AS next_month_start;

-- 计算促销结束时间（开始时间 + 72 小时）
SELECT promo_id,
    start_at,
    DATE_ADD(start_at, INTERVAL 72 HOUR) AS end_at
FROM promotions;

-- 生成最近 30 天的日期序列（配合递归 CTE）
WITH RECURSIVE dates AS (
    SELECT CURDATE() - INTERVAL 29 DAY AS dt
    UNION ALL
    SELECT DATE_ADD(dt, INTERVAL 1 DAY) FROM dates WHERE dt < CURDATE()
)
SELECT dt FROM dates;
```

## 复合时间单位

```sql
-- YEAR_MONTH：'年-月' 格式
SELECT DATE_ADD('2026-01-15', INTERVAL '1-6' YEAR_MONTH);  -- 1年6个月后 = 2027-07-15

-- DAY_HOUR：'天 时' 格式
SELECT DATE_ADD('2026-03-15 10:00:00', INTERVAL '2 12' DAY_HOUR);  -- 2天12小时后

-- HOUR_MINUTE：'时:分' 格式
SELECT DATE_ADD(NOW(), INTERVAL '1:30' HOUR_MINUTE);  -- 1小时30分后
```

---

## DATE_ADD vs DATE_SUB

```sql
-- DATE_ADD 加正数 = DATE_SUB 加正数
SELECT DATE_ADD('2026-03-15', INTERVAL 7 DAY);    -- 2026-03-22
SELECT DATE_SUB('2026-03-15', INTERVAL -7 DAY);   -- 2026-03-22（负数取反）

-- 通常推荐：
-- 加法用 DATE_ADD 或 + INTERVAL（更直观）
-- 减法用 DATE_SUB 或 - INTERVAL
SELECT '2026-03-15' + INTERVAL 7 DAY;   -- 加7天
SELECT '2026-03-15' - INTERVAL 7 DAY;   -- 减7天
```

## 适用场景

- **有效期计算**：VIP 到期时间、优惠券过期时间、合同截止日期
- **预约系统**：基于预约时间计算提醒时间（预约时间 - N 小时）
- **统计周期偏移**：上周、上月的日期范围计算
- **生成日期序列**：配合递归 CTE 生成连续日期用于报表

---

## 常见问题

**DATE_ADD 加月时月末如何处理？**

当结果月份没有对应日期时，MySQL 自动调整到该月的最后一天：`DATE_ADD('2026-01-31', INTERVAL 1 MONTH)` 返回 `2026-02-28`（2026 年 2 月只有 28 天）。这种"月末截断"行为需要注意，在某些业务场景（如按月账单）可能需要额外处理。

---

## 注意事项

- `INTERVAL` 中的 `expr` 可以是负数，此时 DATE_ADD 实际上是做减法。如果代码中需要做减法，用 `DATE_SUB` 或 `- INTERVAL` 写法更语义清晰。
- 对 DATETIME 列做范围查询时，不要对列本身加函数（会导致索引失效），而是对比较值用 DATE_ADD 计算好再比较：`WHERE col < DATE_ADD(NOW(), INTERVAL 7 DAY)`（col 上的索引可用）。

---

## 总结

`DATE_ADD(date, INTERVAL expr unit)` 在日期/时间值上加一个时间间隔，支持多种时间单位（年月日时分秒及复合单位）。负数 expr 相当于减法。月末自动截断（如 1月31日 + 1个月 = 2月末）。常用于有效期计算、统计周期边界推算、日期序列生成。运算符写法 `date + INTERVAL n unit` 完全等价，代码更简洁。
