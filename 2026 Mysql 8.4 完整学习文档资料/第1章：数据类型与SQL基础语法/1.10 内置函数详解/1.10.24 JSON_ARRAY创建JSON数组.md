# JSON_ARRAY 创建 JSON 数组

`JSON_ARRAY()` 函数接受任意数量的参数，将它们打包成一个 JSON 数组返回。它是在 SQL 中动态构建 JSON 数组的标准方式，常与 `JSON_OBJECT` 配合使用来构建复杂的嵌套 JSON 结构。

---

## 语法

```sql
JSON_ARRAY([val[, val ...]])
-- 零参数时返回空数组 []
-- 参数可以是任意 MySQL 数据类型（字符串、数字、布尔、NULL、嵌套 JSON 等）
```

---

## 基本示例

```sql
-- 创建简单数组
SELECT JSON_ARRAY(1, 2, 3);
-- 结果：[1, 2, 3]

SELECT JSON_ARRAY('java', 'mysql', 'python');
-- 结果：["java", "mysql", "python"]

-- 空数组
SELECT JSON_ARRAY();
-- 结果：[]

-- 混合类型（数字、字符串、NULL、布尔）
SELECT JSON_ARRAY(1, 'hello', NULL, TRUE, 3.14);
-- 结果：[1, "hello", null, true, 3.14]

-- 嵌套数组
SELECT JSON_ARRAY(JSON_ARRAY(1, 2), JSON_ARRAY(3, 4));
-- 结果：[[1, 2], [3, 4]]

-- 将列值构建为数组
SELECT JSON_ARRAY(id, username, email) AS user_info FROM users WHERE id = 1;
-- 结果：[1, "alice", "alice@example.com"]
```

---

## 与 JSON_OBJECT 嵌套使用

```sql
-- 构建用户对象，其中 tags 是数组
SELECT JSON_OBJECT(
    'id', 1,
    'name', 'alice',
    'tags', JSON_ARRAY('admin', 'user', 'developer'),
    'scores', JSON_ARRAY(95, 87, 92)
) AS user_json;

-- 结果：
-- {
--   "id": 1,
--   "name": "alice",
--   "tags": ["admin", "user", "developer"],
--   "scores": [95, 87, 92]
-- }

-- 存储商品规格（颜色选项、尺寸选项）
INSERT INTO products (name, attributes) VALUES (
    'T恤',
    JSON_OBJECT(
        'colors', JSON_ARRAY('红', '蓝', '白'),
        'sizes', JSON_ARRAY('S', 'M', 'L', 'XL'),
        'material', '棉'
    )
);
```

## JSON_ARRAYAGG（聚合多行为 JSON 数组）

```sql
-- JSON_ARRAYAGG(expr)：将分组内的多行值聚合为一个 JSON 数组
-- 比 GROUP_CONCAT 更强大：保留 JSON 类型，支持复杂表达式

-- 将每个部门的员工列表聚合为 JSON 数组
SELECT dept_id,
    JSON_ARRAYAGG(name ORDER BY name) AS employee_list
FROM employees
GROUP BY dept_id;
-- 结果：
-- dept_id=1: ["李四", "张三"]
-- dept_id=2: ["王五"]

-- 将每个订单的商品聚合为 JSON 对象数组
SELECT o.id AS order_id,
    JSON_ARRAYAGG(
        JSON_OBJECT(
            'product_id', oi.product_id,
            'product_name', p.name,
            'quantity', oi.quantity,
            'unit_price', oi.unit_price
        )
        ORDER BY oi.product_id
    ) AS items
FROM orders o
INNER JOIN order_items oi ON oi.order_id = o.id
INNER JOIN products p ON p.id = oi.product_id
GROUP BY o.id;
```

## JSON_ARRAY 的元素访问和操作

```sql
-- 从 JSON 数组列中访问元素
SELECT product_id,
    attributes -> '$.colors[0]' AS first_color,    -- 第一种颜色
    JSON_LENGTH(attributes -> '$.colors') AS color_count  -- 颜色数量
FROM products;

-- 检查数组是否包含某元素
SELECT product_id FROM products
WHERE JSON_CONTAINS(attributes -> '$.colors', '"红"');
-- 查找有红色的商品

-- 获取数组所有元素（展开）
SELECT product_id,
    JSON_EXTRACT(attributes, '$.colors') AS all_colors
FROM products;
-- 返回整个数组，如 ["红", "蓝", "白"]
```

## JSON_ARRAY vs GROUP_CONCAT 对比

| 对比维度 | JSON_ARRAYAGG | GROUP_CONCAT |
|---------|--------------|--------------|
| 返回类型 | JSON 数组 | 字符串 |
| 元素类型 | 保留原始类型 | 全部转为字符串 |
| 嵌套结构 | 支持（数组的数组、对象数组）| 不支持 |
| 结果大小限制 | 受 JSON 文档大小限制 | `group_concat_max_len` 变量 |
| 空 NULL 处理 | NULL 包含在数组中（JSON null）| 忽略 NULL |
| 适用场景 | API 返回 JSON 数据 | 简单文本拼接 |

---

## 适用场景

- **构建 JSON 列的默认初始值**：插入记录时为 JSON 数组列设置初始数组
- **API 数据格式化**：在 DB 层将多列值打包为 JSON 数组返回
- **嵌套 JSON 构建**：在 JSON_OBJECT 中为某个 key 设置数组 value
- **聚合子表数据**：用 JSON_ARRAYAGG 将明细表数据聚合为父表 JSON 字段的数组

---

## 常见问题

**JSON_ARRAY 中 NULL 如何处理？**

`JSON_ARRAY(1, NULL, 3)` 返回 `[1, null, 3]`，NULL 被转换为 JSON 的 `null` 值（保留在数组中）。这与 `GROUP_CONCAT` 不同——GROUP_CONCAT 会忽略 NULL。如果不想让 NULL 出现在数组中，需要先过滤：`JSON_ARRAYAGG(IF(col IS NULL, JSON_ARRAY(), col))` 或在 WHERE 中排除。

---

## 注意事项

- `JSON_ARRAYAGG` 在 MySQL 5.7.22+ 才可用（某些旧版本 5.7 可能没有）。MySQL 8.0+ 完全支持。
- `JSON_ARRAYAGG` 不支持 `DISTINCT`（不能去重），如果需要去重，先在子查询中 DISTINCT 再 JSON_ARRAYAGG，或用 GROUP_CONCAT 结合 JSON_ARRAY 手动处理。

---

## 总结

`JSON_ARRAY(val1, val2, ...)` 将参数列表打包为 JSON 数组，支持任意类型和嵌套结构，NULL 保留为 JSON null。`JSON_ARRAYAGG(expr)` 聚合多行为 JSON 数组，比 GROUP_CONCAT 保留类型信息，支持复杂嵌套对象数组。与 `JSON_OBJECT` 配合可以构建任意复杂的嵌套 JSON 文档，是在 SQL 层面组装 JSON API 响应的核心工具。
