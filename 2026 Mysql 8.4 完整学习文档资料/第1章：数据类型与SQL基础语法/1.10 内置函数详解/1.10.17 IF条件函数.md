# IF 条件函数

`IF()` 是 MySQL 中最简单的条件函数，根据第一个参数（条件）的真假，返回第二个或第三个参数的值。它相当于编程语言中的三元运算符 `condition ? true_val : false_val`，适合简单的二选一逻辑。

---

## 语法

```sql
IF(condition, true_val, false_val)
```

- `condition`：布尔表达式，为 TRUE（非 0 非 NULL）返回 `true_val`，否则返回 `false_val`
- `true_val` 和 `false_val` 可以是任意类型，包括 NULL

---

## 基本示例

```sql
-- 简单二选一
SELECT IF(1 > 0, '是', '否');          -- '是'
SELECT IF(1 < 0, '是', '否');          -- '否'
SELECT IF(NULL, '是', '否');           -- '否'（NULL 视为 FALSE）

-- 在查询中使用
SELECT id, salary,
    IF(salary >= 15000, '高薪', '普通') AS salary_level
FROM employees;

-- 用于状态标签转换
SELECT order_id,
    IF(status = 1, '待支付',
    IF(status = 2, '已完成',
    IF(status = 3, '已取消', '未知'))) AS status_label
FROM orders;
-- 嵌套 IF 处理多种状态（超过 2 种情况建议改用 CASE WHEN）
```

---

## 常见业务场景

```sql
-- 场景1：NULL 值替换（等价于 IFNULL）
SELECT id, IF(phone IS NULL, '未填写', phone) AS phone_display FROM users;

-- 场景2：条件聚合（统计各类别数量）
SELECT 
    SUM(IF(status = 1, 1, 0)) AS pending_count,
    SUM(IF(status = 2, 1, 0)) AS completed_count,
    SUM(IF(status = 3, 1, 0)) AS cancelled_count,
    COUNT(*) AS total_count
FROM orders;
-- 一次扫描同时统计多个状态的数量，比多个 COUNT + WHERE 更高效

-- 场景3：条件求和
SELECT dept_id,
    SUM(IF(gender = 'M', salary, 0)) AS male_total_salary,
    SUM(IF(gender = 'F', salary, 0)) AS female_total_salary,
    AVG(IF(gender = 'M', salary, NULL)) AS male_avg_salary,  -- NULL 不参与 AVG
    AVG(IF(gender = 'F', salary, NULL)) AS female_avg_salary
FROM employees
GROUP BY dept_id;

-- 场景4：动态排序（按条件给不同优先级）
SELECT * FROM tasks
ORDER BY IF(priority = 'high', 1, IF(priority = 'medium', 2, 3)),
         created_at ASC;

-- 场景5：行转列（pivot 效果）
SELECT product_id,
    SUM(IF(MONTH(sale_date) = 1, amount, 0)) AS jan_sales,
    SUM(IF(MONTH(sale_date) = 2, amount, 0)) AS feb_sales,
    SUM(IF(MONTH(sale_date) = 3, amount, 0)) AS mar_sales
FROM sales
WHERE YEAR(sale_date) = 2026
GROUP BY product_id;
```

## IF vs CASE WHEN

```sql
-- IF（二选一，语法简洁）
SELECT IF(score >= 60, '及格', '不及格') AS result FROM students;

-- CASE WHEN（多条件，语义更清晰）
SELECT CASE 
    WHEN score >= 90 THEN '优秀'
    WHEN score >= 75 THEN '良好'
    WHEN score >= 60 THEN '及格'
    ELSE '不及格'
END AS result FROM students;

-- 原则：二选一用 IF，三种及以上用 CASE WHEN
```

---

## IF 返回类型规则

```sql
-- IF 的返回类型由 true_val 和 false_val 共同决定（取更宽泛的类型）
SELECT IF(1>0, 1, 'a');      -- 返回字符串类型（'1'），因为其中有字符串
SELECT IF(1>0, 1.5, 2);      -- 返回浮点类型（1.5），因为其中有浮点数
SELECT IF(1>0, NULL, 'abc'); -- 返回字符串类型
```

---

## 适用场景

- **简单状态转换**：`IF(is_vip = 1, 'VIP', '普通用户')`
- **条件聚合（行转列）**：`SUM(IF(status=1, 1, 0))` 统计某状态的数量
- **NULL 处理**：`IF(col IS NULL, default_val, col)`（等价于 IFNULL）
- **条件排序**：`ORDER BY IF(condition, 1, 2)` 将满足条件的行排在前面

## 常见问题

**IF 和 IIF（SQL Server 中的函数）有区别吗？**

MySQL 中没有 `IIF` 函数（这是 SQL Server / MS Access 的函数），MySQL 对应的是 `IF()`。两者功能完全相同，只是名称不同。

---

## 注意事项

- 嵌套 IF 超过 2 层时，代码可读性急剧下降。超过 2 种条件的判断应换用 `CASE WHEN ... THEN ... END` 语法，结构更清晰、可维护性更高。
- `IF(condition, true_val, false_val)` 中，当 condition 为 NULL 时，结果是 `false_val`（NULL 视为 FALSE），不是 NULL。

---

## 总结

`IF(condition, true_val, false_val)` 是 MySQL 的三元条件函数，TRUE 返回 true_val，FALSE 或 NULL 返回 false_val。适合简单的二选一逻辑。多于两种条件时改用 `CASE WHEN`。最常见的高级用法是 `SUM(IF(...))` 实现条件聚合和行转列，比多次全表扫描效率更高。
