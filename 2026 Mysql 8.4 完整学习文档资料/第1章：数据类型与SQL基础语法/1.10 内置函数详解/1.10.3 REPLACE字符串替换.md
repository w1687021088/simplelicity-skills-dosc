# REPLACE 字符串替换

`REPLACE()` 函数将字符串中所有出现的指定子字符串替换为另一个字符串。它区分大小写，会替换目标字符串中的**所有**匹配项（不只是第一个），并返回替换后的新字符串（不修改原始数据，除非在 UPDATE 中使用）。

---

## 语法

```sql
REPLACE(str, from_str, to_str)
```

- `str`：原始字符串（或列名）
- `from_str`：要被替换的子字符串
- `to_str`：替换后的新字符串

---

## 基本示例

```sql
-- 替换所有匹配项
SELECT REPLACE('Hello World World', 'World', 'MySQL');
-- 结果：Hello MySQL MySQL（两个 World 都被替换）

-- 大小写敏感
SELECT REPLACE('Hello world', 'World', 'MySQL');
-- 结果：Hello world（未替换，因为 'world' != 'World'）

-- to_str 为空字符串（相当于删除 from_str）
SELECT REPLACE('Hello, World!', ',', '');
-- 结果：Hello World!（删除所有逗号）

-- 应用于列
SELECT REPLACE(description, '<br>', '\n') AS clean_desc FROM articles;
```

---

## UPDATE 中批量替换

```sql
-- 将 content 列中所有的旧域名替换为新域名
UPDATE articles
SET content = REPLACE(content, 'http://old-domain.com', 'https://new-domain.com')
WHERE content LIKE '%http://old-domain.com%';
-- 执行前先 SELECT 验证命中范围

-- 去除字段中的空格（替换为空字符串）
UPDATE products
SET product_code = REPLACE(product_code, ' ', '')
WHERE product_code LIKE '% %';

-- 批量清理HTML标签（简单场景）
UPDATE comments
SET content = REPLACE(REPLACE(content, '<b>', ''), '</b>', '')
WHERE content REGEXP '</?b>';
-- 先替换 <b> 再替换 </b>（REPLACE 嵌套）
```

---

## REPLACE 的嵌套使用

```sql
-- 替换多个不同的子字符串（嵌套 REPLACE）
SELECT REPLACE(
    REPLACE(
        REPLACE(phone, '-', ''),  -- 先去掉横线
    ' ', ''),                     -- 再去掉空格
'(', '')                          -- 再去掉左括号
AS clean_phone
FROM users;
-- '138-1234 5678' → '13812345678'
-- 嵌套层数越多越难读，可以考虑用 REGEXP_REPLACE（MySQL 8.0+）
```

---

## REGEXP_REPLACE（正则替换，MySQL 8.0+）

```sql
-- 当需要按模式替换（而非固定字符串）时，使用 REGEXP_REPLACE
-- 语法：REGEXP_REPLACE(str, pattern, replacement)

-- 去除所有数字
SELECT REGEXP_REPLACE('abc123def456', '[0-9]', '');
-- 结果：abcdef

-- 将多个连续空格替换为单个空格
SELECT REGEXP_REPLACE('Hello   World', ' +', ' ');
-- 结果：Hello World

-- 隐藏手机号中间4位（使用捕获组）
SELECT REGEXP_REPLACE('13812345678', '(\\d{3})\\d{4}(\\d{4})', '$1****$2');
-- 结果：138****5678
```

## 适用场景

- **批量数据修复**：修改大量文章中的旧 URL、品牌名变更等
- **数据清理**：去除字段中的特殊字符、空格、非法字符
- **格式标准化**：统一电话号码、产品编号的格式
- **HTML/标签清理**：简单的 HTML 标签去除（复杂情况建议在应用层处理）

---

## 常见问题

**REPLACE 和 UPDATE 一起使用会影响索引吗？**

会。`UPDATE SET col = REPLACE(col, ...)` 修改了列的值，如果该列有索引，索引会随之更新。如果批量更新大量行，会产生大量索引维护开销。对于大表批量替换，建议分批执行（LIMIT）或在低峰期操作。

---

## 注意事项

- `REPLACE()` 是大小写敏感的（不受列的 collation 影响，直接按字节比较 from_str）。如果需要大小写不敏感的替换，先将字符串转为统一大小写再处理，或使用 `REGEXP_REPLACE` 配合 `(?i)` 修饰符（MySQL 8.0+ REGEXP 支持 `(?i)` 标志）。
- 对于需要按正则表达式模式替换的场景，优先使用 MySQL 8.0+ 的 `REGEXP_REPLACE()` 函数，比嵌套 REPLACE 更灵活且可读性更好。

---

## 总结

`REPLACE(str, from_str, to_str)` 将 str 中所有的 from_str 替换为 to_str，替换所有出现项，区分大小写。在 UPDATE 中使用可以批量修改列值。多种字符需要替换时，嵌套 REPLACE 或改用 MySQL 8.0+ 的 `REGEXP_REPLACE()`。
