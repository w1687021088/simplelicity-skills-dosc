# CURDATE() 当前日期

`CURDATE()` 返回当前日期，格式为 `YYYY-MM-DD`，不包含时间部分。它是处理纯日期业务逻辑（如今日统计、生日匹配、日期对比）的基础函数。

---

## 语法

```sql
CURDATE()           -- 返回当前日期 YYYY-MM-DD
CURRENT_DATE        -- 等价于 CURDATE()，SQL 标准写法
CURRENT_DATE()      -- 等价于 CURDATE()
```

---

## 基本示例

```sql
-- 获取当前日期
SELECT CURDATE();           -- 2026-03-15
SELECT CURRENT_DATE;        -- 2026-03-15
SELECT CURRENT_DATE();      -- 2026-03-15

-- 与 NOW() 的区别
SELECT NOW();               -- 2026-03-15 14:30:25（含时间）
SELECT CURDATE();           -- 2026-03-15（只有日期）

-- 数值上下文中的 CURDATE()
SELECT CURDATE() + 0;       -- 20260315（转为整数）
SELECT CURDATE() + INTERVAL 1 DAY;  -- 2026-03-16（日期运算）
```

## 常见日期范围过滤

```sql
-- 查询今天的订单（DATETIME 类型列）
SELECT * FROM orders
WHERE created_at >= CURDATE()
  AND created_at < CURDATE() + INTERVAL 1 DAY;

-- 查询本月的订单
SELECT * FROM orders
WHERE created_at >= DATE_FORMAT(CURDATE(), '%Y-%m-01')  -- 本月第一天
  AND created_at < DATE_FORMAT(CURDATE() + INTERVAL 1 MONTH, '%Y-%m-01');  -- 下月第一天

-- 查询本周的订单（周一到今天）
SELECT * FROM orders
WHERE created_at >= CURDATE() - INTERVAL (WEEKDAY(CURDATE())) DAY
  AND created_at < CURDATE() + INTERVAL 1 DAY;

-- 查询今天生日的用户
SELECT * FROM users
WHERE MONTH(birthday) = MONTH(CURDATE())
  AND DAY(birthday) = DAY(CURDATE());

-- 查询今天及未来 7 天到期的优惠券
SELECT * FROM coupons
WHERE expire_date BETWEEN CURDATE() AND CURDATE() + INTERVAL 7 DAY;
```

## 日期计算

```sql
-- 距今天数
SELECT DATEDIFF(CURDATE(), '2026-01-01') AS days_since_new_year;
-- 距 2026 年元旦的天数

-- 今天是星期几（0=周一，6=周日）
SELECT WEEKDAY(CURDATE());

-- 今天是一年中的第几天
SELECT DAYOFYEAR(CURDATE());

-- 本月还有几天
SELECT DATEDIFF(LAST_DAY(CURDATE()), CURDATE()) AS days_remaining_in_month;
-- LAST_DAY：返回该月最后一天的日期

-- 当前季度第一天
SELECT DATE_FORMAT(CURDATE(), '%Y') + 0,
    QUARTER(CURDATE()) AS quarter_number,
    MAKEDATE(YEAR(CURDATE()), 1) + INTERVAL ((QUARTER(CURDATE()) - 1) * 3) MONTH AS quarter_start;
```

## CURDATE() 与 DATE(NOW()) 的对比

```sql
-- 两者结果相同，但 CURDATE() 更高效
SELECT CURDATE();             -- 直接返回日期
SELECT DATE(NOW());           -- 先获取 NOW() 的 DATETIME 值再转换为日期
-- 推荐使用 CURDATE()，语义更清晰，性能略好
```

## 适用场景

- **今日数据统计**：今天的订单数、注册用户数、访问量
- **日期有效性验证**：检查日期是否在有效范围内
- **生日/纪念日查询**：今日生日的用户、今日到期的合同
- **日期偏移计算**：计算 N 天前/后的日期用于过滤

---

## 常见问题

**`WHERE date_col = CURDATE()` 和 `WHERE DATE(datetime_col) = CURDATE()` 的区别？**

- `WHERE date_col = CURDATE()`：`date_col` 是 DATE 类型时，直接等值比较，可以使用索引。
- `WHERE DATE(datetime_col) = CURDATE()`：对 DATETIME 列加了函数，**导致索引失效**，应改为范围查询：`WHERE datetime_col >= CURDATE() AND datetime_col < CURDATE() + INTERVAL 1 DAY`。

---

## 注意事项

- 对 DATETIME 类型的列做"今日"过滤时，不要用 `DATE(col) = CURDATE()`（索引失效），而应该用 `col >= CURDATE() AND col < CURDATE() + INTERVAL 1 DAY` 的半开区间，确保索引可用。
- `CURDATE()` 受 MySQL 实例的系统时区影响（`time_zone` 变量），在多时区应用中需要注意时区一致性。

---

## 总结

`CURDATE()` 返回当前日期（`YYYY-MM-DD`），不含时间部分。等价写法有 `CURRENT_DATE` 和 `CURRENT_DATE()`。今日数据过滤用范围条件（`>= CURDATE()` 且 `< CURDATE() + INTERVAL 1 DAY`）而非对列加函数，保证索引可用。与 `DATE(NOW())` 效果相同但更简洁高效。
