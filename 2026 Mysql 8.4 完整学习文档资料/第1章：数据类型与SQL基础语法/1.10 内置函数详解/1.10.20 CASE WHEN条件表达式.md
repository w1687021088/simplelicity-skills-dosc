# CASE WHEN 条件表达式

`CASE WHEN` 是 MySQL 中最强大的条件表达式，支持多条件分支判断，可以出现在 SELECT、WHERE、ORDER BY、GROUP BY 和聚合函数内部等任何接受表达式的地方。它有两种语法形式：简单 CASE（等值比较）和搜索 CASE（任意条件）。

---

## 语法

```sql
-- 形式1：简单 CASE（等值比较，类似 switch）
CASE expr
    WHEN val1 THEN result1
    WHEN val2 THEN result2
    [ELSE default_result]
END

-- 形式2：搜索 CASE（任意条件，类似 if-elseif-else）
CASE
    WHEN condition1 THEN result1
    WHEN condition2 THEN result2
    [ELSE default_result]
END
```

- `ELSE` 可选，不写 ELSE 且所有 WHEN 都不匹配时返回 NULL
- 从上到下按顺序匹配，找到第一个匹配就停止（短路求值）

---

## 基本示例

```sql
-- 简单 CASE：状态码转中文
SELECT order_id,
    CASE status
        WHEN 0 THEN '待支付'
        WHEN 1 THEN '已支付'
        WHEN 2 THEN '已完成'
        WHEN 3 THEN '已取消'
        ELSE '未知状态'
    END AS status_label
FROM orders;

-- 搜索 CASE：按薪资范围分级
SELECT name, salary,
    CASE
        WHEN salary >= 30000 THEN 'S级'
        WHEN salary >= 20000 THEN 'A级'
        WHEN salary >= 12000 THEN 'B级'
        WHEN salary >= 8000  THEN 'C级'
        ELSE 'D级'
    END AS salary_grade
FROM employees;
```

## 在聚合和统计中的应用

```sql
-- 行转列（pivot）：统计各状态订单数
SELECT 
    DATE_FORMAT(created_at, '%Y-%m') AS month,
    SUM(CASE WHEN status = 0 THEN 1 ELSE 0 END) AS pending,
    SUM(CASE WHEN status = 1 THEN 1 ELSE 0 END) AS paid,
    SUM(CASE WHEN status = 2 THEN 1 ELSE 0 END) AS completed,
    SUM(CASE WHEN status = 3 THEN 1 ELSE 0 END) AS cancelled,
    COUNT(*) AS total
FROM orders
GROUP BY DATE_FORMAT(created_at, '%Y-%m')
ORDER BY month;

-- 条件 SUM（按条件分别求和）
SELECT dept_id,
    SUM(CASE WHEN gender = 'M' THEN salary ELSE 0 END) AS male_salary,
    SUM(CASE WHEN gender = 'F' THEN salary ELSE 0 END) AS female_salary,
    AVG(CASE WHEN gender = 'M' THEN salary END) AS male_avg,   -- ELSE NULL 时 AVG 忽略 NULL
    AVG(CASE WHEN gender = 'F' THEN salary END) AS female_avg
FROM employees GROUP BY dept_id;
```

## 在 ORDER BY 中使用自定义排序

```sql
-- 自定义优先级排序（不按字段值的字典序，而是按业务优先级）
SELECT * FROM tasks
ORDER BY 
    CASE priority
        WHEN 'critical' THEN 1
        WHEN 'high'     THEN 2
        WHEN 'medium'   THEN 3
        WHEN 'low'      THEN 4
        ELSE 5
    END,
    created_at ASC;

-- 将特定值排到最前（如置顶帖子）
SELECT * FROM posts
ORDER BY 
    CASE WHEN is_pinned = 1 THEN 0 ELSE 1 END,  -- 置顶的排前面
    created_at DESC;
```

## 在 WHERE 中使用（动态条件）

```sql
-- 动态查询条件（根据参数决定过滤方式）
SELECT * FROM products
WHERE 
    CASE 
        WHEN @filter_type = 'price_range' THEN price BETWEEN @min_price AND @max_price
        WHEN @filter_type = 'category'    THEN category_id = @category_id
        ELSE TRUE  -- 不过滤
    END;
-- 注意：MySQL 中 CASE 在 WHERE 里返回布尔值（1/0），可以直接作为过滤条件
```

## 在 GROUP BY 中分组

```sql
-- 按薪资范围分组统计（不需要子查询）
SELECT 
    CASE
        WHEN salary < 10000  THEN '10K以下'
        WHEN salary < 20000  THEN '10K-20K'
        WHEN salary < 30000  THEN '20K-30K'
        ELSE '30K以上'
    END AS salary_range,
    COUNT(*) AS emp_count,
    AVG(salary) AS avg_salary
FROM employees
GROUP BY 
    CASE
        WHEN salary < 10000  THEN '10K以下'
        WHEN salary < 20000  THEN '10K-20K'
        WHEN salary < 30000  THEN '20K-30K'
        ELSE '30K以上'
    END;
```

## 适用场景

- **状态/类型转换**：将数字状态码转为可读标签
- **行转列（pivot）**：将单行多状态的统计转为多列展示
- **自定义排序**：按业务优先级排序，不按字段自然值
- **数值分桶**：将连续数值按区间分组展示

---

## 常见问题

**CASE WHEN 和 IF 怎么选？**

二选一时两者都可以，IF 更简短。三种及以上条件时必须用 CASE WHEN，因为 IF 的嵌套可读性很差。在聚合（SUM/AVG）中，`CASE WHEN condition THEN val END`（没有 ELSE，即 ELSE NULL）是条件聚合的标准写法，IF 的写法是 `IF(condition, val, NULL)`，两者等价。

---

## 注意事项

- `CASE WHEN` 是短路求值：从上到下找到第一个匹配的 WHEN 就停止，不会继续检查后面的条件。因此条件顺序很重要，更具体的条件（范围更窄）应该放在前面。
- 没有 `ELSE` 子句且所有 WHEN 都不匹配时，返回 NULL，而不是报错。如果需要明确的默认值，务必加上 `ELSE` 子句。

---

## 总结

`CASE WHEN` 是 SQL 标准的多条件表达式，有简单 CASE（等值匹配）和搜索 CASE（任意条件）两种形式。可以在 SELECT、ORDER BY、GROUP BY、WHERE 和聚合函数中使用，是实现行转列、条件聚合、自定义排序等高级查询的核心工具。从上到下短路求值，没有 ELSE 时默认返回 NULL。
