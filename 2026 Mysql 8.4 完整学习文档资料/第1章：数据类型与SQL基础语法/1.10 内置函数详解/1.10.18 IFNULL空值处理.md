# IFNULL 空值处理

`IFNULL()` 函数检查第一个参数是否为 NULL，如果是 NULL 则返回第二个参数（默认值），如果不是 NULL 则返回第一个参数本身。它是处理 NULL 值的专用简化函数，等价于 `IF(expr IS NULL, null_result, expr)`。

---

## 语法

```sql
IFNULL(expr1, expr2)
-- expr1 非 NULL：返回 expr1
-- expr1 为 NULL：返回 expr2
```

---

## 基本示例

```sql
-- 基础用法
SELECT IFNULL(NULL, '默认值');      -- '默认值'
SELECT IFNULL('实际值', '默认值');  -- '实际值'
SELECT IFNULL(0, '默认值');         -- 0（0 不是 NULL，返回原值）
SELECT IFNULL('', '默认值');        -- ''（空字符串不是 NULL，返回空字符串）

-- 在查询中使用
SELECT id,
    IFNULL(phone, '未填写') AS phone,
    IFNULL(address, '地址未录入') AS address
FROM users;

-- 数值类型的默认值
SELECT product_id,
    IFNULL(discount_price, price) AS final_price  -- 无折扣价时用原价
FROM products;
```

---

## 常见业务场景

```sql
-- 场景1：聚合计算中 NULL 的处理
SELECT dept_id,
    SUM(IFNULL(bonus, 0)) AS total_bonus  -- bonus 为 NULL 时算 0
FROM employees
GROUP BY dept_id;
-- 注意：SUM 本身忽略 NULL，效果上与 SUM(bonus) 相同
-- 但 AVG 不同：AVG(bonus) 只对非 NULL 行求均值，
--             AVG(IFNULL(bonus, 0)) 对 NULL 行也算 0，两者语义不同

-- 场景2：LEFT JOIN 后 NULL 列的默认值
SELECT u.id, u.username,
    IFNULL(SUM(o.amount), 0) AS total_spent
FROM users u
LEFT JOIN orders o ON u.id = o.user_id AND o.status = 2
GROUP BY u.id, u.username;
-- 没有订单的用户，SUM 返回 NULL，IFNULL 转为 0

-- 场景3：连接字段中的 NULL（防止整串变 NULL）
SELECT CONCAT(
    IFNULL(first_name, ''),
    ' ',
    IFNULL(last_name, '')
) AS full_name
FROM users;
-- 用 IFNULL 替代 CONCAT_WS 时的写法

-- 场景4：NULL 值排序（NULL 排最后）
SELECT id, name, score
FROM students
ORDER BY IFNULL(score, -1) DESC;  -- 把 NULL 当 -1，排在最后
-- 也可以：ORDER BY score IS NULL ASC, score DESC
```

---

## IFNULL vs COALESCE vs IF IS NULL

```sql
-- 三种写法效果相同
SELECT IFNULL(col, 'default') FROM t;
SELECT COALESCE(col, 'default') FROM t;
SELECT IF(col IS NULL, 'default', col) FROM t;

-- 区别：
-- IFNULL：只处理 1 个可能为 NULL 的值，有且仅有 2 个参数
-- COALESCE：处理多个值，返回第一个非 NULL 的值，参数数量不限
-- IF IS NULL：最冗长，完全可以用 IFNULL 代替

-- COALESCE 的优势：多个备选值
SELECT COALESCE(mobile, phone, email, '无联系方式') AS contact FROM users;
-- 优先用 mobile，没有就用 phone，再没有就用 email，全空则显示 '无联系方式'
-- IFNULL 做不到多级备选
```

## NULLIF（与 IFNULL 相反的函数）

```sql
-- NULLIF(expr1, expr2)：如果 expr1 = expr2，返回 NULL；否则返回 expr1
SELECT NULLIF(5, 5);    -- NULL（相等，返回 NULL）
SELECT NULLIF(5, 6);    -- 5（不等，返回 expr1）
SELECT NULLIF('', '');  -- NULL（可用于将空字符串转为 NULL）

-- 应用场景：防止除以零
SELECT total_amount / NULLIF(order_count, 0) AS avg_order_amount
FROM sales_summary;
-- 当 order_count = 0 时，NULLIF 返回 NULL，除以 NULL = NULL，避免除以零报错
```

---

## 适用场景

- **NULL 默认值替换**：展示层将 NULL 替换为更友好的文本或默认数值
- **LEFT JOIN 结果处理**：将无匹配行的 NULL 聚合结果转为 0
- **防除零**：配合 NULLIF 防止 `除以零` 错误（`a / NULLIF(b, 0)`）
- **连接字段保护**：CONCAT 中确保没有 NULL 导致整体为 NULL

---

## 常见问题

**IFNULL(0, 'default') 返回什么？**

返回 0，不是 'default'。`0`、空字符串 `''`、`FALSE` 都不是 NULL，只有 NULL 才是 NULL。`IFNULL` 只检查是否为 NULL，不检查是否为"假值"。

---

## 注意事项

- IFNULL 只有 2 个参数，如果需要多级备选值（第一个为 NULL 就用第二个，第二个也是 NULL 就用第三个），应该使用 `COALESCE()`。
- 在需要区分 NULL 和空字符串 `''` 的场景（它们是不同值），只有 `IS NULL` 检查才能识别 NULL，`= ''` 无法匹配 NULL。

---

## 总结

`IFNULL(expr1, expr2)` 在 expr1 为 NULL 时返回 expr2，否则返回 expr1。它是 NULL 值处理的最简洁写法，等价于 2 参数的 COALESCE。只有真正的 NULL 会触发替换，0 和空字符串不会。`NULLIF(a, b)` 是其逆向操作：相等时返回 NULL，用于防除零等场景。需要多个备选值时用 COALESCE 替代 IFNULL。
