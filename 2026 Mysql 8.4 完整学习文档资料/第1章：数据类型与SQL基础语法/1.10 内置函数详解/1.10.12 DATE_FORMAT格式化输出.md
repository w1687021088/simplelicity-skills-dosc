# DATE_FORMAT 格式化输出

`DATE_FORMAT()` 将日期或日期时间值按照指定格式转换为字符串，是最常用的日期格式化函数。无论是生成报表标题、按月/周分组统计，还是输出用户友好的日期显示，都离不开它。

---

## 语法

```sql
DATE_FORMAT(date, format)
TIME_FORMAT(time, format)   -- 专门用于时间部分的格式化
```

---

## 常用格式符

| 格式符 | 含义 | 示例（2026-03-15 14:30:05）|
|-------|------|--------------------------|
| `%Y` | 4位年份 | 2026 |
| `%y` | 2位年份 | 26 |
| `%m` | 2位月份（01-12）| 03 |
| `%c` | 月份（1-12，无前导零）| 3 |
| `%d` | 2位日（01-31）| 15 |
| `%e` | 日（1-31，无前导零）| 15 |
| `%H` | 24小时制小时（00-23）| 14 |
| `%h` | 12小时制小时（01-12）| 02 |
| `%i` | 分钟（00-59）| 30 |
| `%s` | 秒（00-59）| 05 |
| `%p` | AM/PM | PM |
| `%W` | 星期英文全称 | Sunday |
| `%w` | 星期数字（0=周日，6=周六）| 0 |
| `%j` | 一年中的第几天（001-366）| 074 |
| `%U` | 周数（00-53，周日为第一天）| 11 |
| `%V` | 周数（01-53，周一为第一天，配合 %X）| 11 |
| `%X` | 周所属年份（配合 %V 使用）| 2026 |
| `%f` | 微秒（000000-999999）| 000000 |

---

## 基本示例

```sql
-- 标准日期格式
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d');             -- 2026-03-15
SELECT DATE_FORMAT(NOW(), '%Y/%m/%d');             -- 2026/03/15
SELECT DATE_FORMAT(NOW(), '%d/%m/%Y');             -- 15/03/2026

-- 含时间的格式
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:%i:%s');    -- 2026-03-15 14:30:05

-- 中文风格
SELECT DATE_FORMAT(NOW(), '%Y年%m月%d日');          -- 2026年03月15日
SELECT DATE_FORMAT(NOW(), '%Y年%m月%d日 %H时%i分'); -- 2026年03月15日 14时30分

-- 12小时制
SELECT DATE_FORMAT(NOW(), '%h:%i:%s %p');          -- 02:30:05 PM
```

## 在 GROUP BY 中按时间维度聚合

```sql
-- 按年月统计订单量（月报）
SELECT DATE_FORMAT(created_at, '%Y-%m') AS month,
       COUNT(*) AS order_count,
       SUM(amount) AS total_amount
FROM orders
WHERE status = 2
GROUP BY DATE_FORMAT(created_at, '%Y-%m')
ORDER BY month;

-- 按周统计（%X-%V：年份-周数，确保跨年周正确处理）
SELECT DATE_FORMAT(created_at, '%X年第%V周') AS week,
       COUNT(*) AS order_count
FROM orders
GROUP BY DATE_FORMAT(created_at, '%X-%V')
ORDER BY DATE_FORMAT(created_at, '%X-%V');

-- 按星期分布
SELECT DATE_FORMAT(created_at, '%W') AS weekday,
       COUNT(*) AS count
FROM orders
GROUP BY WEEKDAY(created_at), DATE_FORMAT(created_at, '%W')
ORDER BY WEEKDAY(created_at);
-- 注意：GROUP BY 用 WEEKDAY 确保排序正确，SELECT 用 DATE_FORMAT 显示名称
```

## STR_TO_DATE（DATE_FORMAT 的逆向操作）

```sql
-- 将非标准格式的字符串转为 DATE 类型
SELECT STR_TO_DATE('15/03/2026', '%d/%m/%Y');   -- 2026-03-15
SELECT STR_TO_DATE('2026年03月15日', '%Y年%m月%d日');  -- 2026-03-15

-- 在 INSERT 时转换用户输入的日期字符串
INSERT INTO events (event_date, title)
VALUES (STR_TO_DATE('2026/3/15', '%Y/%c/%e'), '活动名称');
```

## 与 EXTRACT 函数的配合

```sql
-- EXTRACT：从日期时间中提取特定部分（返回整数）
SELECT EXTRACT(YEAR FROM NOW());     -- 2026
SELECT EXTRACT(MONTH FROM NOW());    -- 3
SELECT EXTRACT(DAY FROM NOW());      -- 15
SELECT EXTRACT(HOUR FROM NOW());     -- 14
SELECT EXTRACT(WEEK FROM NOW());     -- 11

-- 等价的函数：YEAR(), MONTH(), DAY(), HOUR(), MINUTE(), SECOND()
SELECT YEAR(NOW()), MONTH(NOW()), DAY(NOW());
```

## 适用场景

- **报表维度格式化**：将 DATETIME 格式化为年月（`%Y-%m`）用于 GROUP BY 月统计
- **用户显示**：将存储的标准日期转为用户友好的格式（中文日期、本地化格式）
- **日期导出**：CSV 导出时统一日期格式
- **解析导入数据**：用 `STR_TO_DATE` 将各种格式的日期字符串转为标准日期类型

---

## 常见问题

**DATE_FORMAT 对 GROUP BY 的性能有影响吗？**

有一定影响。对 DATETIME 列调用 `DATE_FORMAT` 后，该列的索引就无法直接使用了，GROUP BY 需要全表扫描或 filesort。对于大表，如果按月分组是高频操作，可以考虑额外存储一个 `DATE_FORMAT(created_at, '%Y-%m')` 的生成列（Generated Column）并建立索引。

---

## 注意事项

- `DATE_FORMAT` 对 DATETIME 列加函数会导致 WHERE 中该列的索引失效。时间范围过滤要写成范围条件（`created_at >= '2026-03-01' AND created_at < '2026-04-01'`），不要写成 `DATE_FORMAT(created_at, '%Y-%m') = '2026-03'`。
- `%y`（2位年）在跨世纪时可能有歧义（如 `26` 是 2026 还是 1926？），日期显示推荐始终用 `%Y`（4位年）。

---

## 总结

`DATE_FORMAT(date, format)` 将日期/时间按格式字符串转为可读字符串，支持丰富的格式符（年月日时分秒、星期、周数等）。在 GROUP BY 中按时间维度聚合时常用（按月用 `%Y-%m`，按周用 `%X-%V`）。`STR_TO_DATE` 是其逆操作，将格式化字符串转回 DATE 类型。WHERE 过滤中避免对日期列调用 DATE_FORMAT，改用范围条件保证索引可用。
