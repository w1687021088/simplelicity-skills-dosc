# CURTIME() 当前时间

`CURTIME()` 返回当前时间，格式为 `HH:MM:SS`，不包含日期部分。它用于需要处理纯时间逻辑的场景，如营业时间判断、班次判断、每日时间段统计等。

---

## 语法

```sql
CURTIME()           -- 返回当前时间 HH:MM:SS
CURTIME(fsp)        -- 带小数秒精度（fsp=0~6）
CURRENT_TIME        -- 等价于 CURTIME()，SQL 标准写法
CURRENT_TIME()      -- 等价于 CURTIME()
```

---

## 基本示例

```sql
-- 获取当前时间
SELECT CURTIME();           -- 14:30:25
SELECT CURRENT_TIME;        -- 14:30:25
SELECT CURTIME(3);          -- 14:30:25.123（毫秒精度）

-- 与 NOW() 的区别
SELECT NOW();               -- 2026-03-15 14:30:25（日期 + 时间）
SELECT CURDATE();           -- 2026-03-15（只有日期）
SELECT CURTIME();           -- 14:30:25（只有时间）

-- 数值上下文
SELECT CURTIME() + 0;       -- 143025（转为整数）
```

## 营业时间和班次判断

```sql
-- 判断当前是否在营业时间内（09:00 - 22:00）
SELECT 
    CASE 
        WHEN CURTIME() BETWEEN '09:00:00' AND '22:00:00' THEN '营业中'
        ELSE '休息中'
    END AS status;

-- 根据当前时间分配班次
SELECT
    CASE 
        WHEN CURTIME() BETWEEN '08:00:00' AND '15:59:59' THEN '早班'
        WHEN CURTIME() BETWEEN '16:00:00' AND '23:59:59' THEN '晚班'
        ELSE '夜班'
    END AS shift;

-- 查询当前时间段内活跃的促销活动
SELECT promo_name, start_time, end_time
FROM promotions
WHERE CURDATE() BETWEEN start_date AND end_date
  AND CURTIME() BETWEEN start_time AND end_time
  AND is_active = 1;
```

## 时间段统计

```sql
-- 统计各小时的订单量分布（今天）
SELECT HOUR(created_at) AS hour,
       COUNT(*) AS order_cnt
FROM orders
WHERE created_at >= CURDATE()
  AND created_at < CURDATE() + INTERVAL 1 DAY
GROUP BY HOUR(created_at)
ORDER BY hour;

-- 统计当前小时的实时下单量
SELECT COUNT(*) AS current_hour_orders
FROM orders
WHERE created_at >= CONCAT(CURDATE(), ' ', HOUR(CURTIME()), ':00:00')
  AND created_at < CONCAT(CURDATE(), ' ', HOUR(CURTIME()), ':59:59');
```

## TIME 类型的相关函数

```sql
-- ADDTIME：给时间加上一个时间间隔
SELECT ADDTIME(CURTIME(), '01:30:00');  -- 当前时间 + 1小时30分

-- SUBTIME：减去时间间隔
SELECT SUBTIME(CURTIME(), '00:30:00');  -- 当前时间 - 30分钟

-- TIMEDIFF：两个时间的差值
SELECT TIMEDIFF('18:00:00', CURTIME()) AS remaining;
-- 距 18:00 还有多少时间

-- TIME()：从 DATETIME 中提取时间部分
SELECT TIME(NOW());  -- 等价于 CURTIME()
```

## 适用场景

- **营业时间判断**：是否在工作时间、营业时间内
- **班次管理**：根据当前时间分配或统计各班次数据
- **时间段内的实时统计**：当前小时的数据量、当前时间段的活跃用户数
- **定时任务触发条件**：在存储过程中判断是否到达执行时间点

## 常见问题

**TIME 类型的列可以直接和 CURTIME() 比较吗？**

可以。TIME 类型的列存储的就是时间（`HH:MM:SS`），可以直接与 `CURTIME()` 进行大小比较：`WHERE close_time > CURTIME()` 表示"营业结束时间在当前时间之后（即还未关门）"。

---

## 注意事项

- `CURTIME()` 返回的时间不含日期，不适合直接与 DATETIME 类型的列比较。对 DATETIME 列提取时间部分应用 `TIME(col)` 函数，但这会导致索引失效。如需高效过滤，最好将时间分段用 DATETIME 范围表示。
- `CURTIME()` 受 `time_zone` 变量影响，与 `CURDATE()` 和 `NOW()` 一致。

---

## 总结

`CURTIME()` 返回当前时间（`HH:MM:SS`），不含日期部分，支持小数秒精度（`CURTIME(n)`）。等价写法为 `CURRENT_TIME`。适合营业时间判断、班次分配、时间段统计等纯时间逻辑场景。与 DATETIME 列比较时需要注意类型转换和索引影响。
