# COALESCE 多值空值处理

`COALESCE()` 函数接受多个参数，返回参数列表中**第一个非 NULL** 的值。如果所有参数都是 NULL，则返回 NULL。它是处理多级备选值和 NULL 替换的最灵活工具，也是 SQL 标准函数（所有主流数据库都支持）。

---

## 语法

```sql
COALESCE(val1, val2, val3, ...)
-- 从左到右依次检查，返回第一个非 NULL 的值
-- 所有值都是 NULL 时，返回 NULL
```

---

## 基本示例

```sql
-- 基础用法
SELECT COALESCE(NULL, NULL, 'third', 'fourth');  -- 'third'（第一个非 NULL）
SELECT COALESCE(NULL, NULL, NULL);               -- NULL（全 NULL）
SELECT COALESCE('first', 'second');              -- 'first'（第一个就非 NULL）
SELECT COALESCE(NULL, 0);                        -- 0

-- 与 IFNULL 的对比
-- IFNULL：只有 2 个参数
SELECT IFNULL(NULL, 'default');        -- 'default'
-- COALESCE：任意多个参数（推荐在多级备选时使用）
SELECT COALESCE(NULL, NULL, 'default'); -- 'default'
```

## 多级备选联系方式

```sql
-- 查询用户最优联系方式（优先用手机，其次固话，再次邮件）
SELECT id, username,
    COALESCE(mobile, landline, email, '无联系方式') AS best_contact
FROM users;
-- mobile 不为 NULL 就用 mobile
-- mobile 为 NULL 但 landline 不为 NULL 就用 landline
-- 两者都为 NULL 但 email 不为 NULL 就用 email
-- 全都为 NULL 就返回 '无联系方式'
```

## 常见业务场景

```sql
-- 场景1：价格优先级（特价 > 会员价 > 原价）
SELECT product_id, name,
    COALESCE(special_price, member_price, original_price) AS final_price
FROM products;

-- 场景2：地址补全（优先使用完整地址，其次用城市+省份）
SELECT id,
    COALESCE(
        full_address,
        CONCAT_WS(', ', city, province),
        province,
        '未知地区'
    ) AS display_address
FROM customers;

-- 场景3：UPDATE 中使用（只更新非 NULL 的值，保留旧值）
UPDATE user_profiles
SET 
    nickname = COALESCE(@new_nickname, nickname),    -- 如果传入 NULL，保留原值
    bio      = COALESCE(@new_bio, bio),
    avatar   = COALESCE(@new_avatar, avatar)
WHERE user_id = 100;
-- 这是"部分更新"模式：只更新传了新值的字段，NULL 表示"不改"

-- 场景4：LEFT JOIN 后的数值默认值
SELECT u.id, u.username,
    COALESCE(stats.order_count, 0)   AS order_count,
    COALESCE(stats.total_amount, 0)  AS total_amount,
    COALESCE(stats.avg_amount, 0.00) AS avg_amount
FROM users u
LEFT JOIN (
    SELECT user_id,
           COUNT(*) AS order_count,
           SUM(amount) AS total_amount,
           AVG(amount) AS avg_amount
    FROM orders WHERE status = 2
    GROUP BY user_id
) stats ON u.id = stats.user_id;
-- 没有订单的用户，stats 列全为 NULL，COALESCE 给默认值 0
```

## COALESCE 的短路求值

```sql
-- COALESCE 对参数进行短路求值：一旦找到非 NULL 值就停止
-- 这意味着后面的参数不会被计算（如果前面已经找到非 NULL 值）

-- 实际应用：避免不必要的子查询计算
SELECT COALESCE(
    (SELECT cached_value FROM cache WHERE key = 'stat_total'),
    (SELECT COUNT(*) FROM orders WHERE status = 2)  -- 只有缓存为 NULL 时才执行
) AS total_orders;
-- 如果缓存有值，第二个子查询根本不执行（MySQL 8.0 优化）
```

## COALESCE 与空字符串的区别

```sql
-- COALESCE 只处理 NULL，不处理空字符串 ''
SELECT COALESCE('', 'default');     -- ''（空字符串不是 NULL，返回空字符串）
SELECT COALESCE(NULL, 'default');   -- 'default'

-- 如果需要同时处理 NULL 和空字符串：
SELECT COALESCE(NULLIF(col, ''), 'default') FROM t;
-- NULLIF(col, '') 将空字符串转为 NULL，再用 COALESCE 替换
```

---

## 适用场景

- **多级备选值**：从优先级由高到低的多个列中取第一个有值的列
- **NULL 安全的默认值**：确保计算中不出现 NULL（如聚合结果的默认 0）
- **部分更新模式**：`SET col = COALESCE(@new_val, col)` 只更新非 NULL 的新值
- **统一缺失数据表示**：将多列的 NULL 统一替换为标准的"无数据"文本

---

## 常见问题

**COALESCE 和 IFNULL 怎么选？**

只有 2 个参数时两者等价，可以随意选择（IFNULL 更简短，COALESCE 是 SQL 标准可移植性更好）。需要 3 个及以上备选值时，必须用 COALESCE（IFNULL 做不到）。在团队中，统一用 COALESCE 可以保持风格一致。

---

## 注意事项

- COALESCE 是 SQL 标准函数，在 MySQL、PostgreSQL、SQL Server、Oracle 中行为完全相同，可移植性优于 IFNULL（IFNULL 是 MySQL 特有的）。
- COALESCE 不区分 NULL 和空字符串。如果需要同时处理两者，先用 `NULLIF(col, '')` 将空字符串转为 NULL，再套 COALESCE。

---

## 总结

`COALESCE(val1, val2, ...)` 返回参数列表中第一个非 NULL 的值，是处理多级备选和 NULL 默认值的最通用函数。与 IFNULL 的区别是支持任意数量的参数。是 SQL 标准函数，比 IFNULL 可移植性更好。只处理 NULL，不处理空字符串（空字符串需先用 NULLIF 转为 NULL）。
