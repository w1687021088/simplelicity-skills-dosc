# DATE_SUB 日期减法

`DATE_SUB()` 从日期或日期时间值中减去一个时间间隔，返回新的日期时间值。它与 `DATE_ADD()` 互为镜像操作，用于计算过去某个时间点、设定最早有效日期边界等场景。

---

## 语法

```sql
DATE_SUB(date, INTERVAL expr unit)
SUBDATE(date, INTERVAL expr unit)      -- DATE_SUB 的同义函数
date - INTERVAL expr unit              -- 运算符写法（等价）
```

---

## 基本示例

```sql
-- 减天数
SELECT DATE_SUB('2026-03-15', INTERVAL 7 DAY);   -- 2026-03-08
SELECT DATE_SUB(CURDATE(), INTERVAL 30 DAY);      -- 30天前的日期

-- 减月数
SELECT DATE_SUB('2026-03-31', INTERVAL 1 MONTH);  -- 2026-02-28（月末截断）

-- 减年
SELECT DATE_SUB('2026-03-15', INTERVAL 1 YEAR);   -- 2025-03-15

-- 减小时/分钟
SELECT DATE_SUB(NOW(), INTERVAL 2 HOUR);           -- 2小时前
SELECT DATE_SUB(NOW(), INTERVAL 90 MINUTE);        -- 90分钟前

-- 运算符写法（等价，更简洁）
SELECT CURDATE() - INTERVAL 7 DAY;    -- 7天前
SELECT NOW() - INTERVAL 1 HOUR;       -- 1小时前
```

---

## 常见业务场景

```sql
-- 查询最近 30 天的订单
SELECT COUNT(*) AS recent_orders
FROM orders
WHERE created_at >= DATE_SUB(NOW(), INTERVAL 30 DAY)
  AND status = 2;

-- 查询超过 1 年未登录的用户（僵尸用户）
SELECT id, username, last_login_at
FROM users
WHERE last_login_at < DATE_SUB(NOW(), INTERVAL 1 YEAR)
   OR last_login_at IS NULL;

-- 查询最近 3 个月的销售额按月统计
SELECT DATE_FORMAT(created_at, '%Y-%m') AS month,
       SUM(amount) AS total
FROM orders
WHERE created_at >= DATE_SUB(CURDATE(), INTERVAL 3 MONTH)
  AND status = 2
GROUP BY DATE_FORMAT(created_at, '%Y-%m')
ORDER BY month;

-- 删除 90 天前的过期 session
DELETE FROM sessions
WHERE created_at < DATE_SUB(NOW(), INTERVAL 90 DAY);
-- 分批删除建议加 LIMIT
```

## 上周/上月日期边界计算

```sql
-- 上周的日期范围（周一到周日）
SELECT 
    CURDATE() - INTERVAL WEEKDAY(CURDATE()) + 7 DAY AS last_week_start,
    CURDATE() - INTERVAL WEEKDAY(CURDATE()) + 1 DAY AS last_week_end;

-- 上月的日期范围
SELECT 
    DATE_FORMAT(DATE_SUB(CURDATE(), INTERVAL 1 MONTH), '%Y-%m-01') AS last_month_start,
    DATE_FORMAT(CURDATE(), '%Y-%m-01') AS this_month_start;  -- 上月结束 = 本月开始
-- 查询上月数据：
WHERE created_at >= last_month_start AND created_at < this_month_start
```

## DATE_SUB 与 DATE_ADD 的对比

```sql
-- 以下三种写法完全等价
SELECT DATE_ADD('2026-03-15', INTERVAL -7 DAY);  -- DATE_ADD + 负数
SELECT DATE_SUB('2026-03-15', INTERVAL 7 DAY);   -- DATE_SUB + 正数
SELECT '2026-03-15' - INTERVAL 7 DAY;            -- 运算符写法

-- 推荐约定：
-- 向后推算（未来时间）：DATE_ADD 或 + INTERVAL
-- 向前回溯（过去时间）：DATE_SUB 或 - INTERVAL
-- 这样语义最清晰
```

## 适用场景

- **历史数据查询**：查询最近 N 天/月/年的数据
- **数据归档和清理**：删除超过 N 天的过期日志、session、临时数据
- **统计周期边界**：上周、上月、上季度的开始日期
- **有效期回溯**：判断某个记录是否在 N 天内创建

---

## 常见问题

**DATE_SUB 和直接使用 `- INTERVAL` 运算符有性能差异吗？**

没有。`date - INTERVAL n unit` 和 `DATE_SUB(date, INTERVAL n unit)` 是完全等价的，MySQL 内部处理方式相同。选择哪种写法只是代码风格的问题，运算符写法更简洁，DATE_SUB 函数写法更明确。

---

## 注意事项

- 与 DATE_ADD 一样，DATE_SUB 在减月数时也会有月末截断：`DATE_SUB('2026-03-31', INTERVAL 1 MONTH)` 返回 `2026-02-28`（2月没有31日）。
- 对被查询列做日期计算（如 `DATE_SUB(col, INTERVAL 1 DAY)`）会导致索引失效。始终对**常量端**用 DATE_SUB，对**列端**保持原始形式：`WHERE col >= DATE_SUB(NOW(), INTERVAL 30 DAY)`，这样 col 上的索引可用。

---

## 总结

`DATE_SUB(date, INTERVAL expr unit)` 从日期值中减去时间间隔，与 `DATE_ADD` 互为逆操作，等价写法为 `date - INTERVAL expr unit`。减月数时有月末截断行为。用于历史数据查询、过期数据清理、统计周期边界计算。在 WHERE 条件中，应对常量端使用 DATE_SUB，保持列端不加函数，以确保索引可用。
