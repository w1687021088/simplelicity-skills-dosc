# FLOOR 向下取整

`FLOOR()` 函数返回不大于参数值的最大整数，即向下取整（地板函数）。对正数来说，就是去掉小数部分；对负数来说，则是向更负的方向取整。

---

## 语法

```sql
FLOOR(X)
```

---

## 基本示例

```sql
-- 正数向下取整（去掉小数部分）
SELECT FLOOR(3.0);    -- 3
SELECT FLOOR(3.9);    -- 3（小于等于 3.9 的最大整数是 3）
SELECT FLOOR(3.1);    -- 3

-- 负数向下取整（向更负的方向）
SELECT FLOOR(-3.1);   -- -4（小于等于 -3.1 的最大整数是 -4）
SELECT FLOOR(-3.9);   -- -4
SELECT FLOOR(-3.0);   -- -3

-- 整数不变
SELECT FLOOR(5);      -- 5
SELECT FLOOR(-5);     -- -5
```

---

## 常见业务场景

```sql
-- 将精确金额向下舍入（对用户优惠，不多收）
SELECT price,
    FLOOR(price * 0.9 * 100) / 100 AS discounted_price
FROM products;
-- 避免四舍五入导致的多收情况，例如 9.999 → 9.99 而不是 10.00

-- 计算整数部分（等价于 TRUNCATE(x, 0) 对正数）
SELECT FLOOR(salary / 1000) * 1000 AS salary_bracket FROM employees;
-- 将薪资归入千元档：12500 → 12000

-- 生成随机整数（0 到 N-1）
SELECT FLOOR(RAND() * 10) AS random_0_to_9;
-- RAND() 返回 [0, 1) 的随机浮点数，* 10 得 [0, 10)，FLOOR 得 0~9 的整数

-- 生成指定范围的随机整数（min 到 max，包含两端）
SELECT FLOOR(min_val + RAND() * (max_val - min_val + 1)) AS random_in_range;
-- 例如生成 1~100 的随机整数：
SELECT FLOOR(1 + RAND() * 100) AS rand_1_to_100;

-- 年龄段分组（每10岁一档）
SELECT FLOOR(age / 10) * 10 AS age_group, COUNT(*) AS cnt
FROM users
GROUP BY FLOOR(age / 10) * 10
ORDER BY age_group;
-- 20岁档、30岁档、40岁档...
```

## FLOOR vs CEIL vs TRUNCATE（正负数行为差异）

```sql
-- 正数 3.7
SELECT FLOOR(3.7),      -- 3（向下）
       CEIL(3.7),       -- 4（向上）
       TRUNCATE(3.7,0); -- 3（向零截断）

-- 负数 -3.7
SELECT FLOOR(-3.7),      -- -4（向下，即远离 0）
       CEIL(-3.7),       -- -3（向上，即朝向 0）
       TRUNCATE(-3.7,0); -- -3（向零截断，同 CEIL）
```

## FLOOR 与随机数生成

```sql
-- 抽奖场景：从用户中随机选 1 个（不推荐大表）
SELECT * FROM users ORDER BY RAND() LIMIT 1;

-- 更高效的方式（大表时）：先获取总数，再随机 FLOOR
SELECT * FROM users
WHERE id >= FLOOR(1 + RAND() * (SELECT MAX(id) FROM users))
LIMIT 1;
-- 注意：如果 id 有空洞（不连续），可能需要再查一次

-- 随机分配测试组（A/B 测试）
UPDATE users
SET test_group = FLOOR(RAND() * 3)  -- 随机分为 0、1、2 三组
WHERE test_group IS NULL;
```

## 适用场景

- **向下舍入金额**：优惠计算中不多收一分钱
- **分桶分组**：按数值区间归类（千元薪资档、年龄段等）
- **随机整数生成**：配合 `RAND()` 生成指定范围的随机整数
- **整数运算**：取浮点数的整数部分（等价于正数的 TRUNCATE）

---

## 常见问题

**FLOOR 和 TRUNCATE(X, 0) 对正数一样，有什么区别？**

对正数，`FLOOR(X)` 和 `TRUNCATE(X, 0)` 结果相同（都是去掉小数）。区别在负数：
- `FLOOR(-3.7)` = -4（远离 0）
- `TRUNCATE(-3.7, 0)` = -3（朝向 0）

在处理正数时两者可互换，在处理负数时行为不同。

---

## 注意事项

- `FLOOR(RAND() * N)` 生成 `0` 到 `N-1` 的随机整数，如果需要 `1` 到 `N`，用 `FLOOR(1 + RAND() * N)`。
- 对负数使用 FLOOR 会得到比直觉中"截断"更小的值，注意处理有符号数时的行为差异。

---

## 总结

`FLOOR(X)` 返回不大于 X 的最大整数（向下取整）。对正数等同于去掉小数部分；对负数向更负的方向（远离 0）取整，这与 TRUNCATE 对负数的处理不同。最常用于生成随机整数（`FLOOR(RAND() * N)`）和数值分桶分组。
