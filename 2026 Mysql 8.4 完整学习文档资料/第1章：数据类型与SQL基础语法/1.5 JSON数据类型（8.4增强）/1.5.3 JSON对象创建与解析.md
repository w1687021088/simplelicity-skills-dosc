## JSON 对象创建与解析

JSON 对象（`{}`）是 JSON 文档中最常用的结构，用于存储键值对集合。MySQL 提供了 `JSON_OBJECT()` 函数用于在 SQL 中动态创建 JSON 对象，以及 `JSON_EXTRACT()`、`->` 操作符等用于解析和访问对象字段。

---

### JSON_OBJECT 创建对象

```sql
JSON_OBJECT(key1, val1, key2, val2, ...)
```

```sql
-- 动态构建 JSON 对象
SELECT JSON_OBJECT('name', 'Alice', 'age', 28, 'city', '北京') AS user_json;
-- 输出：{"age": 28, "city": "北京", "name": "Alice"}
-- 注意：key 按字母顺序排序（内部存储优化）

-- 从表中构建 JSON 对象
SELECT JSON_OBJECT('id', id, 'username', username, 'email', email) AS user_data
FROM users WHERE id = 1001;

-- 嵌套对象：JSON_OBJECT 支持嵌套
SELECT JSON_OBJECT(
    'user', JSON_OBJECT('name', 'Bob', 'age', 30),
    'role', 'admin'
) AS nested_json;
-- 输出：{"role": "admin", "user": {"age": 30, "name": "Bob"}}

-- JSON_OBJECT 中的 NULL 值处理
SELECT JSON_OBJECT('name', 'Carol', 'phone', NULL);
-- 输出：{"name": "Carol", "phone": null}
```

---

### JSON_EXTRACT 解析字段

```sql
JSON_EXTRACT(json_doc, path)
-- 等同于 json_doc -> path
```

```sql
-- 示例数据
SET @user = '{"name": "Alice", "age": 28, "address": {"city": "北京", "zip": "100000"}}';

-- 提取顶层字段
SELECT JSON_EXTRACT(@user, '$.name');      -- "Alice"（带引号）
SELECT JSON_EXTRACT(@user, '$.age');       -- 28（数字）

-- 使用 -> 操作符（等价于 JSON_EXTRACT）
SELECT @user -> '$.name';                  -- "Alice"

-- 使用 ->> 操作符（等价于 JSON_UNQUOTE(JSON_EXTRACT())）
SELECT @user ->> '$.name';                 -- Alice（不带引号）

-- 提取嵌套字段
SELECT JSON_EXTRACT(@user, '$.address.city');  -- "北京"
SELECT @user ->> '$.address.city';             -- 北京

-- 提取不存在的字段
SELECT JSON_EXTRACT(@user, '$.phone');     -- NULL（字段不存在返回 NULL）
```

### 解析表中的 JSON 列

```sql
-- 测试表
CREATE TABLE products (
    id      INT UNSIGNED NOT NULL AUTO_INCREMENT,
    name    VARCHAR(200) NOT NULL,
    meta    JSON,
    PRIMARY KEY (id)
);

INSERT INTO products (name, meta) VALUES 
('iPhone 16', '{"color": "black", "storage": 256, "price": 7999.00, "in_stock": true}'),
('MacBook Pro', '{"color": "silver", "cpu": "M4", "ram": 16, "price": 14999.00, "in_stock": false}');

-- 提取 JSON 字段作为查询列
SELECT 
    id,
    name,
    meta ->> '$.color' AS color,
    meta -> '$.price' AS price_json,      -- 带引号：7999.00
    meta ->> '$.price' AS price_str,      -- 不带引号：7999.00
    CAST(meta ->> '$.price' AS DECIMAL(10, 2)) AS price_num  -- 转为数值
FROM products;

-- WHERE 条件中使用 JSON 字段
SELECT * FROM products WHERE meta ->> '$.in_stock' = 'true';
SELECT * FROM products WHERE CAST(meta ->> '$.price' AS UNSIGNED) < 10000;
```

### JSON_KEYS 获取对象的所有键

```sql
-- 获取 JSON 对象的所有顶层 key
SELECT JSON_KEYS('{"name": "Alice", "age": 28, "city": "北京"}');
-- 输出：["age", "city", "name"]（按字母序）

-- 获取嵌套路径的 key
SET @data = '{"user": {"name": "Bob", "role": "admin"}, "token": "abc123"}';
SELECT JSON_KEYS(@data, '$.user');
-- 输出：["name", "role"]
```

---

### JSON_CONTAINS_PATH 检查路径是否存在

```sql
SET @user = '{"name": "Alice", "address": {"city": "北京"}}';

-- 检查路径是否存在（one：至少一个存在，all：全部存在）
SELECT JSON_CONTAINS_PATH(@user, 'one', '$.name');           -- 1（存在）
SELECT JSON_CONTAINS_PATH(@user, 'one', '$.phone');          -- 0（不存在）
SELECT JSON_CONTAINS_PATH(@user, 'all', '$.name', '$.address.city');  -- 1（都存在）
SELECT JSON_CONTAINS_PATH(@user, 'all', '$.name', '$.email');  -- 0（email 不存在）
```

---

### JSON_MERGE_PATCH 合并 JSON 对象

```sql
-- JSON_MERGE_PATCH（RFC 7396 语义）：用新对象覆盖同名字段
SELECT JSON_MERGE_PATCH(
    '{"name": "Alice", "age": 28, "city": "北京"}',
    '{"age": 29, "email": "alice@example.com"}'
);
-- 输出：{"age": 29, "city": "北京", "email": "alice@example.com", "name": "Alice"}
-- age 被更新，其他字段保留，email 新增

-- JSON_MERGE_PRESERVE（保留重复 key 的所有值，合并为数组）
SELECT JSON_MERGE_PRESERVE(
    '{"name": "Alice"}',
    '{"name": "Bob"}'
);
-- 输出：{"name": ["Alice", "Bob"]}
```

### 适用场景

- **动态构建返回值**：用 `JSON_OBJECT()` 在 SQL 层组装 API 返回的 JSON 数据
- **扩展属性查询**：按 JSON 对象内的特定字段过滤数据
- **版本历史记录**：存储实体在某个时间点的状态快照（JSON 对象）
- **配置管理**：应用配置以 JSON 对象形式存储，按 key 读取特定配置项

### 常见问题

**`->` 和 `->>` 有什么区别？**

`->` 等同于 `JSON_EXTRACT()`，返回的是 JSON 值（字符串类型带引号，如 `"Alice"`）；`->>` 等同于 `JSON_UNQUOTE(JSON_EXTRACT())`，返回不带引号的纯字符串值（如 `Alice`）。在 WHERE 条件中比较字符串值时，通常用 `->>`，否则需要手动用 JSON_UNQUOTE 去引号。

**JSON_OBJECT 中如果有重复的 key 会怎样？**

最后一个同名 key 的值会覆盖前面的。`JSON_OBJECT('a', 1, 'a', 2)` 结果是 `{"a": 2}`。

---

### 注意事项

- 在 WHERE 子句中用 `->>` 或 `JSON_EXTRACT` 过滤 JSON 字段时，如果没有虚拟列索引，会进行全表扫描，大表上性能差。高频查询的 JSON 字段应创建虚拟列并为其建索引。
- JSON 中的数值类型（整数、浮点）提取后是 JSON 数值类型，在 SQL 中比较时需要注意类型转换（用 CAST 或直接运算）。

---

### 总结

`JSON_OBJECT()` 用于动态创建 JSON 对象，`JSON_EXTRACT()` 或 `->` 操作符用于从 JSON 文档中提取特定字段，`->>` 在提取的同时去除字符串引号。`JSON_KEYS()` 获取对象的所有键，`JSON_CONTAINS_PATH()` 检查路径是否存在，`JSON_MERGE_PATCH()` 合并 JSON 对象。这些函数组合使用，能够在 SQL 层完成复杂的 JSON 对象操作。
