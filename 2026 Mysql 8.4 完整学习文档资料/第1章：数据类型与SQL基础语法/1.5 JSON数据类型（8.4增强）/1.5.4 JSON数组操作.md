## JSON 数组操作

JSON 数组（`[]`）是 JSON 文档中另一种核心结构，用于存储有序的元素列表。MySQL 提供了 `JSON_ARRAY()`、`JSON_ARRAYAGG()` 用于创建数组，以及专门用于数组搜索、提取、修改的系列函数。

---

### JSON_ARRAY 创建数组

```sql
JSON_ARRAY(val1, val2, val3, ...)
```

```sql
-- 创建简单数组
SELECT JSON_ARRAY(1, 2, 3, 4, 5);
-- 输出：[1, 2, 3, 4, 5]

SELECT JSON_ARRAY('apple', 'banana', 'cherry');
-- 输出：["apple", "banana", "cherry"]

-- 混合类型数组（JSON 允许混合类型）
SELECT JSON_ARRAY(1, 'hello', true, null, 3.14);
-- 输出：[1, "hello", true, null, 3.14]

-- 嵌套数组
SELECT JSON_ARRAY(JSON_ARRAY(1, 2), JSON_ARRAY(3, 4));
-- 输出：[[1, 2], [3, 4]]

-- 对象数组
SELECT JSON_ARRAY(
    JSON_OBJECT('id', 1, 'name', 'Alice'),
    JSON_OBJECT('id', 2, 'name', 'Bob')
);
-- 输出：[{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}]
```

---

### 访问数组元素

```sql
SET @arr = '["apple", "banana", "cherry", "date"]';

-- 按下标访问（从 0 开始）
SELECT JSON_EXTRACT(@arr, '$[0]');   -- "apple"
SELECT JSON_EXTRACT(@arr, '$[2]');   -- "cherry"
SELECT @arr -> '$[1]';               -- "banana"
SELECT @arr ->> '$[1]';              -- banana（无引号）

-- 负下标（从末尾算）
SELECT JSON_EXTRACT(@arr, '$[last]');    -- "date"（最后一个）
SELECT JSON_EXTRACT(@arr, '$[last-1]');  -- "cherry"（倒数第二）

-- 超出范围返回 NULL
SELECT JSON_EXTRACT(@arr, '$[10]');  -- NULL

-- 数组切片（范围提取）
SELECT JSON_EXTRACT(@arr, '$[1 to 2]');  -- ["banana", "cherry"]
SELECT JSON_EXTRACT(@arr, '$[1 to last]');  -- ["banana", "cherry", "date"]
```

---

### JSON_LENGTH 获取数组长度

```sql
SELECT JSON_LENGTH('["a", "b", "c"]');      -- 3
SELECT JSON_LENGTH('[1, [2, 3], 4]');        -- 3（只计顶层元素）
SELECT JSON_LENGTH('[1, [2, 3], 4]', '$[1]'); -- 2（嵌套数组的长度）

-- 用于表中的 JSON 列
CREATE TABLE tags_table (
    id   INT UNSIGNED NOT NULL AUTO_INCREMENT,
    tags JSON,
    PRIMARY KEY (id)
);
INSERT INTO tags_table (tags) VALUES ('["mysql", "database", "sql"]');
INSERT INTO tags_table (tags) VALUES ('["python", "api"]');

SELECT id, tags, JSON_LENGTH(tags) AS tag_count FROM tags_table;
-- id=1: tags=["mysql","database","sql"], tag_count=3
-- id=2: tags=["python","api"], tag_count=2
```

### JSON_SEARCH 在数组中搜索值

```sql
JSON_SEARCH(json_doc, one_or_all, search_str)
-- one_or_all: 'one' 返回第一个匹配路径，'all' 返回所有匹配路径
```

```sql
SET @fruits = '["apple", "banana", "cherry", "apple"]';

-- 搜索第一个匹配
SELECT JSON_SEARCH(@fruits, 'one', 'apple');   -- "$[0]"（第一个 apple 的路径）

-- 搜索所有匹配
SELECT JSON_SEARCH(@fruits, 'all', 'apple');   -- ["$[0]", "$[3]"]（两个 apple 的路径）

-- 搜索不存在的值
SELECT JSON_SEARCH(@fruits, 'one', 'grape');   -- NULL

-- 支持通配符
SET @data = '{"tags": ["mysql", "database", "backend"]}';
SELECT JSON_SEARCH(@data, 'all', 'my%');       -- "$.tags[0]"（前缀匹配 "mysql"）
```

---

### JSON_CONTAINS 检查数组是否包含值

```sql
JSON_CONTAINS(target, candidate [, path])
-- 检查 target 是否包含 candidate
```

```sql
SET @arr = '[1, 2, 3, 4, 5]';

SELECT JSON_CONTAINS(@arr, '3');            -- 1（包含数字 3）
SELECT JSON_CONTAINS(@arr, '6');            -- 0（不包含 6）

-- 检查字符串（注意字符串需要带引号）
SET @tags = '["mysql", "redis", "mongodb"]';
SELECT JSON_CONTAINS(@tags, '"mysql"');     -- 1（包含字符串 "mysql"）
SELECT JSON_CONTAINS(@tags, '"postgres"');  -- 0

-- 检查对象数组
SET @users = '[{"id": 1}, {"id": 2}, {"id": 3}]';
SELECT JSON_CONTAINS(@users, '{"id": 2}');  -- 1
```

### JSON_ARRAYAGG 聚合为数组

```sql
-- 将多行数据聚合为 JSON 数组（MySQL 8.0+）
CREATE TABLE user_interests (
    user_id     INT UNSIGNED NOT NULL,
    interest    VARCHAR(50) NOT NULL
);
INSERT INTO user_interests VALUES (1, 'music'), (1, 'sports'), (1, 'tech');
INSERT INTO user_interests VALUES (2, 'cooking'), (2, 'travel');

-- 按用户聚合兴趣列表
SELECT user_id, JSON_ARRAYAGG(interest) AS interests
FROM user_interests
GROUP BY user_id;
-- user_id=1: interests=["music", "sports", "tech"]
-- user_id=2: interests=["cooking", "travel"]
```

---

### 修改数组（JSON_ARRAY_APPEND / JSON_ARRAY_INSERT）

```sql
-- JSON_ARRAY_APPEND：在数组末尾追加元素
SET @arr = '[1, 2, 3]';
SELECT JSON_ARRAY_APPEND(@arr, '$', 4);     -- [1, 2, 3, 4]
SELECT JSON_ARRAY_APPEND(@arr, '$', 4, '$', 5);  -- [1, 2, 3, 4, 5]

-- JSON_ARRAY_INSERT：在指定位置插入元素
SELECT JSON_ARRAY_INSERT(@arr, '$[1]', 10);  -- [1, 10, 2, 3]（在下标1处插入）

-- 在表的 JSON 列上追加元素
UPDATE tags_table SET tags = JSON_ARRAY_APPEND(tags, '$', 'new_tag') WHERE id = 1;
```

### 适用场景

- **标签/分类列表**：文章标签、商品分类（多个值存为数组）
- **用户兴趣/权限列表**：多值属性存为 JSON 数组
- **历史记录快照**：操作历史以数组形式追加记录
- **多值聚合结果**：用 JSON_ARRAYAGG 将多行聚合成数组后返回

### 常见问题

**如何高效地查询 JSON 数组中包含某个特定值的行？**

对于高频查询，应该创建多值索引（Multi-Valued Index，MySQL 8.0.17+）：

```sql
CREATE TABLE articles (
    id   INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    tags JSON
);

-- 创建多值索引
ALTER TABLE articles ADD INDEX idx_tags ((CAST(tags AS CHAR(50) ARRAY)));

-- 使用 MEMBER OF 操作符（利用多值索引）
SELECT * FROM articles WHERE 'mysql' MEMBER OF (tags);
SELECT * FROM articles WHERE JSON_CONTAINS(tags, '"mysql"');
```

---

### 注意事项

- JSON 数组下标从 0 开始，`$[last]` 表示最后一个元素（MySQL 8.0.17+）。
- `JSON_ARRAYAGG()` 对 NULL 值会将其包含在结果数组中，如需过滤 NULL，在聚合前用 WHERE 或 HAVING 过滤。
- 对大型 JSON 数组频繁调用 `JSON_ARRAY_APPEND` 是低效的，因为每次都需要完整写入 JSON 列（无局部更新）。高频追加场景考虑改为独立行存储。

### 总结

MySQL 的 JSON 数组操作函数涵盖创建（JSON_ARRAY、JSON_ARRAYAGG）、访问（$[n]、$[last]）、搜索（JSON_SEARCH、JSON_CONTAINS）和修改（JSON_ARRAY_APPEND、JSON_ARRAY_INSERT）。`JSON_LENGTH()` 获取数组长度，`JSON_ARRAYAGG()` 将多行聚合为一个 JSON 数组。高频查询 JSON 数组成员时，Multi-Valued Index 配合 MEMBER OF 操作符可以显著提升性能。
