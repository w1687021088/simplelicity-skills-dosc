## JSON 路径表达式语法

JSON 路径表达式（Path Expression）是 MySQL JSON 函数中用于定位 JSON 文档内特定元素的语法。所有接受"路径"参数的 JSON 函数（JSON_EXTRACT、JSON_SET、JSON_REMOVE 等）都使用这套统一的路径语法。

---

### 路径表达式基本结构

路径表达式以 `$` 开头，代表当前 JSON 文档的根节点，然后通过操作符导航到子节点：

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `$` | 根节点 | `$` |
| `.key` | 对象的 key | `$.name` |
| `[n]` | 数组第 n 个元素（从 0 开始）| `$[0]` |
| `[last]` | 数组最后一个元素 | `$[last]` |
| `[last-n]` | 数组倒数第 n+1 个元素 | `$[last-1]` |
| `[m to n]` | 数组切片（m 到 n 的范围）| `$[1 to 3]` |
| `.*` | 对象所有 key 的值（通配符）| `$.*` |
| `[*]` | 数组所有元素（通配符）| `$[*]` |
| `**` | 递归通配符（任意层级）| `$**.name` |

---

### 基础路径操作

```sql
SET @doc = '{
    "user": {
        "name": "Alice",
        "age": 28,
        "address": {
            "city": "北京",
            "zip": "100000"
        }
    },
    "tags": ["mysql", "backend", "cloud"],
    "scores": [95, 87, 92]
}';

-- 根节点
SELECT JSON_EXTRACT(@doc, '$');               -- 整个文档

-- 对象字段
SELECT JSON_EXTRACT(@doc, '$.user.name');     -- "Alice"
SELECT JSON_EXTRACT(@doc, '$.user.age');      -- 28
SELECT JSON_EXTRACT(@doc, '$.user.address.city');  -- "北京"

-- 数组元素
SELECT JSON_EXTRACT(@doc, '$.tags[0]');       -- "mysql"
SELECT JSON_EXTRACT(@doc, '$.tags[last]');    -- "cloud"
SELECT JSON_EXTRACT(@doc, '$.scores[1]');     -- 87

-- 数组切片
SELECT JSON_EXTRACT(@doc, '$.tags[0 to 1]'); -- ["mysql", "backend"]
SELECT JSON_EXTRACT(@doc, '$.scores[1 to last]'); -- [87, 92]
```

### 通配符路径

```sql
SET @catalog = '{
    "books": {"title": "MySQL Guide", "price": 99},
    "videos": {"title": "SQL Tutorial", "price": 199},
    "courses": {"title": "DBA Masterclass", "price": 499}
}';

-- .* 获取对象所有 key 的值
SELECT JSON_EXTRACT(@catalog, '$.*');
-- 输出：[{"price": 99, "title": "MySQL Guide"}, {"price": 199, ...}, ...]

-- 提取所有 price 字段（结合 .* 和 .price）
SELECT JSON_EXTRACT(@catalog, '$.*.price');
-- 输出：[99, 199, 499]

-- [*] 获取数组所有元素
SET @users = '[{"name": "Alice"}, {"name": "Bob"}, {"name": "Carol"}]';
SELECT JSON_EXTRACT(@users, '$[*].name');
-- 输出：["Alice", "Bob", "Carol"]

-- ** 递归通配符（匹配任意层级）
SET @nested = '{"a": {"b": {"c": 1}}, "d": {"c": 2}}';
SELECT JSON_EXTRACT(@nested, '$**.c');
-- 输出：[1, 2]（找到所有层级的 c 字段）
```

### 在各类 JSON 函数中使用路径

```sql
-- JSON_SET：设置路径对应的值（存在则更新，不存在则新增）
SET @user = '{"name": "Alice", "age": 28}';
SELECT JSON_SET(@user, '$.age', 29, '$.email', 'alice@example.com');
-- 输出：{"age": 29, "email": "alice@example.com", "name": "Alice"}

-- JSON_INSERT：插入新值（只新增，不覆盖已有值）
SELECT JSON_INSERT(@user, '$.age', 99, '$.phone', '13800000000');
-- 输出：{"age": 28, "name": "Alice", "phone": "13800000000"}
-- age 已存在，不会被覆盖；phone 是新字段，被插入

-- JSON_REPLACE：替换已有值（只更新，不新增）
SELECT JSON_REPLACE(@user, '$.age', 30, '$.phone', '13900000000');
-- 输出：{"age": 30, "name": "Alice"}
-- age 被更新；phone 不存在，不会被新增

-- JSON_REMOVE：删除路径对应的值
SELECT JSON_REMOVE(@user, '$.age');
-- 输出：{"name": "Alice"}

-- 删除数组中的元素
SET @arr = '["a", "b", "c", "d"]';
SELECT JSON_REMOVE(@arr, '$[1]');  -- ["a", "c", "d"]（删除下标1的元素）
```

### 路径表达式中的特殊字符处理

如果 JSON 对象的 key 中包含特殊字符（空格、连字符、点号等），需要用双引号包裹 key 名：

```sql
SET @data = '{"first-name": "Alice", "last name": "Smith"}';

-- 包含连字符的 key
SELECT JSON_EXTRACT(@data, '$."first-name"');    -- "Alice"

-- 包含空格的 key
SELECT JSON_EXTRACT(@data, '$."last name"');     -- "Smith"
```

---

### 路径表达式与 -> 操作符

`->` 和 `->>` 操作符实际上是路径表达式的语法糖：

```sql
-- 等价写法
SELECT col -> '$.key'            FROM t;
SELECT JSON_EXTRACT(col, '$.key') FROM t;

SELECT col ->> '$.key'                      FROM t;
SELECT JSON_UNQUOTE(JSON_EXTRACT(col, '$.key')) FROM t;
```

### 适用场景

路径表达式贯穿所有 JSON 函数，理解路径语法是使用 MySQL JSON 功能的基础。以下操作都依赖路径表达式：
- 查询时提取特定字段
- UPDATE 时修改 JSON 文档中的指定字段
- 根据 JSON 字段内容做 WHERE 过滤
- 创建虚拟列时指定提取路径

---

### 常见问题

**路径表达式的 `$[last]` 是 MySQL 特有的吗？**

是的，`$[last]` 和 `$[last-n]` 是 MySQL 扩展语法，在 MySQL 8.0.17+ 中支持。标准 JSON Path 规范中没有 `last` 关键字。

**通配符 `.*` 和 `[*]` 的返回结果是什么类型？**

返回一个 JSON 数组，包含匹配到的所有值。如果没有匹配，返回 NULL。

---

### 注意事项

- 路径表达式区分大小写，`$.Name` 和 `$.name` 是不同的路径。
- 使用 `**` 递归通配符时，可能遍历整个 JSON 文档，对大型文档有性能影响。
- 路径中含特殊字符的 key 必须用双引号包裹，否则 MySQL 无法正确解析路径。

---

### 总结

JSON 路径表达式以 `$` 开头，通过 `.key`、`[n]`、`[last]`、`[m to n]`、`.*`、`[*]`、`**` 等操作符组合，精确定位 JSON 文档内的任意节点。所有 MySQL JSON 函数（JSON_EXTRACT、JSON_SET、JSON_INSERT、JSON_REPLACE、JSON_REMOVE 等）共用这套路径语法。掌握路径表达式是使用 MySQL JSON 功能的前提。
