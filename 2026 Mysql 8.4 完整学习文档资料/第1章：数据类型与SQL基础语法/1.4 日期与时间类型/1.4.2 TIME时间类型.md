## TIME 时间类型

TIME 是 MySQL 中专门存储时间值（时分秒）的类型，不包含日期信息。它的范围比直觉上大得多——从 -838:59:59 到 838:59:59，支持负值和超过 24 小时的时间，因为 TIME 也被设计用来表示"时间间隔"而不仅仅是"一天中的时刻"。

---

### 基本特性

| 属性 | 值 |
|------|---|
| 存储空间 | 3 字节（不含小数秒）|
| 时间范围 | -838:59:59 ~ 838:59:59 |
| 显示格式 | hh:mm:ss（或 hhh:mm:ss 对于超大小时数）|
| 小数秒 | 支持，TIME(fsp) 中 fsp=0~6 |
| 含小数秒的存储 | 额外 1~3 字节 |

---

### 语法

```sql
column_name TIME
column_name TIME(fsp)    -- fsp: fractional seconds precision (0~6)
column_name TIME NOT NULL DEFAULT '00:00:00'
```

### 创建示例

```sql
-- 营业时间
CREATE TABLE business_hours (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
    store_id    INT UNSIGNED NOT NULL,

    open_time   TIME NOT NULL COMMENT '开门时间',
    close_time  TIME NOT NULL COMMENT '关门时间',

-- 课程表
CREATE TABLE class_schedule (
    id          INT UNSIGNED NOT NULL AUTO_INCREMENT,
```

### TIME 的常用操作

```sql
-- 时间加减
SELECT ADDTIME('10:00:00', '01:30:00') AS result;    -- 11:30:00
SELECT SUBTIME('10:00:00', '01:30:00') AS result;    -- 08:30:00
SELECT TIMEDIFF('22:30:00', '09:00:00') AS work_duration;  -- 13:30:00

-- 提取时间部分
SELECT HOUR('14:30:45')   AS h;  -- 14
SELECT MINUTE('14:30:45') AS m;  -- 30
SELECT SECOND('14:30:45') AS s;  -- 45

-- 判断营业时间内
SELECT * FROM business_hours 
WHERE open_time <= '14:30:00' AND close_time >= '14:30:00';

-- 格式化输出
SELECT TIME_FORMAT(open_time, '%H:%i') AS formatted FROM business_hours;
-- 输出：09:00

-- 当前时间
SELECT CURTIME();        -- 返回 TIME 类型
SELECT CURTIME(3);       -- 精确到毫秒

-- 计算两个时间之间的秒数差
SELECT TIME_TO_SEC('01:30:00') AS seconds;  -- 5400
SELECT SEC_TO_TIME(5400) AS time_val;       -- 01:30:00
```

### TIME 与 DATETIME 中的时间部分

TIME 可以独立使用，也可以从 DATETIME/TIMESTAMP 提取时间部分：

```sql
-- 从 DATETIME 提取时间
SELECT TIME(NOW()) AS current_time_only;

-- 按时间段分组统计
SELECT HOUR(created_at) AS hour_of_day, COUNT(*) AS orders
FROM orders
WHERE created_at >= '2026-03-14 00:00:00' AND created_at < '2026-03-15 00:00:00'
GROUP BY HOUR(created_at)
ORDER BY hour_of_day;
```

### 适用场景

- **营业时间/工作时间**：记录每天的开始和结束时间
- **课程表/排班表**：上下课时间、班次时间
- **比赛成绩**：运动比赛的完成时间（可能超过 24 小时，如超马）
- **时间间隔记录**：工时统计、操作耗时记录（TIME 支持负值和超过 24 小时）

### 常见问题

**TIME 和只用 DATETIME 的时间部分有什么区别？**

TIME 类型独立存储时间，与日期无关，且支持超过 24 小时的值和负值，适合存储时间间隔。DATETIME 存储完整的日期时间，其时间部分只有 0:00:00 到 23:59:59。

**TIME 支持小数秒吗？**

支持，使用 `TIME(fsp)` 指定精度（0~6），如 `TIME(3)` 支持毫秒精度。额外的精度需要额外存储空间（fsp 1~2 需 1 字节，fsp 3~4 需 2 字节，fsp 5~6 需 3 字节）。

---

### 注意事项

- 存入超出 -838:59:59 到 838:59:59 范围的值在严格模式下报错，非严格模式下会截断到边界值并警告。
- 两位数的小时值（如 `'14:30'`）会被解析为 `14:30:00`；四位数（如 `'1430'`）也会被解析为 `14:30:00`。
- TIME 类型不含时区信息，不受 MySQL 时区设置影响。

---

###  总结

TIME 类型存储时分秒，范围 -838:59:59 到 838:59:59，支持超过 24 小时的值和负值，适合时间间隔场景。支持小数秒精度（TIME(fsp)）。适用于营业时间、课程表、比赛成绩等只需要时间不需要日期的场景。常用函数包括 ADDTIME、TIMEDIFF、TIME_TO_SEC、TIME_FORMAT 等。
