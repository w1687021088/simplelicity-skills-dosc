# INSERT 基础语法

`INSERT` 是 MySQL 中向表中插入数据的 DML 语句，支持插入单行、多行，以及通过 SELECT 子查询批量插入。正确使用 INSERT 的各种变体可以显著提升数据写入的效率和可靠性。

---

## 语法

```sql
-- 单行插入（指定列名）
INSERT INTO tbl_name (col1, col2, ...) VALUES (val1, val2, ...);

-- 单行插入（省略列名，必须提供所有列的值）
INSERT INTO tbl_name VALUES (val1, val2, ...);

-- 多行插入
INSERT INTO tbl_name (col1, col2) VALUES
    (val1a, val2a),
    (val1b, val2b),
    (val1c, val2c);

-- SET 语法（仅单行，类似 UPDATE 的写法）
INSERT INTO tbl_name SET col1 = val1, col2 = val2;
```

---

## 基本示例

```sql
-- 标准建表
CREATE TABLE users (
    id         INT UNSIGNED NOT NULL AUTO_INCREMENT,
    username   VARCHAR(50) NOT NULL,
    email      VARCHAR(200) NOT NULL,
    score      INT UNSIGNED NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (id),
    UNIQUE KEY uk_email (email)
);

-- 指定列名插入（推荐，即使表结构变动也不影响 INSERT 语句）
INSERT INTO users (username, email) VALUES ('alice', 'alice@example.com');

-- 多行插入（比逐条插入效率高很多）
INSERT INTO users (username, email, score) VALUES
    ('bob',   'bob@example.com',   100),
    ('carol', 'carol@example.com', 200),
    ('dave',  'dave@example.com',  150);

-- SET 语法
INSERT INTO users SET username = 'eve', email = 'eve@example.com', score = 80;

-- 省略列名（不推荐，表结构变动会导致错误）
INSERT INTO users VALUES (NULL, 'frank', 'frank@example.com', 50, NOW());
-- AUTO_INCREMENT 列传 NULL 即可，MySQL 自动生成
```

## INSERT 的返回信息

```sql
-- 执行 INSERT 后可以获取以下信息：
-- 1. 影响的行数（affected rows）
-- 2. 最后一条 AUTO_INCREMENT 的值（LAST_INSERT_ID()）

INSERT INTO users (username, email) VALUES ('grace', 'grace@example.com');
SELECT LAST_INSERT_ID();  -- 返回刚插入行的 AUTO_INCREMENT 值

-- 批量插入时，LAST_INSERT_ID() 返回第一条插入行的 ID
INSERT INTO users (username, email) VALUES
    ('henry', 'henry@example.com'),
    ('iris',  'iris@example.com');
SELECT LAST_INSERT_ID();  -- 返回 henry 这行的 id（第一行的 id）
```

## 插入时处理 DEFAULT 和 NULL

```sql
-- 有 DEFAULT 的列可以显式使用 DEFAULT 关键字
INSERT INTO users (username, email, score) VALUES ('jack', 'jack@example.com', DEFAULT);
-- score 使用默认值 0

-- 也可以不提供该列（等同于使用 DEFAULT）
INSERT INTO users (username, email) VALUES ('kate', 'kate@example.com');
-- score 自动为 0

-- NULL 值的插入（列必须允许 NULL）
INSERT INTO articles (title, content) VALUES ('测试文章', NULL);
```

## 多行插入的性能

```sql
-- 多行 VALUES 一次提交 vs 逐条 INSERT 的性能对比
-- 逐条插入（效率低，每条 SQL 有解析开销，每条有网络往返）
INSERT INTO logs (message) VALUES ('a');
INSERT INTO logs (message) VALUES ('b');
INSERT INTO logs (message) VALUES ('c');

-- 批量多行插入（推荐，解析一次，一次网络往返）
INSERT INTO logs (message) VALUES ('a'), ('b'), ('c');

-- 大批量插入建议每次 500~1000 行分批执行
-- 避免单次 INSERT 生成过大的 undo log，影响其他事务

-- 使用事务包裹多次 INSERT（大幅提升写入速度）
START TRANSACTION;
INSERT INTO logs (message) VALUES ('batch1_a'), ('batch1_b');
INSERT INTO logs (message) VALUES ('batch2_a'), ('batch2_b');
COMMIT;
-- 事务内多个 INSERT 只提交一次，速度比每条自动提交快很多
```

- 数据迁移（从其他表批量写入）

## 常见问题

**不指定列名的 INSERT 有什么风险？**

如果表结构发生变化（添加/删除/移动列），不指定列名的 INSERT 会因为列数量或顺序不匹配而报错或插入错误的数据。始终推荐显式指定列名，使 INSERT 语句与表结构变化解耦。

**多行 INSERT 中有一行失败时，其他行会成功吗？**

默认不会，事务内的多行 INSERT 是全有或全无——有一行违反约束则整个语句回滚。使用 `INSERT IGNORE` 可以跳过错误行，使其他行正常插入。

---

## 注意事项

- AUTO_INCREMENT 列的值不能在回滚后"退还"。即使事务回滚，被分配出去的自增值也不会重用，这意味着自增 ID 可能不连续，这是正常行为。
- 超大规模的批量写入（如单表每次几万行），应分批处理并配合事务，避免单个大事务持有过多 undo log 影响其他业务。

---

## 总结

INSERT 语句支持单行、多行和 SET 语法，强烈推荐显式指定列名以提高代码健壮性。多行 VALUES 一次提交比逐条插入效率高得多。LAST_INSERT_ID() 可以获取最后一次 AUTO_INCREMENT 生成的 ID。大批量写入应分批并配合事务提交，以兼顾性能和系统稳定性。
