# SELECT ... INTO OUTFILE 导出

`SELECT ... INTO OUTFILE` 将查询结果直接写入服务器端的文本文件，是与 `LOAD DATA INFILE` 对应的数据导出方式。它可以高效地将大量查询结果输出为 CSV 或 TSV 格式，用于数据备份、数据交换、报表导出等场景。

---

## 语法

```sql
SELECT col1, col2, ...
INTO OUTFILE 'file_path'
    [FIELDS
        [TERMINATED BY 'str']
        [[OPTIONALLY] ENCLOSED BY 'char']
        [ESCAPED BY 'char']
    ]
    [LINES
        [STARTING BY 'str']
        [TERMINATED BY 'str']
    ]
FROM tbl_name
[WHERE ...]
[ORDER BY ...]
[LIMIT n];
```

输出文件写在 **MySQL 服务器**上，文件路径受 `secure_file_priv` 变量限制。

---

## 基本示例

```sql
-- 导出为 CSV 文件（写到服务器的 /var/lib/mysql-files/ 目录）
SELECT id, username, email, score, created_at
INTO OUTFILE '/var/lib/mysql-files/users_export.csv'
FIELDS TERMINATED BY ',' ENCLOSED BY '"'
LINES TERMINATED BY '\n'
FROM users WHERE status = 'active';

-- 生成的文件内容：
-- "1","alice","alice@example.com","100","2026-01-15 10:30:00"
-- "2","bob","bob@example.com","200","2026-01-16 11:45:00"

-- 导出为 TSV 文件（Tab 分隔，Excel 友好）
SELECT id, product_name, price, stock
INTO OUTFILE '/var/lib/mysql-files/products.tsv'
FIELDS TERMINATED BY '\t'
LINES TERMINATED BY '\r\n'   -- Windows 换行符
FROM products;

-- 带表头行（通过 UNION ALL 添加表头）
SELECT 'id', 'username', 'email', 'score'  -- 表头行
UNION ALL
SELECT id, username, email, score FROM users
INTO OUTFILE '/var/lib/mysql-files/users_with_header.csv'
FIELDS TERMINATED BY ',' ENCLOSED BY '"'
LINES TERMINATED BY '\n';
```

## 检查文件路径权限

```sql
-- 查看允许写入的路径
SHOW VARIABLES LIKE 'secure_file_priv';
-- 示例输出：/var/lib/mysql-files/

-- 如果 secure_file_priv 为 NULL，则完全禁止文件操作
-- 在 my.cnf 中配置：
-- [mysqld]
-- secure_file_priv = /var/lib/mysql-files

-- 目标文件不能已存在，否则报错（MySQL 不会覆盖已有文件）
-- ERROR 1086 (HY000): File '/var/lib/mysql-files/test.csv' already exists
```

## 导出到客户端（使用 mysql 命令行工具）

MySQL 8.0 不允许 `SELECT INTO OUTFILE` 写到客户端本地（只写服务器端）。如果需要导出到客户端，可以使用 mysql 命令行工具的输出重定向：

```bash
# 导出到客户端（通过 mysql 命令行）
mysql -u root -p -e "SELECT id,username,email FROM users" mydb > users_export.csv

# 生成 CSV 格式（--batch 选项输出 TAB 分隔）
mysql -u root -p --batch --silent mydb -e "SELECT id,username,email FROM users" > users.tsv
```

## 适用场景

- **数据导出备份**：将重要业务表导出为 CSV，存档或传输给其他系统
- **数据迁移**：与 LOAD DATA INFILE 配合，在不同 MySQL 实例间迁移数据
- **报表生成**：将 SQL 查询结果直接输出为可供 Excel 打开的 CSV 文件
- **数据审计**：将审计记录导出为文本文件存档

## 常见问题

**目标文件已经存在时怎么办？**

MySQL 不会覆盖已有文件，必须先手动删除或改用其他文件名。可以在文件名中加入时间戳来保证唯一性：

```sql
-- 通过动态构造文件名（在存储过程中使用）
SET @filename = CONCAT('/var/lib/mysql-files/export_', DATE_FORMAT(NOW(), '%Y%m%d_%H%i%S'), '.csv');
SET @sql = CONCAT("SELECT * FROM users INTO OUTFILE '", @filename, "' FIELDS TERMINATED BY ','");
PREPARE stmt FROM @sql;
EXECUTE stmt;
DEALLOCATE PREPARE stmt;
```

---

## 注意事项

- `SELECT INTO OUTFILE` 写入的文件在 MySQL 服务器上，MySQL 进程用户（通常是 `mysql`）需要有对目标目录的写权限。
- 导出的文件内容没有表头（列名），如需列名，用 UNION ALL 手动添加一行字符串作为表头。
- 导出 NULL 值时，默认输出为 `\N`（MySQL 的 NULL 文本表示），LOAD DATA INFILE 也会将 `\N` 识别为 NULL。

---

## 总结

`SELECT ... INTO OUTFILE` 将查询结果写入服务器端的文本文件，是 `LOAD DATA INFILE` 的逆操作。支持自定义字段分隔符（CSV/TSV）和行结束符，适合大量数据的导出和跨系统数据交换。输出受 `secure_file_priv` 路径限制，且目标文件必须不存在。需要表头时通过 `UNION ALL` 手动添加。
