# validate_password 组件安装

`validate_password` 是 MySQL 提供的密码验证组件，用于在设置账户密码时强制执行复杂度要求。MySQL 8.0 将其从插件（plugin）升级为组件（component），两者功能相近但在管理方式上有所不同。安装后，所有 `CREATE USER` 和 `ALTER USER` 的密码设置都会自动经过策略检查。

---

## 组件与插件的区别

```sql
-- MySQL 8.0 之前（5.x, 8.0 早期）：validate_password 作为插件存在
INSTALL PLUGIN validate_password SONAME 'validate_password.so';

-- MySQL 8.0+：推荐使用组件形式
INSTALL COMPONENT 'file://component_validate_password';

-- 两者的区别：
-- 插件（plugin）：通过 INSTALL PLUGIN 安装，需要 .so/.dll 文件
-- 组件（component）：通过 INSTALL COMPONENT 安装，更现代化的架构
-- 不能同时安装两者（会冲突）
```

---

## 安装 validate_password 组件

```sql
-- 检查是否已安装
SELECT * FROM mysql.component WHERE component_urn LIKE '%validate_password%';

-- 如果没有安装，执行安装
INSTALL COMPONENT 'file://component_validate_password';

-- 验证安装成功
SELECT * FROM mysql.component WHERE component_urn = 'file://component_validate_password';
-- component_id | component_group_id | component_urn
-- 1            | 1                  | file://component_validate_password

-- 查看组件相关的系统变量
SHOW VARIABLES LIKE 'validate_password%';
```

## 策略级别（validate_password.policy）

| 级别 | 值 | 检查内容 |
|------|---|---------|
| LOW | 0 | 只检查密码长度 |
| MEDIUM | 1（默认）| 长度 + 大小写 + 数字 + 特殊字符 |
| STRONG | 2 | MEDIUM 的全部 + 字典文件检查（禁止字典词汇）|

```sql
-- 设置策略级别
SET GLOBAL validate_password.policy = LOW;     -- 只检查长度
SET GLOBAL validate_password.policy = MEDIUM;  -- 默认，检查复杂度
SET GLOBAL validate_password.policy = STRONG;  -- 最严格

-- 设置最小长度
SET GLOBAL validate_password.length = 12;

-- 要求至少2个特殊字符
SET GLOBAL validate_password.special_char_count = 2;

-- 要求至少2个大写字母
SET GLOBAL validate_password.mixed_case_count = 2;
```

## 持久化配置

```sql
-- 修改 my.cnf，使配置在重启后保持生效

-- [mysqld]
-- validate_password.policy=MEDIUM
-- validate_password.length=12
-- validate_password.mixed_case_count=1
-- validate_password.number_count=1
-- validate_password.special_char_count=1
-- validate_password.check_user_name=ON

-- 或使用 SET PERSIST（8.0+ 自动写入配置文件）
SET PERSIST validate_password.policy = 'MEDIUM';
SET PERSIST validate_password.length = 12;
SET PERSIST validate_password.special_char_count = 1;
```

## 测试密码强度

```sql
-- 安装组件后，可以用 VALIDATE_PASSWORD_STRENGTH() 函数测试密码强度
SELECT VALIDATE_PASSWORD_STRENGTH('password');     -- 强度分：0-25（弱）
SELECT VALIDATE_PASSWORD_STRENGTH('Password1!');   -- 强度分：50-75（中等）
SELECT VALIDATE_PASSWORD_STRENGTH('P@ssw0rd!2#'); -- 强度分：100（强）
-- 返回 0-100 的评分，100 最强，分数低于当前策略要求时密码会被拒绝
```

## 卸载组件

```sql
-- 如果不再需要密码复杂度检查（不推荐在生产环境卸载）
UNINSTALL COMPONENT 'file://component_validate_password';

-- 卸载后，validate_password.* 变量消失，不再进行密码强度检查
```

## 适用场景

- **企业安全合规**：满足密码安全标准（如等保 2.0 要求密码不少于 8 位且含大小写数字特殊字符）
- **防弱密码**：防止用户设置 "123456"、"password" 等弱密码
- **密码字典检查**：配合字典文件，禁止常见密码词汇（STRONG 级别）

## 常见问题

**安装了 validate_password 后，root 账户修改密码时报策略不满足怎么办？**

可以临时降低策略（设置 LOW 级别或减小最小长度），修改完密码后再恢复原策略。或者直接设置一个符合策略的强密码。注意不能先卸载组件再修改密码（这会绕过安全控制），应在策略允许的范围内操作。

---

## 注意事项

- 组件形式（`component_validate_password`）和插件形式（`validate_password`）的变量名格式略有不同：组件用 `validate_password.length`（点分隔），插件用 `validate_password_length`（下划线分隔）。安装时注意区分。
- `validate_password` 只对明文密码设置（`IDENTIFIED BY 'password'`）生效，对直接使用哈希值设置（`IDENTIFIED WITH ... AS 'hash'`）不做检查。

---

## 总结

`INSTALL COMPONENT 'file://component_validate_password'` 安装密码验证组件，安装后所有密码设置自动经过复杂度检查。通过 `validate_password.policy`（LOW/MEDIUM/STRONG）、`validate_password.length`、`validate_password.mixed_case_count` 等变量控制策略。`VALIDATE_PASSWORD_STRENGTH()` 函数可以测试密码强度评分。生产环境推荐使用 MEDIUM 或 STRONG 策略，并通过 `SET PERSIST` 持久化配置。
