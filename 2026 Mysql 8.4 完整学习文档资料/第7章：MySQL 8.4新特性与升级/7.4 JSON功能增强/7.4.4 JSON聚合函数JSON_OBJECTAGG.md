# JSON 聚合函数 JSON_OBJECTAGG

`JSON_OBJECTAGG()` 是 MySQL 8.0 引入的聚合函数，用于将多行数据的键值对聚合为一个 JSON 对象。与 `JSON_ARRAYAGG()`（聚合为数组）不同，`JSON_OBJECTAGG()` 接受两个参数——键（key）和值（value），将每行的键值对组合为一个 JSON 对象。这在将关系型数据转换为键值对格式的 JSON 数据时非常有用，例如将配置表、属性表的数据聚合为一个 JSON 对象。

---

## 基本语法

```sql
-- JSON_OBJECTAGG(key_expr, value_expr)
-- key_expr：作为 JSON 对象键的表达式（必须是字符串类型）
-- value_expr：作为 JSON 对象值的表达式（可以是任意类型）

-- 基本示例：
-- 假设有一个配置表 app_config
-- config_key  | config_value
-- app_name    | MyApp
-- version     | 2.0
-- debug_mode  | true

SELECT JSON_OBJECTAGG(config_key, config_value) AS config
FROM app_config;
-- config: {"app_name": "MyApp", "version": "2.0", "debug_mode": "true"}
```

---

## 配合 GROUP BY 使用

```sql
-- 按类别分组，将每个类别的属性聚合为 JSON 对象
-- 假设表 product_attrs:
-- product_id | attr_name | attr_value
-- 1          | color     | red
-- 1          | size      | L
-- 1          | weight    | 200g
-- 2          | color     | blue
-- 2          | size      | M

SELECT product_id,
       JSON_OBJECTAGG(attr_name, attr_value) AS attributes
FROM product_attrs
GROUP BY product_id;

-- product_id | attributes
-- 1          | {"color": "red", "size": "L", "weight": "200g"}
-- 2          | {"color": "blue", "size": "M"}

-- 配合 JSON_PRETTY 格式化输出：
SELECT product_id,
       JSON_PRETTY(JSON_OBJECTAGG(attr_name, attr_value)) AS attributes
FROM product_attrs
GROUP BY product_id;
```

## 值为复杂类型的聚合

```sql
-- 值可以是数字、布尔值、JSON 对象等
SELECT JSON_OBJECTAGG(
    name,
    JSON_OBJECT('salary', salary, 'department', department)
) AS employee_details
FROM employees
WHERE department = 'IT';

-- 结果：
-- {
--   "张三": {"salary": 15000, "department": "IT"},
--   "李四": {"salary": 18000, "department": "IT"}
-- }

-- 值为聚合结果的嵌套用法（通过子查询）：
SELECT JSON_OBJECTAGG(department, member_count) AS dept_stats
FROM (
    SELECT department, COUNT(*) AS member_count
    FROM employees
    GROUP BY department
) AS sub;

-- dept_stats: {"IT": 5, "HR": 3, "Finance": 4}
```

## 重复键的处理

```sql
-- 当多行具有相同的 key 值时，JSON_OBJECTAGG 的行为：
-- 后面的值会覆盖前面的值（保留最后一个）

-- 示例：
-- name  | score
-- 张三  | 80
-- 张三  | 90（重复键）
-- 李四  | 85

SELECT JSON_OBJECTAGG(name, score) AS scores;
-- 结果可能是：{"张三": 90, "李四": 85}
-- 也可能是：{"张三": 80, "李四": 85}
-- 因为聚合函数不保证行的处理顺序

-- 如果需要确定性结果（如取最高分），应先在子查询中处理：
SELECT JSON_OBJECTAGG(name, max_score) AS scores
FROM (
    SELECT name, MAX(score) AS max_score
    FROM exam_results
    GROUP BY name
) AS sub;
-- {"张三": 90, "李四": 85}
```

## JSON_OBJECTAGG vs JSON_ARRAYAGG

| 对比维度 | JSON_OBJECTAGG | JSON_ARRAYAGG |
|---------|:-------------:|:------------:|
| 参数个数 | 2 个（key, value）| 1 个（value）|
| 返回格式 | JSON 对象 `{...}` | JSON 数组 `[...]` |
| 键的要求 | 必须是字符串 | 无键 |
| 重复键 | 后值覆盖前值 | 允许重复元素 |
| 无数据时 | 返回 NULL | 返回 NULL |
| 典型用途 | 属性表→对象 | 列值→数组 |

## 实际应用示例

```sql
-- 将用户设置表转为 JSON 对象存储
-- 场景：用户个性化设置存储在 EAV（Entity-Attribute-Value）表中

-- user_settings 表：
-- user_id | setting_key     | setting_value
-- 1       | theme           | dark
-- 1       | language        | zh-CN
-- 1       | notifications   | true
-- 2       | theme           | light
-- 2       | language        | en-US

SELECT user_id,
       JSON_OBJECTAGG(setting_key, setting_value) AS settings
FROM user_settings
GROUP BY user_id;

-- user_id | settings
-- 1       | {"theme": "dark", "language": "zh-CN", "notifications": "true"}
-- 2       | {"theme": "light", "language": "en-US"}

-- 将 EAV 表数据合并更新到用户表的 JSON 列：
UPDATE users u
JOIN (
    SELECT user_id, JSON_OBJECTAGG(setting_key, setting_value) AS settings
    FROM user_settings
    GROUP BY user_id
) s ON u.id = s.user_id
SET u.preferences = s.settings;
```

## 适用场景

- **EAV（实体-属性-值）表数据的 JSON 化**：将分散在多行中的属性键值对聚合为一个 JSON 对象，便于应用层直接使用，无需多次查询或在应用层拼装
- **动态报表数据的透视转换**：将行数据转换为列结构（类似 PIVOT），以 JSON 对象的形式返回，适合列名不固定的动态报表场景

## 常见问题

**JSON_OBJECTAGG 的 key 必须是字符串类型吗？如果传入数字会怎样？**

JSON 标准要求对象的键必须是字符串。如果传入数字类型的 key（如 INT 列），MySQL 会自动将其转换为字符串。例如 `JSON_OBJECTAGG(id, name)` 中 id 是 INT 类型，结果会是 `{"1": "张三", "2": "李四"}`（键是字符串 "1"、"2"，不是数字 1、2）。如果 key 为 NULL，MySQL 会报错 `JSON documents may not contain NULL member names`，因此需要确保 key 列没有 NULL 值。

---

## 注意事项

- `JSON_OBJECTAGG` 在没有匹配行时返回 NULL。如果需要返回空对象 `{}`，可以使用 `COALESCE(JSON_OBJECTAGG(k, v), CAST('{}' AS JSON))` 或 `IFNULL(JSON_OBJECTAGG(k, v), JSON_OBJECT())`。
- key 列包含 NULL 值时会导致运行时错误。在使用前应确保 key 列不为 NULL，或在查询中过滤掉 NULL 键：`SELECT JSON_OBJECTAGG(k, v) FROM t WHERE k IS NOT NULL`。

---

## 总结

`JSON_OBJECTAGG(key, value)` 将多行键值对聚合为 JSON 对象。key 必须是字符串（数字自动转换，NULL 会报错），value 可以是任意类型。配合 `GROUP BY` 按分组生成对象。重复键的值会被覆盖（保留最后一个，顺序不确定）。无匹配行返回 NULL（用 `COALESCE` 处理为空对象 `{}`）。典型用途：EAV 表数据 JSON 化、配置表聚合、动态透视查询。可嵌套 `JSON_OBJECT()` 生成嵌套结构。
