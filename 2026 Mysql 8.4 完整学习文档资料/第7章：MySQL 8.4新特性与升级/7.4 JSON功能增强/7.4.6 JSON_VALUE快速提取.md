# JSON_VALUE 快速提取

`JSON_VALUE()` 是 MySQL 8.0.21 引入的函数，用于从 JSON 文档中提取标量值（字符串、数字、布尔值），并直接返回指定的 SQL 数据类型。它是 `JSON_EXTRACT()` + `JSON_UNQUOTE()` + `CAST()` 的简化替代，语法更简洁，并且可以直接用于创建函数索引（Functional Index），为 JSON 列上的查询提供索引加速。

---

## 基本语法

```sql
-- JSON_VALUE(json_doc, path [RETURNING type] [on_empty] [on_error])
-- json_doc：JSON 文档
-- path：JSON 路径表达式
-- RETURNING type：返回的 SQL 数据类型（可选，默认 VARCHAR(512)）
-- on_empty：路径不存在时的行为（可选）
-- on_error：类型转换错误时的行为（可选）

-- 基本用法：
SELECT JSON_VALUE('{"name": "张三", "age": 25}', '$.name');
-- 张三（返回类型：VARCHAR(512)）

SELECT JSON_VALUE('{"name": "张三", "age": 25}', '$.age');
-- 25（返回类型：VARCHAR(512)，实际是字符串 "25"）

-- 指定返回类型：
SELECT JSON_VALUE('{"name": "张三", "age": 25}', '$.age' RETURNING UNSIGNED);
-- 25（返回类型：UNSIGNED INT）

SELECT JSON_VALUE('{"price": 99.50}', '$.price' RETURNING DECIMAL(10,2));
-- 99.50（返回类型：DECIMAL(10,2)）

SELECT JSON_VALUE('{"created": "2024-01-15"}', '$.created' RETURNING DATE);
-- 2024-01-15（返回类型：DATE）
```

---

## RETURNING 支持的类型

```sql
-- JSON_VALUE 的 RETURNING 子句支持以下 SQL 数据类型：

-- 整数类型：
JSON_VALUE(j, '$.id' RETURNING SIGNED)
JSON_VALUE(j, '$.id' RETURNING UNSIGNED)

-- 浮点/定点数类型：
JSON_VALUE(j, '$.price' RETURNING FLOAT)
JSON_VALUE(j, '$.price' RETURNING DOUBLE)
JSON_VALUE(j, '$.price' RETURNING DECIMAL(10,2))

-- 字符串类型：
JSON_VALUE(j, '$.name' RETURNING CHAR(50))
JSON_VALUE(j, '$.name' RETURNING VARCHAR(100))

-- 日期/时间类型：
JSON_VALUE(j, '$.date' RETURNING DATE)
JSON_VALUE(j, '$.time' RETURNING TIME)
JSON_VALUE(j, '$.dt' RETURNING DATETIME)

-- JSON 类型：
JSON_VALUE(j, '$.nested' RETURNING JSON)
-- 当提取的值本身是 JSON 对象或数组时使用
```

## 错误处理

```sql
-- ON EMPTY：路径不存在时的行为
-- ON ERROR：类型转换失败时的行为

-- 可选值：
-- NULL ON EMPTY / NULL ON ERROR（默认）
-- DEFAULT value ON EMPTY / DEFAULT value ON ERROR
-- ERROR ON EMPTY / ERROR ON ERROR

-- 示例：
SELECT JSON_VALUE('{"name": "张三"}', '$.age' 
    RETURNING UNSIGNED 
    DEFAULT 0 ON EMPTY
);
-- 0（age 路径不存在，返回默认值 0）

SELECT JSON_VALUE('{"age": "abc"}', '$.age' 
    RETURNING UNSIGNED 
    DEFAULT -1 ON ERROR
);
-- -1（"abc" 无法转为 UNSIGNED，返回错误默认值 -1）

-- 抛出错误（严格模式）：
SELECT JSON_VALUE('{"name": "张三"}', '$.age' 
    RETURNING UNSIGNED 
    ERROR ON EMPTY
);
-- ERROR: Missing value for JSON_VALUE
```

## 创建函数索引

```sql
-- JSON_VALUE 最重要的应用之一：为 JSON 列创建函数索引

CREATE TABLE products (
    id INT AUTO_INCREMENT PRIMARY KEY,
    data JSON NOT NULL
);

-- 在 JSON 字段的 $.sku 路径上创建索引：
CREATE INDEX idx_sku ON products (
    (JSON_VALUE(data, '$.sku' RETURNING CHAR(20)))
);

-- 在 JSON 字段的 $.price 路径上创建索引：
CREATE INDEX idx_price ON products (
    (JSON_VALUE(data, '$.price' RETURNING DECIMAL(10,2)))
);

-- 使用索引的查询（优化器会自动匹配）：
SELECT * FROM products
WHERE JSON_VALUE(data, '$.sku' RETURNING CHAR(20)) = 'SKU-12345';
-- 走 idx_sku 索引

SELECT * FROM products
WHERE JSON_VALUE(data, '$.price' RETURNING DECIMAL(10,2)) BETWEEN 100 AND 500;
-- 走 idx_price 索引

-- 验证索引使用情况：
EXPLAIN SELECT * FROM products
WHERE JSON_VALUE(data, '$.sku' RETURNING CHAR(20)) = 'SKU-12345';
-- type: ref, key: idx_sku
```

## JSON_VALUE vs JSON_EXTRACT vs ->>/->

```sql
-- 三种提取方式的对比：
SET @j = '{"name": "张三", "age": 25}';

-- JSON_EXTRACT：返回 JSON 类型
SELECT JSON_EXTRACT(@j, '$.name');    -- "张三"（带引号，JSON 字符串）
SELECT JSON_EXTRACT(@j, '$.age');     -- 25（JSON 数字）

-- ->> 操作符（JSON_UNQUOTE + JSON_EXTRACT）：返回文本
SELECT @j->>'$.name';                 -- 张三（无引号，SQL 字符串）
SELECT @j->>'$.age';                  -- 25（SQL 字符串）

-- JSON_VALUE：返回指定 SQL 类型
SELECT JSON_VALUE(@j, '$.name');                         -- 张三（VARCHAR）
SELECT JSON_VALUE(@j, '$.age' RETURNING UNSIGNED);       -- 25（UNSIGNED INT）
```

| 对比维度 | JSON_EXTRACT / -> | ->> | JSON_VALUE |
|---------|:-----------------:|:---:|:----------:|
| 返回类型 | JSON | TEXT | 指定 SQL 类型 |
| 字符串引号 | 带引号 | 无引号 | 无引号 |
| 类型转换 | 不转换 | 仅转文本 | 支持 RETURNING |
| 函数索引 | 可用（需 CAST）| 可用 | 可用（推荐）|
| 错误处理 | 无 | 无 | ON EMPTY/ON ERROR |
| 引入版本 | 5.7 | 5.7.13 | 8.0.21 |

## 适用场景

- **JSON 列的函数索引创建**：`JSON_VALUE` 与 `RETURNING` 子句的组合，是在 JSON 列上创建函数索引最直观和推荐的方式。相比使用 `CAST(json_col->>'$.path' AS type)`，语法更简洁
- **需要类型安全的 JSON 值提取**：当业务逻辑需要确保提取的值是特定类型（如 DECIMAL 用于金额计算、DATE 用于日期比较）时，`JSON_VALUE` 的 `RETURNING` 子句提供了内置的类型转换和错误处理

---

## 常见问题

**JSON_VALUE 能提取 JSON 对象或数组吗？**

默认情况下 `JSON_VALUE` 只提取标量值（字符串、数字、布尔值、null）。如果路径指向一个 JSON 对象或数组，默认会触发 ON ERROR 行为（默认返回 NULL）。如果需要提取对象或数组，可以指定 `RETURNING JSON`：`JSON_VALUE(data, '$.address' RETURNING JSON)`，此时返回的是 JSON 类型的对象或数组。不过这种情况通常直接使用 `JSON_EXTRACT` 更自然。

---

## 注意事项

- 创建函数索引时，`JSON_VALUE` 表达式必须用双层括号包裹：`CREATE INDEX idx ON t ((JSON_VALUE(j, '$.path' RETURNING type)))`。外层括号是 MySQL 函数索引的语法要求，内层括号是函数调用本身。
- `JSON_VALUE` 的默认返回类型是 `VARCHAR(512)`。如果不指定 `RETURNING`，在创建函数索引时索引列类型就是 `VARCHAR(512)`，可能浪费索引空间。建议在创建索引时始终指定 `RETURNING` 为最合适的类型和长度。

---

## 总结

`JSON_VALUE(json_doc, path [RETURNING type])` 从 JSON 文档提取标量值并转换为指定 SQL 类型（MySQL 8.0.21+）。默认返回 `VARCHAR(512)`，可通过 `RETURNING` 指定 `SIGNED`/`UNSIGNED`/`DECIMAL`/`FLOAT`/`CHAR`/`DATE`/`DATETIME`/`JSON` 等类型。支持 `DEFAULT ... ON EMPTY`/`ON ERROR` 错误处理。核心应用：为 JSON 列创建函数索引（`CREATE INDEX idx ON t ((JSON_VALUE(j, '$.key' RETURNING type)))`），使 JSON 路径查询可以利用索引加速。与 `JSON_EXTRACT`/`->>` 相比，`JSON_VALUE` 提供内置类型转换和错误处理，是 JSON 索引创建的推荐方式。
